# 分层演讲制作与编辑试用

2026-10-19 开始制作，2026-10-20 完成当前验证。本阶段在本机源码工作台提供独立试用入口，保留默认整图制作、已有项目、图片历史、逐字稿与口播。未替换或重启已安装的 Mac App，托管账号版不开放制作入口。

## 使用流程

在项目的画面制作页点击「分层制作 · 试用」。创建演示时选择分层制作和制作页范围。新记录保存原稿、风格与附件快照；正文和底图分开，后续修改只写入该演示。

生成依次执行文案复核、自由版式设计、无字底图生成、文字残留检查。已完成阶段会保存；失败后继续，避免无理由重复文案与版式请求。底图含字时会保留失败素材并提示，重试只重画底图。实际生成调用配置的模型并计费。新页面的所有主要文字均独立；旧试验底图中的书法等艺术字可以保留。

分层页直接点画面文字输入或粘贴纯文字；选择手柄可移动或调整范围，也可用方向键微调。“文字排版”面板修改字体、字重、字号、颜色和字距。输入不重载画布；“撤销一步”恢复最近一次画布编辑。「位置与出场顺序」提供文字框和动画步骤设置。保持自然字形，不自动拉伸或缩小；字体加载完成且文字未溢出后才能保存。保存最多保留 20 次撤销历史，有版本冲突时拒绝覆盖。

“页面动效”面板另提供六种可试播的内容编排，保存后用于 HTML；[详细适配范围与操作](分层演讲-画布编辑与动效编排.md)。三种播放方式按页保存：

| 方式 | 体验 |
| --- | --- |
| 自然出场 | 按配置的顺序、时长和延迟进入 |
| 逐步讲述 | 点击下一步揭示同组内容；可以退回 |
| 整页静态 | 整页同时呈现 |

在工作台打开的独立播放器中点击「暂停改字」，会暂停并定位到编辑器对应页。保存后更新播放器，保留页序和讲述步骤，由演讲者点击继续。离线导出的 HTML 提供播放，不提供这个与工作台联动的编辑入口。保存、撤销、播放均不调用模型；上屏文字、讲稿和已生成口播分别保存，改字不会自动重录。

## 导出与字体

HTML 内嵌图片、字体及所选已有口播；可离线播放。PPTX 从当前已保存的图层重新生成，使用底图和原生文本框；可在 PowerPoint 继续编辑。PPTX 本阶段不包含原生动画或口播音频。

PPTX 支持思源黑体 300/400/700 与思源宋体 400/600，导出字面为 Jianghao Sans Light、Jianghao Sans、Jianghao Serif。准备完整字体包后，按实际使用字面嵌入完整字库并附 OFL 许可；缺少字体、字重不支持或出现字库没有的字符会明确报错。完整嵌入可减少换电脑后的字体替换，不能保证不同排版引擎逐像素一致。

维护者使用独立 Python 环境安装 `scripts/requirements-pptx-fonts.txt`。准备经过校验、允许嵌入和分发的静态 TTF 与 OFL 原文，清单格式沿用[字体内嵌试验](正文分层-单页保真试验.md#pptx-完整字体内嵌试验2026-10-19)：每项含 `family`、`slot`、`file`、`licenseFile`、`sha256`。字体家族必须与上面的导出字面一致，字重及常规/粗体槽位要匹配。

```sh
python scripts/prepare-layered-font-pack.py /absolute/fonts/manifest.json /absolute/new-font-pack
AUTOPPT_PPTX_FONT_DIR=/absolute/new-font-pack npm start
```

目标字体包目录必须不存在。工具只读指定清单与字体，不发现或安装系统字体，不读写项目记录。字体包路径需要在启动服务前配置；没有字体包仍可编辑、播放和导出 HTML。完整中文字体会使 PPTX 明显增大，本次五页文件约 42 MB。

## 五种风格与验收范围

复用之前的水墨书卷、日系建筑、儿童摄影杂志、当代 NEO、先锋紫绿背景，共 5 页、21 个文字层，在全新工作区建立演示。演示沿用已校准的自然字体几何参数，不把任意图片识别成可编辑页面，也不宣称与模型笔画完全相同。

如本地保留上一阶段的试验素材，可创建新工作区复现：

```sh
node scripts/seed-layered-workflow-demo.mjs /absolute/editable-text-experiment /absolute/new-demo-data
AUTOPPT_DATA_DIR=/absolute/new-demo-data AUTOPPT_PPTX_FONT_DIR=/absolute/new-font-pack PORT=51921 npm run dev
```

目标数据目录必须不存在，脚本不复制模型密钥或设置。样例素材不进入 Git 仓库，只有源代码和复现工具提交。
