SIGNATURE: The real path is website → invitation/register → account/workspace → first-page trial; clicking website from a draft keeps the mounted workspace and returns to the last route with its draft preserved.
TYPE/MATERIAL/GROUND: Locally bundled incumbent DM Sans with Chinese system fallback, fine rules, generous spacing, legible labels. Login and registration use the same brand, with one focused form. Public screenshot assets already existed and are labelled as demo material.
OPERATE: My projects / styles are primary, up to six recent projects collapse independently, support and website are secondary, account is unified at the bottom. Admin-only website management is a separate destination; server permissions remain authoritative. Tablet icons retain titles and accessible names; mobile uses a focus-contained closable drawer.
