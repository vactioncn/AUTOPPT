# 讲好安装与使用说明

适用版本：2026 年 10 月 20 日的仓库代码。产品原名 AutoPPT；程序文件名与数据路径继续沿用原标识。

讲好把演讲逐字稿拆成页面，按选定风格生成图片，并导出包含逐页备注的 PPTX。按照本说明完成安装、模型配置和一次小规模测试，就可以开始制作自己的演讲。

本轮源码将产品显示名、工作台页头、菜单和官网统一为「讲好」，使用同一品牌标志。本次未安装或替换 `/Applications/AutoPPT.app`，正在运行的旧 App 不会自动更新；新界面需在新构建版本下一次启动后使用。已有项目、模型连接和草稿保持，数据无需迁移。

优先使用下方 Mac App 方式，无需登录。第 1–6 节继续介绍浏览器本机版：程序运行在自己的电脑上，项目也保存在本机，分享代码不会同步已有项目、参考图或模型密钥。使用管理员提供的网站地址和邀请码时，请直接阅读第 7 节，无需本机安装或填写 Key。

## Mac App 的安装与使用

> 2026-10-18 新增独立的 [huashu-motion 动态讲解试验](huashu-motion-PPT价值实测.md)：40 秒样片可连续播放、逐步讲述并导出带配乐视频。它需要单独的本机预览服务，不是已安装 App 中的新按钮，也不改变现有项目或模型配置。普通使用者无需安装试验依赖；开发者复现步骤与限制见链接。

拿到 `AutoPPT-mac-arm64.zip` 后解压，将 `AutoPPT.app` 拖入“应用程序”再打开。App 无需账号、邀请码、Node 或服务器；第一次在“模型与服务”配置内容理解与图片生成服务。项目保存在本机；调用模型时，相关文字和图片仍会发送到自己配置的服务商，并按服务商规则计费。

当前是 Apple Silicon Mac 内部构建，尚未配置 Developer ID 签名和 Apple 公证，其他电脑可能受到 macOS 安全检查限制。Intel Mac 尚未实机验证。构建者可在 Mac 上执行 `npm ci`、`npx install-electron`、`npm run build:mac`；在全新临时目录验证 App 与压缩包后，只保留 `release/AutoPPT-mac-arm64.zip`，临时 App 自动清理，避免启动列表出现多个 AutoPPT。`AUTOPPT_MAC_OUTPUT_DIR` 可指定 ZIP 输出目录，构建不修改已安装程序。普通使用者不需要执行这些命令。

日常只保留“应用程序”中的 `/Applications/AutoPPT.app`。升级前先等任务结束、退出旧版并备份数据，再将新 App 拖入“应用程序”替换同名程序。确认新版本能打开、项目完整后，把下载或构建目录中多余的 App 移到废纸篓；暂不清空，便于恢复。不要使用卸载工具清理关联数据，也不要删除 `~/Library/Application Support/AutoPPT/` 或旧浏览器版的 `.local/`；这些位置保存项目、素材、声音、密钥和草稿，不属于可清理的安装副本。

在新构建版本的菜单“讲好 → 打开数据文件夹”查看本机项目，已安装旧版菜单可能仍显示 AutoPPT。数据位于 `~/Library/Application Support/AutoPPT/workspace/`，独立于旧浏览器版的 `.local/`，安装包不包含他人的项目或 Key。App 不会自动迁移旧项目；可在浏览器版的交付中心导出项目源文件，再从 App 项目首页导入新副本。

设置页分为“模型服务”“语音与声音”“实验室”，切换后只显示当前栏目。模型与 MiniMax 已配置时默认收起连接表单，可展开“修改连接配置”或“修改 MiniMax 连接”，修改后点击对应保存按钮。语音栏先选择默认声音，需要本人声音时再展开“采集演讲者的声音”。切换栏目保留未保存输入，并停止录音和试听，不会自动保存或生成素材。数字人移到实验室并标为实验功能；已有头像、声音、视频和项目选择保留。新项目演练默认“自己讲”，需要数字人时主动展开实验入口。

项目首页的删除入口是卡片右上角的垃圾桶图标，鼠标移到卡片上时才显示；键盘聚焦时也会显示。触屏设备保持显示，点击区域更大。点击后先确认，选择“取消”不会删除项目。

App 内打开“设置 → 实验室 → 数字人工作室”，连接 HeyGen 和 MiniMax，再保存头像、风格和 MiniMax 声音，输入短文字试播。文字先用所选 MiniMax 声音合成音频，再把头像和音频交给 HeyGen 同步嘴型，不使用 HeyGen 平台配音。Key 保存在当前工作区，不回显、不随项目包导出；测试连接只查询账号，真实试播按两项服务规则计费。浏览器预览与 App 配置不同步，旧 App 需升级。

项目中进入“演练中心 → 实验室 · 数字人讲解”，直接选择已准备好的数字人，生成本页或整场讲解。默认从逐页讲稿生成声音和嘴型，不需要先制作 AI 口播。操作步骤见后文。

点击窗口关闭按钮会隐藏窗口，任务继续运行；从 Dock 可重新打开。选择菜单“退出讲好”（已安装旧版为“退出 AutoPPT”）或按 Command Q 才会退出，有未完成任务时会先提醒。退出再打开，已保存内容和试做草稿仍会保留。备份时先退出 App，再复制整个 `workspace` 文件夹；不要分享包含自己模型密钥的 `settings.json`。

## 1 开始前准备

准备好以下内容：

- 一台 Mac 或 Windows 电脑，以及能够联网的浏览器。
- Node.js 24 LTS。项目最低要求为 22.13；建议新安装统一使用 24 LTS。安装包自带 npm，下载地址：[Node.js 官方下载](https://nodejs.org/en/download)。
- Git。用于下载和更新代码，下载地址：[Git 官方下载](https://git-scm.com/downloads/)。也可以直接从 GitHub 下载 ZIP，跳过 Git 安装。
- 模型服务的接口地址、准确的模型名称和 API Key。需要分别配置内容理解和图片生成，具体要求见第 3 节。

代码仓库：[vactioncn/AUTOPPT](https://github.com/vactioncn/AUTOPPT)。如果无法打开，请联系仓库负责人确认访问权限。

无需另行安装数据库、Python、Docker 或 Codex。导出后可以用 PowerPoint 等兼容软件打开 PPTX。公开作品网址导入在部分动态页面上需要本机 Google Chrome；普通本地图片上传不需要额外安装浏览器运行组件。

**完成顺序：安装运行环境 → 下载代码 → 安装依赖并构建 → 启动 → 配置两类模型 → 生成测试稿 → 导出 PPT。**

本说明的安装、构建和启动在 macOS 与 Node.js 24 环境验证。Windows 提供对应操作步骤和通用启动命令，尚未在 Windows 实机验收。

## 2 首次安装与启动

### 打开项目所在的终端

安装 Node.js 后，重新打开终端，让新安装的命令生效。

- **Mac**：打开“终端”，输入 `cd `（末尾留一个空格），把准备存放代码的文件夹拖入终端，再按回车。
- **Windows**：在文件资源管理器中打开准备存放代码的文件夹，点击地址栏，输入 `cmd` 并按回车。下面命令按“命令提示符”编写；如果使用 PowerShell 且提示禁止运行 `npm.ps1`，请改用 `npm.cmd`。

先逐行执行，确认安装成功：

```sh
node -v
npm -v
git --version
```

`node -v` 应显示 `v24.x.x`，或至少为 `v22.13.0`。选择 ZIP 下载方式时，可以跳过 Git 检查。

### 下载代码并安装

使用 Git 时，逐行执行；每一步成功后再继续：

```sh
git clone https://github.com/vactioncn/AUTOPPT.git AutoPPT
cd AutoPPT
npm ci
npm run build
npm start
```

也可以在仓库页面点击 **Code → Download ZIP**，完整解压后，在含有 `package.json` 的目录打开终端，从 `npm ci` 开始执行。ZIP 不含 Git 记录，构建前需向维护者取得该源码对应的完整 40 位提交号：Mac 执行 `export AUTOPPT_BUILD_GIT_SHA=完整提交号`；Windows 命令提示符执行 `set AUTOPPT_BUILD_GIT_SHA=完整提交号`，再执行 `npm run build`。不能填写分支名 `main`。不要直接在压缩包内运行，也不要复制其他电脑的 `node_modules`。

看到终端输出 `AutoPPT → http://127.0.0.1:4317` 后，在浏览器打开：

**http://127.0.0.1:4317**

能看到“项目”“风格库”“模型与服务”即表示本机程序已经启动。首次运行没有个人项目，模型密钥也需要重新配置。

### 日常启动与停止

以后进入同一项目目录，执行 `npm start` 即可；终端保持开启。关闭浏览器不会停止生成任务。需要关闭程序时，先等待任务完成，或在页面点击“停止”，再回到终端按 **Ctrl+C**。

Mac 完成首次安装和构建后，也可双击仓库内的 **启动 AutoPPT.command** 在后台运行；首次被系统拦截时，可使用终端中的 `npm start`。后台模式关闭终端仍会运行，停止方法见第 5 节。

## 3 配置模型并完成首次测试

### 配置两类模型

打开“设置”，分别填写以下两个区域。两者可以使用同一家服务，但需要确认对应接口和模型都可用。

| 配置区域 | 模型需要具备的能力 | 使用场景 |
| --- | --- | --- |
| 内容理解与风格分析 | 兼容 Chat Completions，支持 JSON 输出和图片理解 | 拆分讲稿、提炼和复核上屏文案、分析风格参考图 |
| 图片生成 | 兼容 Images Generations；带附件还需支持 Images Edits 多图输入 | 根据方案与内容附件生成完整画面 |

每个区域都要填写：

1. **接口地址**：填写服务方提供的基础地址，通常以 `/v1` 结尾。不要再拼接 `/chat/completions`、`/images/generations` 或 `/images/edits`。
2. **模型名称**：使用服务方实际提供的名称。页面中的预填值和下拉建议不代表你的账户一定有权限使用。
3. **API Key**：填写对应服务密钥。可以先测试当前输入，确认后点击“保存设置”。另一个区域也要完成同样操作。

支持你们自建的 OpenAI 兼容 API。接口地址使用服务方提供的基础地址（常见以 `/v1` 结尾，也可以是自定义路径），模型名称填写服务内部配置的名称或别名。

- **测试连接**：只发一次轻量连接请求，不核对模型名称、不调用生成，不自动保存。自定义名称不在模型列表里也不会因此失败。
- **查看结果**：HTTP 错误、超时或服务返回错误时如实提示；返回网页或非 JSON 时，只说明“服务地址已连通”，不能据此判断密钥或模型生成可用。
- **保存设置**：单独保存当前配置。更换服务地址后需重新填写对应密钥。接口路径和模型名称按你的填写使用，不自动改成官方地址或其他型号。

**连接成功但制作没有结果**：先检查服务方给出的完整 API 基础地址。若实际地址需要 `/v1`，只填根域名可能返回网站网页，虽然 HTTP 为 200，也没有模型内容。生成错误会分别说明“返回网页”“没有有效 JSON”或“缺少 Chat Completions 文本”，不会据此断言模型不支持视觉。按服务方提供的路径修正设置后，回到失败任务点击“继续重试”；已有原稿和完成页面保留，系统不会自动重提任务。

生成时会把相关讲稿、设计内容，风格分析所需的参考图，以及重做页面时添加的内容附件发送给配置的模型服务，可能消耗该服务额度。API Key 保存在本机 `.local/settings.json`；转发说明文档和代码时，无需附带此文件。

年份按内容依据处理：原稿、图表和截图中的真实历史日期保留，不统一改成今年。内容分析与出图请求会携带上海时区的实时日期，只在明确要求“今天/当前年份”时帮助理解，不自动加入口播或画面。风格示例、文件名和素材边缘的装饰年份不应被沿用为新页年份。已有图片、原稿、风格规则与历史不批量改写；PPTX、HTML 和图片下载使用已保存的画面，所以旧图片里的日期仍会保留。模型可能仍未遵循日期要求，请查看实际成品。具体检查范围与验证结果见仓库中的《提示词年份检查》。

### 做一次完整测试

1. 项目首页的首次工作区准备卡会显示运行形态、模型和风格状态，可跳过；模型未就绪时可选“先写草稿”，生成前才需连接。本机可点“连接并测试模型”，hosted 按账户的真实模型服务状态判断，未就绪时请联系管理员或等待配置。Mac 与本机浏览器点击新建后，先填写主题（如“首次测试”），从封面直接选择风格；默认选中“克制儿童摄影杂志风”，也可搜索其他风格。点“下一步 · 内容倾向”，可保持通用，或选一个常用行业，再点“创建并写第一段”进入制作台。没有可用风格时，前往风格库会直接打开“手动填写”；往返会保留已填主题和设置。手机上底部下一步与创建按钮保持可见。
2. 粘贴约 100–500 字准备讲的话，或点“使用示例文字”后替换。系统自动拆页，完整原稿保留。草稿自动保存，但“已保存”不等于“已生成”。首次点击“提交讲稿并制作”会确认模型调用与费用：先调用内容模型拆页，再按实际拆分页调用图片模型；具体页数以结果为准。本机费用由配置服务商按实际调用收取，hosted 使用管理员图片额度。点击“开始生成”后等待完成；“返回修改”或关闭保留草稿。“以后直接生成”只适用于后续提交新讲稿，并在服务端接受本次生成后记住；草稿保存或请求失败不会启用。响应丢失时重试同一讲稿会复用提交标识，避免重复建批次。也可用下面这段短稿：

```text
# 开场说明

今天我们一起讨论，怎样把重复的工作交给工具。
例如，先把整理资料交给工具，再由人判断哪些信息值得使用。
这样，我们就可以把更多时间留给与客户的交流。
```

3. 打开生成页面，先看三点提示：逐字稿是演讲者说的完整内容，上屏文案是观众看到的重点，重新设计是按当前讲稿和风格重新制作画面。保存讲稿或点击“知道了”后不再重复；再次调用模型与费用的提示保留在重新设计确认框。确认图片可以显示，逐字稿只保留正文。“开场说明”这一整行标题应已去掉，正文措辞和段落应保留。
4. 在交付中心先点击“查看制作报告”，确认原稿正文与页面备注逐字一致；再完成导出检查，点击“下载 ZIP 交付包”。解压 ZIP 后打开 PPTX 和独立逐字稿 Markdown，确认页序、图片和逐页备注正确。备注可在 PowerPoint 的备注区域或演讲者视图查看。

首次测试通过后，再导入个人风格和较长讲稿；如果失败，先处理页面中给出的具体错误。没有页面时，演练中心突出“先写讲稿 / 生成至少一页”，交付中心提示“还没有可交付内容”并可返回制作台；“项目源文件”折叠区仍可备份和迁移草稿。

“使用帮助 → 重新查看新手引导”可以重看工作区准备和页面提示，不更改生成确认的选择。三个引导偏好独立保存在当前浏览器，按运行形态和实际登录账号隔离，不随项目包迁移；清理浏览器存储后会重新显示，存储不可用时只在当前会话记住操作。模型未就绪、取消确认或请求错误均不会清空草稿。

### 官网与帮助

本机浏览器、后续新构建的 Mac App 和服务器版共用 `src/WebSite.tsx` 的「讲好」官网：保留四组十二张实际作品、产品介绍视频和 Amanda《朝花夕拾》声音案例。工作台侧栏统一为“官网与帮助”，打开 `/website`；网站内的“使用帮助”位于 `/support`，与工作区帮助共用可搜索的问答组件和内容源。官网讲产品，帮助讲操作，不再挂载旧版介绍 iframe。返回工作台保留当前会话的工作页面与草稿。

旧 `/#intro`、`/intro/` 和 `/intro/index.html` 转到统一官网，`/intro/help.html` 转到统一帮助；旧 `/#help` 仍兼容工作区诊断与新手引导。当前构建不再生成旧静态介绍站点，旧 `deploy:intro` 命令已停用，不会上传另一套页面。历史源码、文件和已发布站点不删除。

官网随完整服务部署到同一域名：`/website` 为介绍，`/support` 为帮助，`/login`、`/register` 为账号，`/#projects` 为工作台。本机打开官网直接返回本机工作区，无需邀请码；服务器保持邀请制账号与权限隔离。

### 查看版本与工作区

打开左侧“使用帮助”，展开“版本与工作区”。这里同时展示前端页面和后端服务的版本、短提交号、构建时间、接口版本与一致性状态，以及当前运行形态、工作区说明和能力矩阵。需要完整提交号时，将鼠标停在短提交号上。页面默认不显示内部绝对目录或密钥。

本机浏览器工作区保存在本机服务中，项目不会随浏览器缓存清理而删除；Mac App 独立工作区与浏览器版分开，可从 App 菜单打开数据文件夹；hosted 账号工作区保存在托管服务中，由管理员管理，账号之间保持隔离。

能力矩阵包含项目源文件导入导出、PPTX 与逐字稿、标准放映、AI 口播生成、动态演示、本机和管理员模型设置。不可用时会显示原因。未配置语音的本机版仍可手动翻页；hosted 支持口播播放器和可选 MiniMax 合成，其模型设置由管理员管理。演练中心、交付中心与模型设置页会复用相同的服务原因。

如果前后端接口版本不兼容，或发布版本的已知提交号不同，程序会暂停进入工作台。先点击“刷新页面”；若仍异常，请等制作任务结束后更新 App，或请管理员重新部署同一发布的前后端。已保存项目不受影响。开发环境提交差异只提示；unknown 表示无法核对提交，不代表版本冲突。

## 4 制作自己的演讲

### 建立风格

进入“风格库 → 创建风格”，选择“手动填写”，输入名称和完整风格提示词（最多 3 万字），点击“保存风格”即可使用。无需上传图片，也不调用模型改写提示词；可直接试做或用于演讲，后续修改进入版本记录。需要根据图片重新提炼时，再补充参考图。

也可以选择“上传图片”，或选择“从网址获取”，粘贴公开作品页或图片链接。可上传或继续追加 1–12 张图片，支持含多页缩略图的展示图；网址导入先展示预览，勾选后再分析。名称可留空自动命名。展开“视觉补充要求（可选）”，只填写希望强化或避免的视觉方向。主题、行业、受众与使用场景属于具体项目，在新建项目或项目的“内容倾向与配色”中填写并保存。输出沿用单张 16:9 横版演示页面。

点击“分析视觉风格”，系统先从十二个维度观察图片，分开内容主题、具体版式、视觉语言与底层设计逻辑，区分直接观察与合理推断。然后判断同一视觉系统、不同页面类型、混合风格、离群图或证据不足。多种风格按 STYLE A、STYLE B 等独立生成，离群图明确标注且不并入主体；不能从参考图题材推定所有新页面必须出现同一个人物、物件或行业。缩略图展示的外框、灰底、阴影、水印和源图文案按模板要求忽略。一张拼图内部若含不同风格，先说明可辨认主体与局限，需要分组时请拆成独立图片上传。

提炼时每个章节只显示一次标题；程序去掉模型在章节开头重复的同名标题与编号，保留正文。手动保存的规则和历史版本不会自动改写。

每组结果可查看中英文名称、定义与风格边界、核心视觉 DNA、完整提示词、锁定语句和风险提醒。完整提示词有 19 个章节，覆盖角色、内容判断、气质、颜色、字体、构图与网格、图像、材质、图形、真实数据、编辑细节、页面变化、行业语境、禁止事项、自检与效果标准。四级规则明确“必须保持、可以变化、偶尔使用、必须禁止”。锁定语句、四级规则与共同设计底线已合并进完整提示词，点击“复制完整提示词”即可带走。预览其他组不更换当前规则，点击“采用这组风格”才保存新版本；试做、封面与正式页面使用当前保存的完整规则。

风格详情默认显示“已保存到风格库”，可直接用于新项目或试做，无需再次保存。提示词、分析记录、历史版本与动态页码说明统一放在折叠的“高级设置”中，日常使用不需要打开。高级设置中复制和编辑使用当前保存的完整原文，不会误用旧分析；“分析记录”保留最近一次提炼的候选与依据，明确点击“采用这组风格”才保存新版本。

风格详情的标题、关闭按钮与底部操作保持可见。桌面左侧是参考图和可选视觉调整，右侧是保存状态与高级设置；窄窗口改为单列。已有参考图时展开“调整视觉风格（可选）”，填写调整要求，草稿自动保存在本机，关闭后重新打开仍可继续；点击区内“重新提炼风格”成功后才应用到风格，失败时保留当前规则。无参考图时先补图，不展示无法应用的调整表单。高级提示词编辑仍需明确“保存规则”，保存前不能试做或创建项目。项目的主题、行业和受众不会从这里填写。

每次分析先调用一次支持图片理解的内容模型，再为每组调用一次内容模型生成提示词，单组共两次，产生相应服务费用；不会自动生成图片。全部组验证通过才保存，任一组失败或取消都保留原有规则；升级不会自动重写已有风格。原图只用于观察，写作使用本组记录，出图使用完整提示词。成功后再主动试做，核对不同内容是否做到同源但不同形。分组、复制、切换、失败保护和版本保留已用模拟模型与浏览器验证；真实模型的分组准确率、分析深度与新风格成图效果尚未实测。

部分站酷页面需要本机 Google Chrome。遇到登录、滑动验证或图片访问限制时，可以改用图片直链或本地上传。程序不会自动完成验证码。

在风格详情点击“试做一页”，桌面左侧集中显示成图、保存风格和试做记录，右侧按“试做内容 / 调整效果”切换操作；右侧内容独立滚动，生成按钮保持可见。窄窗口先编辑内容，再查看成图。默认使用预填示例，“换一段示例”可切换通用表达、儿童摄影、运动与赛事，无需先创建项目。试做草稿自动保存在本机，切换页签保留讲稿、调整意见、提示词和独立配色；讲稿、行业、受众与临时配色不会保存为正式风格。需要精细调整规则时展开“试做内容 → 高级设置”；展开“内容倾向与配色（可选）”才显示这些选项。已有讲稿仍可手填或从已有页面选择。普通试做不再用作封面。展开“风格封面”后点击“生成统一封面”，固定以“让想法被看见 / 把内容讲清楚，让表达有自己的风格。”两句文案，按已保存风格直接生成一张图并自动设为封面。文案不再提炼，也不带入试做讲稿、反馈或临时倾向与配色；不改提示词、不增加出图参考。失败或风格中途变化时保留旧封面。封面只需图片模型；普通试做还需内容模型，均会调用所选服务。若提示后台版本过旧，请等制作任务完成后重新打开程序，仅刷新网页不会更新后台。

封面、试做和演讲页面统一为横向 16:9。模型请求中会独立注明画幅要求，保存前再检查实际图片比例。服务返回竖图、方图或其他比例时，显示真实尺寸并停止，保留旧图片和封面，不自动重试；再次生成可能收费。历史异常图在横向预览框内完整显示并标出问题，不拉伸或裁切掩盖错误。尺寸可能因服务而异，比例允许 1% 的取整差异。

提炼后可先“风格试做”。设计提示词将原文用于出图，不会自动改写。需要修改时在“试做内容 → 高级设置”中编辑原文，试做满意后点击“保存这版为正式风格”；只有主动“重新提炼风格”才会根据参考图改写规则。

### 查看和恢复提示词版本

在“查看风格 → 高级设置”进入“历史版本”，或在试做区的“试做内容 → 高级设置”中展开“提示词版本”，选择历史记录，查看版本号、保存时间、来源及完整提示词；展开“与当前版本比较”，可查看增加、移除的文字和旧版构思方式的历史记录。

手动保存、重新提炼、试做转正式时，提示词有变化便留存版本；相同内容不重复保存。点击“恢复此版本”会创建一个新版本，恢复前的内容仍保留。恢复不改变参考图和已有图片，下次主动制作时使用恢复后的规则。编辑中的内容需要先保存或取消；试做中的草稿可先转为正式风格，或“从正式风格重新开始”。其他窗口更新过规则时，会提示冲突并保留你的输入，先比较最新版本再保存。

版本保存在本机数据库中，备份 `.local` 时一并保留。旧提炼和试做转正式记录按实际保存内容展示；旧版构思方式仅作为历史元数据保留，恢复版本也不会重新启用额外构图。过去没有留存的手动修改无法补回。

### 动态角标页码

图片生成时，系统只在风格原有的明确页码描述处填入整份演讲的当前页序，例如“微型页码”临时变成“微型页码（显示为 84）”。字体、位置、大小与装饰仍由原风格决定；保存的提示词、版本和封面不会被自动改写。也可在原有页码位置手动填写 `{{page_number}}`。单页试做和统一封面使用 `01`，演讲页面按真实页序使用 `01`、`02`、…、`100`，与本次制作的任务编号无关。

系统仅识别明确的“页码 / page number(s)”描述或上述占位符。没有明确位置、带否定要求或已经指定固定数值时，不猜测修改；章节、照片与流程编号不替换。风格详情会提示是否支持动态页码。当前内置的先锋酸性色彩编辑风、新瑞士主义战略编辑风、高质感手账、日系现代建筑提案风可自动识别；其他内置风格保持原文。

“实际发送的出图提示词”可核对编号。页码由图片模型画入，下载和导出不会另加数字；模型仍可能漏画或写错。插页、删页、拆分、合并或调整顺序不会自动重画旧图片，受影响页面需重新生成，重试时按请求发出前的最新顺序取号。页面详情会提示新旧页序不一致；本功能没有为既有图片识别或修复页码，也不自动增加付费调用。

### 切换风格与保留满意的设计

0.2.0 版新增 8 套已选定的风格及统一文案封面：先锋酸性色彩编辑风、新瑞士主义战略编辑风、高质感手账、暗黑参数化数据地形风、80 年代复古编辑风、日系现代建筑提案风、当代 Neo-Swiss、高端科技战略发布会风。连同原有 5 套，共 13 套内置风格；默认首选仍为“克制儿童摄影杂志风”。新增的 8 套均保留完整提示词与已生成封面，新安装无需重新提炼或生成这些封面。升级只补齐缺失记录，保留同 ID 风格的个人修改、删除状态与已有项目选择。封面仅用于展示，不作为生成参考；模型接口仍由使用者自行配置。

“克制儿童摄影杂志风”已设为程序默认风格，保留完整原始提示词，采用黑白基底、少量荧光黄绿、杂志编辑语言和儿童摄影行业语境，默认直接出图。新建项目预选这一风格；从某个风格详情新建时，沿用明确选择。专属封面随程序提供，用于风格库、风格选择和无成图的项目预览，不作为出图参考，不限制以后页面的构图。升级复用已有同 ID 风格，不覆盖提示词、历史版本、删除状态或旧项目；新安装自动补齐内置记录。旧的“克制极简风格”继续保留；默认项不可用时会选取其他可用风格。

字体、材质、图形与装饰由所选风格规范决定；配色默认沿用风格，也可独立选择。已有风格规范与成品保留。新主题建议单独建风格，上传参考、提炼并试做。向原风格追加图片会保留原有参考和规则。

“按内容构思”功能已取消。试做、单页重新设计与整场制作统一按风格原文和已复核文案直接出图，不额外调用内容模型制定构图，旧的开启配置也不再生效。已有图片与风格版本保留，升级不会自动重新生成。

旧版保存的构图说明可在生成依据中查看，标为“历史构图记录（功能已停用）”。再次生成或重试不会把它追加给图片模型；有效上屏文案继续复用，附件、独立配色和你主动填写的画面调整仍按原流程使用。

选择新风格后，选中需要更新的页面并重新设计。新图原文使用所选风格的提示词。讲稿和内容附件未变时，复用同一份已提炼文案，不因换风格重新拆稿或改写文字。仅切换选择不会自动替换成品，旧版本保留。

画面调整与上屏文字调整分别填写。画面反馈只影响本页视觉表达，不改写风格提示词；需要精简或重选内容时，填写“上屏文字调整”。图片模型执行构图，不保证逐像素保留旧布局，最终效果需检查样张。

### 内容倾向与配色方案

Mac 与本机浏览器的新建窗口在第二步选择内容倾向，默认为“通用 · 不限定行业”。也可直接选择摄影影像、教育培训、科技互联网、零售电商、餐饮文旅、医疗健康、金融服务、制造工程或企业管理。9 类预设都带有完整说明，直接使用，不需要调用 AI。倾向仅调整语境，保留原稿含义与所选视觉风格。

需要更具体的倾向时：选择“定制我的内容倾向” → 填写受众与场景 → 点击“生成专属倾向”。生成时会显示阻塞进度窗，说明正在处理什么及等待时长；可取消，输入会保留。失败后可重试，或选常用行业/通用继续。完成后可展开“查看并修改说明”，确认后再点“创建并写第一段”。修改简述需重新生成；返回上一步、往返风格库保留已填设置。配色放在第二步的“配色调整（可选）”，默认沿用风格。

项目中的“内容倾向与配色”和风格试做仍使用原编辑方式。已有详细说明未编辑时保留；旧记录只有简述、没有说明时，在这些编辑器中会自动补齐说明草稿。保存格式不变，不更新旧项目或已生成画面。

在项目设置或风格试做中，内容倾向写一句受众或场景，例如“面向儿童摄影影楼老板”。停止输入约 0.9 秒后自动生成方案，输入框下会显示进度；无需打开“展开说明”。折叠区只用于查看和手动编辑，外面的“重新生成说明 / 重试”可再次生成。中文输入法组词时不发送请求，连续修改合并处理；改字、手动编辑说明、清空或关闭后，旧请求不会覆盖新内容。失败时仍能保存简述，不会自动反复重试。生成说明以用户提供的“受众与行业语境”范本为参考，依次展开受众视角、具体候选场景、抽象概念的转译、应避免的偏离、使用边界及最终目标；场景与措辞按行业或活动重新选择，不只替换名称。简述修改后，以新描述为准，清除旧展开说明并自动更新。语境服务内容，不补出原文没有的事实、定义、判断或结论。

配色现有 16 套预设，按“清爽商务 / 温暖人文 / 深色舞台 / 鲜明创意”筛选，选择后可看颜色预览。也可点“自定义”，承接当前背景、文字和强调色，用取色器或直接填写 HEX 色值（#RGB 或 #RRGGBB）；无效色值不会写入设置。无需提取旧颜色、填写名称或编写提示词。选择新色板后，出图模型按原风格是否已有配色，替换原配色或采用新配色；字体、材质等继续按原风格。选回“默认 · 沿用风格”可取消替换；切换风格时保留已选独立配色。已有自定义说明可按需编辑，不修改则保持原样。

填写或修改非空简述会自动调用内容分析模型，重新生成也会调用并产生相应服务费用；展开说明、选择色板和自定义颜色不调用模型。生成期间暂停保存或出图，但仍可改字与选色；清空或关闭可取消待处理请求。保存设置不会自动修改已有图片；选页重新设计才应用。讲稿、附件未变且文案已有有效复核时，复用原上屏文案；构图仍可能变化。内容附件中承载事实的颜色要求保留，成图请自行核对。

每次试做与页面历史保存实际使用的选项；试做转正式不会把语境或配色写入共享风格。查看生成依据可核对设置，对照 ChatGPT 时复制完整出图提示词。

### 删除项目与风格

在“我的演讲”的项目卡片或风格库的风格卡片右上角点击“删除”，再确认。项目正在制作、风格正在提炼或试做时，需先完成或停止任务。

删除项目后从列表移除，无法继续编辑、生成或导出该项目；其他项目与共享风格不受影响。删除风格保留已有页面、讲稿和历史，使用它的项目需另选风格才能继续制作。底层保留原记录及图片以免破坏历史和共享素材，删除不能用于释放磁盘空间，目前没有界面恢复入口。

### 从制作台到演练中心

演练中心首先提供“开始演练”：直接播放制作台已保存的 PPT，自己现场讲，无需先生成声音。本机制作台的“编辑文字与动效”用于画布改字、排版和动效；关闭后留在制作台。完整且与当前项目版本、页序一致的可编辑 PPT 会用于演练，保留编辑器选中的版本；没有可用版本时明确显示使用项目画面，读取失败时不自动切换。“AI 口播与配音（可选）”收起声音、试播、整场生成和已有记录，口播稿与上屏文字分别保存。旧图片提取仅留在兼容设置和历史入口，不再是开始演练的必经步骤。

一次准备的服务连接、密钥、声音采集、默认声音放在全局设置；头像与数字人声音在实验室管理，风格在风格库管理；本场只保存素材编号与演讲选择。缺少声音或头像时，点击“管理声音 / 服务”或“管理 / 创建头像”，打开独立设置窗口，完成后直接返回原项目。改变全局默认声音不会替换已有项目保存的声音。数字人按本场所选 MiniMax 声音生成音频，再把同一音频交给 HeyGen 同步嘴型；也可沿用本项目已有完整口播，不重新配音。

“先试当前页”支持开头最多 100 字或完整一页，确认范围和费用后才开始。短片段明确标记，不当作完整页结果；完整页试播与整场文字、声音、语速、情绪、头像一致时复用音频和嘴型视频。动态演示先转换当前页，整场只生成尚无匹配结果的页面。未填口播或缺少画面的页面会提示，用户可调整范围后生成。

生成期间显示声音、嘴型与动态页进度，可先听完成的声音或看完成的页面；关闭窗口后任务和结果仍保留。整场完整音频另存为口播版本，可在高级播放器与交付中继续使用。HeyGen 明确失败时不再显示“继续查询或下载”，已生成的 MiniMax 音频保留；处理失败原因后，重新确认生成可复用音频。尚在处理或下载失败的提交继续使用原任务，避免重复提交。继续未生成的声音或失败的动态页需再次确认费用。

“已有版本与高级调整”保留原口播播放器、AI 演绎、数字人历史和动态图层校准。密钥已保存仅代表完成配置，不代表服务可用或额度充足。自动化测试使用模拟服务验证数据保留、个人声音、完整页复用、短片段范围和失败保护；真实 App 的验收进度与服务限制见[本次发布验证记录](演练中心发布验证-2026-10-10.md)。

### 追加讲稿并调整页面

项目分为“概览 → 制作台 → 演练中心 → 交付中心”，对应“写 → 做 → 练 → 交”。概览按当前状态给出一个下一步动作，来源版本不同的演示会单独提示。已有讲稿时，制作台顶部显示“继续添加讲稿”，内容视图为“页面 / 演说稿”，范围为“最近制作 / 全部页面 / 历史段落”。演练中心打开播放器和动态演示，交付中心集中报告与下载。

“最近制作”跟随实际制作任务：制作中显示当前及排队任务涉及的页面，没有进行中的任务时显示最近一次制作的页面，完成后仍保留在视图中。标签数字表示页数，卡片按整份演讲的当前顺序编号，插页后会随之更新。查看旧讲稿使用段落下拉框，“全部页面”查看完整演讲；尚无制作记录时回退到最近添加的段落。

流程为“完整逐字稿 → 按讲述逻辑拆页 → 每页提炼并复核上屏文案 → 搭配原始风格提示词出图”。风格不参与拆页和文案提炼。段落是拆页依据，不机械地一段一页。选好风格后，一段一段追加逐字稿，确认本段效果后再继续。系统保留提交原文，并在拆页和保存逐字稿时去掉 Markdown 标题，包括 `#` 到 `######` 的标题，以及下划线式标题。正文、普通短句、加粗强调和段落继续保留。

**需要被去掉的大标题，请在原稿中明确标成 Markdown 标题。** 没有标题标记的普通短句会作为正文保留。

在页面卡片或演说稿的页间点击“插入”，填写新页完整讲稿，再点“插入并生成”。固定新增一页，沿用当前风格、内容倾向和配色，后续页码顺延；不等待其他页制作完成。也可仅插入、稍后生成，或在第一页前及末尾插入。失败后新页和讲稿保留，可以改稿或重试；网络异常后重试同一次提交不会重复插页。

手动拆分可对照原图插入分界，立即拆成多页；默认后台生成，也可关闭生成先改稿。原文及内容附件保留，新页重新提炼文案和出图。拆分页空闲时可撤销，不影响其他页刚完成的图片。合并相邻页仍先预览、确认后出图。修改正文后，画面标记为待核对。在概览点击“核对 N 页画面”，可查看每页原因及前后讲稿；换行、空格或加粗的变化会单独说明。需要调整时进入页面编辑；画面仍适用时点击“确认保留第 N 页”，关闭该页提醒。“稍后处理”暂不作决定。确认保留不调用模型，原图、讲稿和历史保留；以后再次改稿会重新提醒。

逐页修改后可提交后台任务，再编辑其他页，最多同时执行 4 项，超出自动排队。手动拆分立即保存新页，每张新图独立排队；制作只锁定对应页。合并方案只锁定来源页，追加讲稿只锁定未完成页，同一项目的追加段落按顺序制作。其他空闲页可改稿、重绘、拆分，也可提交下一段。正在制作的本页可先写草稿，完成后再提交；离开时提示未提交内容。已有拆分或合并方案在来源页空闲时即可确认，其他页任务不影响。确认时显示提交状态，失败提示仅属于本次窗口，重新打开会清除旧提示。切换风格和 PPT 导出仍需项目空闲，单独下载已保存逐字稿无需等待出图。旧图保留，失败可重试；实际提速取决于服务商额度。弹窗外部点击或拖动不会关闭弹窗；请用关闭、取消按钮或 Esc 键。

### 看懂本次制作进度

顶部按本次实际需要制作的页面显示“已生成、失败、待处理”，另列已保存并跳过的页数。例如 133 页中还有 24 页未完成，继续后分母为 24，另外 109 页明确显示已保存、本次跳过；当前页仍标注原项目页码。“已处理”包括成功和失败，不代表全部成图；内容分析保存进度也不代表图片已经生成。

可恢复的服务拥堵、暂无可用通道或限流拒绝会先自动等待并重试，显示原因、等待时间与次数，无需再次点击，恢复期间不标为失败。恢复成功后继续制作；重试耗尽或需人工处理时，才显示失败数量。展开“查看原因与处理方式”可查看原页码、原因分类、建议操作和具体错误。失败页先跳过，其他页继续，已完成内容立即保存。任务结束后点击“继续未完成任务”，仅补做未完成部分。

### 全部或选择几页重新设计

在制作台点击“重新设计”（手机端先展开“更多操作”，也可用键盘聚焦后按 Enter 展开）。手机首屏保留“补齐未生成页面”；首部插页和撤销也在“更多操作”中。选择“全部页面重新设计”会包含整个项目，不受当前查看段落影响；选择“选择几页重新设计”后，直接勾选缩略图，也可“全选可重做页面”或“清空选择”。页面卡片左上角的多选框始终显示，勾选后也能从底栏“重新设计所选 N 页”进入，原有勾选会带入窗口。

核对窗口里的当前风格、页码和数量，再点击“开始重新设计 N 页”。这时才会调用模型并产生费用；取消不会生成。使用已保存的讲稿、内容附件、风格和配色重新出图，成功后旧图存入历史，失败保留旧图。正在制作的页不能重复提交，可以选择其他空闲页。此操作重做 PPT 图片；动态 HTML 仍从独立入口转换。

### 控制画面文字密度

新页面会先提炼上屏文案，再单独复核，最后把文案和原始风格提示词一起交给图片模型。系统把内容分为核心表达、必要支撑和口播展开，提炼观众需要看见的重点，不逐句缩写原稿；开场、重复解释、口语衔接和长段展开优先留给口播，同时保留关键条件、数字、单位和范围。逐字稿与导出备注保持完整。

原稿引用校验允许空行、换行、中文间距和 Markdown 加粗、斜体差异；例如两句之间少一个空行，不再报“缺少原文依据”。原稿和引用记录保持原样，英文单词与数字之间有意义的分隔仍保留。实质文字、数字、标点、否定或条件变化，以及跳过正文拼接引用，仍会被拦截。完整语义由文案复核继续检查，已选主张的必保条件也继续保留。

在“上屏文案与风格 → 文字取舍与密度”查看讲稿字数、上屏字数、文字组数及取舍依据。字数含标点、不计空白；附件内部文字不计入，但模型会看图判断阅读负担。改稿后的旧方案提示重新设计，缺失记录不显示。可展开风格原文和实际出图提示词核对输入。

试做生成后展开左侧“查看上屏文案与生成依据”，可查看“本次提炼的上屏内容”；更详细的生成依据另行展开。对照时复制完整出图提示词，或分别复制风格和“内容部分（含辅助信息）”，可展开辅助依据。使用内容倾向或独立配色时，请复制完整提示词以包含全部要求。只复制主文案会漏掉语义边界，已有 ChatGPT 对话也可能带入上下文。复制取自当前记录，改稿后会提示；不调用模型，受限时可手动复制。

页面按任务设置密度提醒，超出时说明保留理由，不截断原稿或自动增加页数。字多时可填写“上屏文字调整”后重做；只调整画面或换风格时复用文案。确需拆页时，在逐字稿中手动选择分界。

校验保护已选上屏主张的必要条件，允许“五个/5个”等明确等值的整数数量写法。整条移至口播的非核心支撑信息不必强制上屏；仍在表达的结果不能只删限定词。必要条件无法匹配时自动恢复有依据的对应原句；仍不确定时保留有效候选或完整原稿继续制作，不追加文案修复请求。对比句允许多个主要文字块，层级、密度、重复和拆页建议只作提示，不再导致整页失败。恢复记录可在文字取舍中查看。

正常提炼与建议共两次内容请求；建议接口失败时沿用已提炼文字，必要信息的原句恢复在本地完成。换风格、重新构图及仅更新出图格式时复用有效文案；图片失败后重试复用有效方案。语义判断仍可能出错，密度复核不代表成图面积或阅读时间，成图仍需检查。

内容部分会保留各组文案的核心、支撑、限定或出处、标签角色，供图片模型建立阅读主次，角色说明本身不上屏。字号、位置和构图仍依照风格决定。旧图片保持原样，下次主动重新设计或续做时采用新格式；格式更新不代表排版质量已验收。

出图默认使用风格原文、上屏文案和简短的辅助表达边界。以已提炼的上屏文案为主，保持原意和表达程度。为丰富页面可增加少量、轻微、中性的辅助联想或解释，不能有指向性或引导性，不能让观众读出原文没有表达的意思、判断、倾向或结论，也不能补造事实。文字、图像和图形关系都遵守这一边界；有来源的摘录仅作次要辅助。成图仍需核对。

“实际发送的出图提示词”同时显示服务、请求模型和规格、实际尺寸及服务返回的信息。缺失信息不补造；若服务返回改写提示词也会显示。同文输入不保证构图一致，第三方接口的模型名称也不能证明后端与 ChatGPT 相同。

### 重做时加入图表或产品截图

打开要调整的页面，在“换一个思路，再设计一次”下面点击“添加图片”。可添加 1–4 张 PNG、JPG 或 WebP，每张最多 12 MB。缩略图可打开查看，也可移除后换图。

这些图片是内容材料，不是风格参考。可写明用途，如“第一张是操作界面，第二张是测试结果”，再点击“重新设计这页”。附件会交给文案提炼、复核和图片模型，结合风格原文参与整页构图，不默认贴缩略图、套卡片或固定放在一侧。照片可裁切无关外围、自然衔接背景；图表与界面用周围排版融合。保留主体身份、数据、文字和必要上下文，避免扭曲、遮挡或缩得过小。

成功后，附件随这一版页面保存；恢复历史版本也会恢复对应附件。生成失败时保留旧页面、本次方案和附件，可以继续重试。添加后尚未点击重做就离开，会提示附件选择尚未提交。

带附件出图要求配置的图片服务支持 Images Edits 多图输入；不支持时会明确报错，不会自动忽略附件改为纯文字出图。模型生成的图表数值、小字与产品细节仍应检查；接口传递的测试不代表真实模型能逐像素保留材料。

### 用报告核对内容完整性

在交付中心点击“查看制作报告”。报告显示四项：已提交原文字数、页面总数、页面备注字数、演说稿字数，并显示已有画面与待生成的页数。

统一按非空白字符计数：不计空格和换行，汉字、标点、数字及每个英文字母各算一个字符。原文包含提交时的 Markdown 标题，所以另列去标题后的正文，用正文与备注比较，避免把正常去标题误判为遗漏。

报告不仅比较字数，还逐字检查正文与当前已保存备注的顺序和内容。发现差异时显示第一处差异的上下文，能定位时可直接打开对应页面。改过备注也可能产生差异，需要结合原稿判断；报告不会自动改稿。

演说稿就是页面备注按顺序拼合，因此两者字数相同；完整性要以备注与原稿正文的核对结果为准。未拆页的已提交段落计入原文并提示，未提交草稿单独显示、不纳入基准。可展开逐页字数，或下载文字报告。报告不调用模型。

新图、试做和附件重绘统一请求 2560 × 1440（16:9）、high 质量。保存时使用高质量 JPG，质量参数 92，保留完整色彩采样以照顾小字和线条。图片等比限制在 2560×1440 内，不裁切，较小图片不放大；实际像素可在生成依据中核对。JPG 属于有损压缩，适用于屏幕演示，不等于无损原图。

新页面、试做和封面采用同一规则。风格参考图沿用 1600×1600 上限，内容附件保留实际尺寸；透明图片、抠图和蒙版仍保存为 PNG。已有本机原图与历史不批量改写，旧项目在导出 PPT、HTML 或保存单图时自动转换。已符合要求的 JPG 不重复压缩。

### 导出图片加备注的 PPT

在交付中心完成导出检查，再点击“下载 ZIP 交付包”会下载带版本号的 ZIP，其中有 PPTX 和独立逐字稿 Markdown。Markdown 按当前页序包含最新保存的完整讲稿，附页码，包含改稿、拆并页和插页结果；不使用提炼后的上屏文案，可作为新版本留存。两份文件来自同一份保存记录。服务不支持 ZIP 交付包时，按钮为“下载 PPTX”，直接下载 PPTX 文件。

导出的 `.pptx` 为 16:9，包含每页最新已保存的逐字稿备注。旧整图页面仍是完整图片；2026-10-20 起，本机新制作的页面是底图加可编辑文本框，并内嵌完整字体（需配置字体包）。整图使用适合屏幕播放的高质量 JPG；正文分层底图保留无损 PNG，避免二次压缩改变照片和文字周围的像素。

下载前确认：

- 所有段落已经拆页，所有页面都有完成的图片。
- 当前没有正在执行的生成任务。
- 逐字稿修改已经保存；未提交的输入草稿和未确认的结构调整不会导出。
- 如果提示画面待更新，先重做图片，或核对后下载当前图片配最新备注。
- 生成失败但保留现有画面时，检查窗口会列出失败页数量和页码，必须勾选“我已核对失败页，确认使用现有画面继续导出”才能继续。失败且无图仍需先补齐，勾选确认不能绕过缺图检查。

在交付中心点击“导出演说稿（Markdown）”，可以单独导出全部页面的最新完整正文，每页用 Markdown 二级标题标明页码。

“仅下载逐字稿”可以在图片尚未完成或正在生成时使用，但已提交段落必须先完成拆页；输入框中未保存的修改不包含在内。插页和改稿后，报告可能显示与最初提交原文的差异，最新版本以当前页面讲稿为准。

导出本身不调用模型。解压后请核对 PPTX 页序、备注及独立逐字稿。

### 把已有页面转换为动态 HTML

在演练中心展开“AI 口播与配音（可选）→ 已有版本与高级调整”，点击“查看旧版提取记录”。这是兼容旧图片的提取流程；新可编辑 PPT 通过制作台的“编辑文字与动效”制作。选择“整个项目”，或先关闭窗口、在工作台勾选多页，再选择“选中的页面”。一次支持 1–500 页，按原项目页序转换；所选范围如有未生成图片的页，会提示先补齐。已有演示可在窗口上方切换，也可新建另一份转换。

系统识别图片里的中英文文字及排版，把文字还原为 HTML，并分离边界明确的照片、插图和图形。文字后的高亮底色、线条等尽可能保留；复杂交叠、内部带文字或无法可靠分离的图形保留在背景中。转换结果独立保存，原图、讲稿、历史及“导出”保持不变。转换使用当时的图片快照，后来改稿或换图不会自动更新已有演示。

每页需要一次内容分析；复杂背景还可能调用一次图片编辑，服务必须支持带图片与 mask 的 Images Edits。费用由模型服务收取，线上图片修复计入图片额度。开始后可关闭窗口继续后台转换；失败可只重试这一页，或继续所有未完成页。停止保留完成的页面与已完成的识别；服务中断后也要主动点击继续，才会再调用模型。已发送的请求即使停止也可能计费。

转换完成后对照原图检查，点击预览中的文字选中图层，可修改内容、黑体或宋体、颜色、坐标、宽高、字重及出场动效。“按原图字形边界拟合”会匹配实际字形宽高；手动改字号自动关闭拟合。文字来自图片识别，特殊字形和复杂背景可能有误差；可导入拥有嵌入与分享授权的 WOFF2 原稿字体，最多 8 MB，再为相应文字层选择该字体。移动图层不会重新清理底图，底图清理范围仍按最初识别位置。

同一步骤的图文一起出现，步骤 0 用于开场，步骤 1、2 等用于随后论点；可调上浮、淡入、横向揭示、轻推近、线条展开或静止，以及延迟、时长。保存后标记该页已校对。校准、播放和下载不调用模型。未保存校准时会阻止切页与关闭，先保存或撤销；其他窗口已修改时会阻止覆盖并保留当前输入。

点击“播放本页”或“播放全部”，也可下载单个 HTML。图片和所用字体内嵌在文件中，断网也能播放；默认不含讲稿，勾选“HTML 包含演讲备注”后才附带备注。请核对图片与备注的分享范围。

播放时用方向键、空格或 Page Up/Down 翻页，Home/End 跳到首尾，手机可横向滑动。可切换整页播放与逐步讲述，也可设置 5、10、20、30 秒自动播放。F 全屏，R 重播，G 总览，N 备注，B 黑屏，P 自动播放或暂停；Esc 关闭浮层并暂停。离开浏览器标签页时自动暂停，系统设置减少动态效果时直接显示内容。

三张真实生成页面已在 macOS Chrome 中完成转换和视觉检查，包含九张照片的独立分层；模拟测试覆盖失败续做、停止、离线播放与原项目隔离。特殊字体无法仅凭图片保证完全一致；复杂背景、其他服务商和超大项目仍需先做少量页面验证。Windows/Linux 未完成本功能实机验收。此入口只转换本程序已生成页面，不导入外部 PPTX。

### 播放 PPT 并自动讲述

本机版打开演讲项目，在演练中心点击“开始演练”。使用前后翻页按钮或方向键播放已保存的页面，点击“全屏”进入正式放映，按 Esc 返回。播放器可以查看逐页讲稿，不需要再次生成图片。

开始演练读取已有画面，无需配置语音服务；没有页面时先返回制作台。保存版本读取失败会提示，并提供明确的“先放映项目画面”备用入口。

需要自动口播时，先在“设置”中找到“语音与声音 · MiniMax”，填写语音 API Key 并保存。默认接口为 `https://api.minimax.cn/v1`，模型为 `speech-2.8-hd`。这是独立的 MiniMax 原生语音连接，不沿用内容和图片模型的 Key；更换服务地址需要重新填写密钥。保存设置不会调用付费模型。

1. 在演练中心展开“AI 口播与配音（可选）”，选择 AI 口播并检查正文。已有口播播放器在其中的“已有版本与高级调整”；手动讲述直接点击“开始演练”，已有音频不要求重新配置服务。
2. 进入“1 · 口播文本”。点击“重新识别整场口播”，从原稿过滤主副标题、一级菜单、章节和停顿、暂停、环顾四周等动作提示。结果即时显示；用“查看口播页”逐页核对正文和过滤说明，可编辑，原稿不变。留空表示本页不口播。检查后点击“保存并继续 · 选择演讲表达”，成功保存后才进入下一步。
3. 在“2 · 演讲表达”选择 AI 编排或普通口播。AI 编排成功后检查方案，点击“使用方案 · 选择声音”；若不需要编排，点击“跳过 AI 编排 · 使用普通口播”，不额外调用内容分析模型。失败会说明已停止；有保存进度时可从中断处继续，也可选择普通口播，旧音频仍可播放。
4. 进入“3 · 声音制作”。选择播报男声、新闻女声、电台男主播、温柔学姐或自己创建的声音。设置整体及逐页情绪，必要时调整生成语速；普通口播试听本页开头最多 180 字；演绎口播试听本页第一个编排句段（最多 600 字）。试听会调用语音服务。点击后，按钮旁显示生成状态和等待秒数，完成后自动尝试播放。若自动播放受限，点击“播放已生成试听”；可在原位置暂停、继续和重播，这些播放操作不再调用语音模型。生成或读取失败会在按钮旁说明原因，读取重试使用已保存音频。等待过久可点击“停止等待”；切换工作区也会停止等待，不会在离开后突然播放。
5. 检查满意后点击“生成整场口播”。1–500 页需都有画面；系统逐页、逐段合成并保存。已完成声音保留，失败可继续未完成页面。生成期间仍能播放选中的旧版，新版完成后点击“使用新口播版本”。
6. 切换到“放映”，点击“开始口播”，长页片段依次播放，最后一个片段结束后翻页。随时暂停、继续、跳页或拖动当前片段进度；画面下方“播放倍速”可实时选择 0.75× 至 2×，换页继续保持，无需重新生成。无口播页停留 3 秒，倍速也影响这段停留；末页停止。切到其他标签页或窗口可能暂停，回到播放器可继续。

识别、保存文本和调整生成设置只修改制作草稿，不会让“开始口播”消失。原有声音继续播放已保存版本；需要听到新正文或新声音时再生成新版本。“播放倍速”即时改变播放速度，“生成语速”只影响下一份合成音频。
口播使用生成时的画面与讲稿快照。之后改稿、换图或调整页序时，点击“载入当前项目”，检查后重新生成；原有口播仍可从“已保存的口播”中选择。相同服务账号、模型、文本、音色、情绪与语速的音频会复用，重复播放不计模型费用。选择新声音或修改情绪后，先重新生成，才会按新设置播放。明确的临时服务拒绝先自动重试；超时或响应中断需核对结果后继续。退出 App 时会识别正在生成的语音任务。

播放器会显示“音频已生成 X/Y 页”、总时长和本页时长；“正在读取”表示音频已生成、浏览器正在加载。读取失败时先点击“重新读取音频”，只加载已保存文件，不重新合成或计费。2026-10-07 已修复 `.local` 目录中的音频读取问题。使用旧版时，等生成任务结束后更新并重启后台，再刷新页面；新版播放器会绕过更新期间缓存的读取错误，已有口播无需重新生成。

1002 表示请求频率超限，1008 表示余额不足。限流后等待 60、120、180 秒，明确的 HTTP 服务拥堵拒绝等待约 5、15、30 秒，均最多重试 3 次，并遵守更长的 Retry-After；超过 10 分钟则稍后手动继续。可随时停止，已完成音频保留；超时、余额、权限错误或已含音频/用量的返回不自动重试。

### 让逐字稿具备演讲表达

在“1 · 口播文本”检查并保存正文后，进入“2 · 演讲表达”，点击“AI 编排整场演讲”。这与本地“重新识别”不同：它会调用设置中的内容分析模型，先过滤常见非口播标记，先通读全文形成统一的表达思路，再按连续多页分批安排情绪、节奏、停顿与重点表达；不允许模型增删改写口播正文。支持 1–500 页、单次最多 30 万字符。

选择“自然演讲”“沉稳克制”或“生动有感染力”。“适度加入辅助表达”默认开启，模型只在适合的语境安排轻笑、笑声、轻叹或换气，每页最多一次；咳嗽、清嗓仅在原稿明确标注时采用。关闭后只编排情绪、停顿和强调。原稿中的动作提示作为理解依据，不会直接念出来。

批次按句数、正文长度与页数自动划分，每批最多 64 句、8000 正文字符、12 页，尽量保持单页完整，超长页再拆分。长稿超出一次阅读范围时分段通读后汇总，正文不会被截掉。编排显示全文规划阶段、当前批次、覆盖页码和已保存页数，可以停止；失败或中断保留上一份完成方案与已有音频，下次不会自动调用模型。完成后可展开“全场表达思路”，在“2 · 演讲表达”用“查看演绎页”逐页检查情绪、语速、句后额外停顿及原因，也可下载带提示的演绎稿。重点句通过整句稍慢、音量略增强来表现，暂不提供精确的词级重音。

表达编排会在每次模型结果通过检查后保存进度，包括长页面中已经编排的句子。遇到明确拥堵、暂无通道或限流时有限重试；最终失败、手动停止或重开 App 后，点击“继续编排 · 从中断处继续”，只请求剩余内容，已保存句子不会重新编排，已完成的全文规划也会复用；旧版逐页断点可继续使用，先补充全文规划再批量处理剩余句子。界面显示已完成页数和已保存句数。续编要求整场口播正文、原稿提示、标题、页序、表达设置、内容分析模型及接口一致；发生变化时需从头编排。“从头重新编排”会替换未完成进度并重新请求整场，已有完整方案和音频保留。重开 App 不自动发起付费请求；旧版失败时未保存的结果无法补回，迁移后的项目需重新编排。

点击“使用方案 · 选择声音”，进入“3 · 声音制作”试听，再生成整场。此时编排接管整体和逐页情绪，生成语速仍可整体调整。正文、页序或页面数量改变后，需重新编排；也可选择“跳过 AI 编排 · 使用普通口播”，继续按普通口播生成。旧音频始终保留，编排完成不会自动扣取语音生成额度。

含辅助声音的编排需要 MiniMax Speech 2.8 HD 或 Turbo；旧模型会提示更换模型，或关闭辅助表达重新编排。系统将方案转成模型支持的情绪参数和声音、停顿标记，编排标签不作为中文正文朗读。音频片段间的额外停顿可暂停、继续，App 实时倍速也作用于停顿；导出静态和动态 HTML 后保留。项目包携带演绎方案，换电脑可继续使用；相同表达片段复用缓存。

批量编排已通过模拟模型与浏览器验证，尚未实测真实模型下的长篇速度和听感。原有演绎流程通过模拟模型、浏览器交互和真实模型短稿联调：121 字示例正文成功生成 5 段音频，MiniMax Speech 2.8 HD 接受了轻笑、停顿与重点句控制。实际语气、辅助声音自然度及长篇连贯性仍需用户试听后确认。情绪安排是模型建议，不能保证每句都符合演讲者本人的习惯。

### 在数字人工作室准备形象和试播

在 App 中打开“设置 → 实验室”，进入“数字人工作室”。数字人目前作为实验功能保留，生成效果与等待时间仍需优化，建议先做短试播。已有头像、声音和视频记录保留，供项目按需使用。

1. 展开“连接 HeyGen”，保存独立 API Key，再测试连接。连接成功只表示密钥有效，真实试播仍需要 API 账号余额和可用头像。
2. 点击“添加数字人”，填写名称并上传正面清晰、嘴部无遮挡的 JPEG、PNG 或 WebP，最大 8 MB。选择原始照片、职业照、卡通或古装分类。上传保存只写入本机，不在这一步发送到 HeyGen。
3. 在“语音与声音 · MiniMax”保存语音服务配置；本人声音需先在这里采集。回到工作室选择“MiniMax 声音”，点击“保存数字人”或“保存形象与声音”。列表与 AI 口播共用，包含播音员和已采集声音。已有头像优先沿用最近口播使用的 MiniMax 声音；无法确认声音时需自行选择，不会替换成 HeyGen 平台声音。可把常用形象设为默认数字人。
4. 在“文字试播”输入 1–300 字，点击“生成试播视频”。确认文字交给 MiniMax 使用所选声音合成音频，再把头像和音频交给 HeyGen 同步嘴型，按两项服务规则计费后开始。完成的视频直接显示在这里，可播放检查声音、嘴型和形象；输入的试播草稿会在本机保留。
5. 要制作其他风格，展开“创建其他风格形象”，选择职业照、卡通或古装，确认图片服务费用后生成。需要图片服务支持带照片的 Images Edits 接口；完成后另存一个数字人，原头像保留。也可以直接上传已经准备好的风格图片。风格分类本身不会把照片自动变成卡通或古装。

1. 打开项目的“演练中心”，展开“实验室 · 数字人讲解”，选择“数字人讲解”，选择工作室里已经保存好头像和声音的数字人。
2. 选择一个有逐页讲稿的页面，点击“生成本页讲解”。确认窗口显示形象、声音、讲稿及 API 计费提示；确认后自动用所选 MiniMax 声音合成讲稿音频，再同步嘴型，不需要先到另一处制作口播。满意后可点击“生成整场讲解”。
3. 在生成记录查看进度。完成后点击“播放讲解”，在项目画面上播放有声数字人视频；可连续播放、切换片段和调整倍速。
4. “显示位置与其他方式”中可选择四角位置、尺寸。需要保留已经制作好的 AI 口播声音时，改选“沿用已有 AI 口播”，选择当前画面、讲稿匹配的已完成版本，再生成。直接传原口播音频，不重新选择声音或合成；旧方式使用原演讲播放器。

任务会保留素材和讲稿快照。相同头像、MiniMax 账号、模型、声音和文字的已完成素材会优先复用，试播与项目也可以复用；音频在视频提交前保存，下载重试不会重新合成。更改页面或讲稿后旧视频会保留，但不能作为当前版本播放。项目内不提供临时上传头像，修改形象与声音请回到数字人工作室。

网络中断、下载失败或重新打开 App 后，点击任务的“继续查询或下载”。已生成音频直接复用，已提交的视频只查询和下载，尚未生成的片段可能使用 MiniMax 或 HeyGen 额度。未知提交超过安全重试时限时会被拦截，应先到 HeyGen 核对任务。不要另建相同内容绕过未确认提交。

“停止后续生成”阻止后续上传和提交，但已经被 HeyGen 接受的任务仍可能完成并计费。App 退出时会提示正在进行的任务。

### 在 Mac App 中复制页面图片

在稿件中打开页面或放大图片，把鼠标放在图片上，右键选择“复制图片”，再到微信、Word、Keynote 等应用粘贴。复制的是图片本身。文字输入框也提供剪切、复制、粘贴菜单；不要在图片之外的空白区域右键。

在数字人工作室的连接区域依次点击“保存 HeyGen 设置”和“测试 HeyGen 连接”，连接成功仅表示密钥有效。Key 写入工作区私有 `presenter-settings.json`，留空保存保留已有密钥，也可单独移除。测试不上传头像、音频或生成视频。 HeyGen 明确报告 API 额度不足时，会显示钱包提示并保留已生成音频；这类已失败视频不能继续查询恢复，补充额度后需重新确认新任务。

数字人配置、头像及已生成视频保存在本机工作区，项目迁移包、PPTX 与离线 HTML 暂不包含这部分内容。备份时退出 App 并复制整个 `workspace` 文件夹；安装或升级只替换 App，不删除此文件夹。配置保存、跨项目隔离、错误口播拦截、生成接口的离线模拟、失败恢复、视频复用、播放器同步及 Mac 图片剪贴板已通过本机测试；2026-10-09 已用保存的本人照片和 MiniMax 复刻声音成功生成约 2.64 秒视频，确认原音频传给 HeyGen、没有平台配音选项，视频音轨沿用 MiniMax 原音频，查询下载和本机保存通过。旧版 HeyGen 平台配音视频保留并标明来源。不同风格的真实口型效果及各图片服务的风格生成未逐项付费验证，请先做短试播。

### 采集自己的声音

在“设置 → 语音与声音”中展开“采集演讲者的声音”。安静环境下自然讲述 30–60 秒；可以点击“开始录音”，也可以上传已有的 WAV、MP3 或 M4A。音频需在 10 秒至 5 分钟之间、20 MB 以内；直接录音最多 2 分钟，结束后可以先在本机试听，过短录音会提示重新录制。

Mac App 首次录音需要系统麦克风授权。若拒绝过，请在系统设置的“隐私与安全性 → 麦克风”允许 AutoPPT，随后重新打开 App；也可以直接上传录音。录音只在主动点击开始时开启，结束录音或离开设置时停止。

填写声音名称，勾选本人声音或已取得演讲者授权的确认项，再点击“创建我的声音”。此时录音才上传到已配置的语音供应商，原始录音不写入本机项目。创建成功后选择新声音，先试听，再生成口播。声音复刻保留说话人的音色，情绪还需结合讲稿和逐页设置试听调整，不保证一次就达到演讲者本人表现。

MiniMax 声音复刻要求先完成供应商平台实名认证；复刻、首次使用及语音生成可能分别计费，请查看自己的供应商账号。创建后 7 天内至少正式调用一次，避免未使用音色被供应商清理。复刻音色保存在供应商账号中，更换 API Key 可能需要重新采集；已经生成的本机音频仍能播放。

静态与动态 HTML 可包含口播；PPTX 暂不包含音频，也不导入外部 PPTX。2026-10-06 已用真实 MiniMax 服务生成四个默认音色及全部情绪选项的中文短样，并在 Chrome 验证真实音频自动翻页、暂停和缓存复用。听感与长篇表现仍需人工试听；声音复刻相似度、Mac 麦克风系统弹窗、其他电脑和 Windows/Linux 尚未验收。模拟测试另覆盖失败续做、停止和恢复。

### 用量与账单

在 Mac App 左侧打开“用量与账单”，查看今天、本月或全部时间的 AI 消耗。可以按项目和调用类型筛选，查看每次调用的模型、用量、预估费用及计价依据，再导出筛选后的 CSV 账单。

第一次使用先点“模型单价”，按供应商控制台或合同填写人民币单价。未知价格请留空，确认免费才填 0。内容分析按输入、输出和缓存 Token 计价，缓存已包含在输入中，不重复累计。图片可按张或统一 Token 单价估算，尺寸和质量分别设置。语音优先采用接口返回的计费字符数；未返回时按发送字符估算并明确标注。声音复刻按成功次数做预算估算，实际扣费时点以供应商规则为准。复杂多模态和阶梯价格、折扣、汇率不会自动同步。

页面生成、风格分析与试做、动态页面识别与图层修复、演绎编排、口播试听、整场合成、声音复刻的实际 AI 请求都会记录；重试单独留痕。播放已有音频、实时变速、规则过滤、保存文本和普通导出不调用 AI。复用相同的已保存语音显示零费用。

点击“补充预算”，填写金额与备注即可增加本机记账额度。此操作不会付款，也不会给供应商充值。可勾选以积分显示，¥1 对应 1,000 积分；积分不是 Token。全局剩余预算扣除所有项目、所有时间的已知预估费用，不受当前筛选影响。低于 20% 或用完时在账单页提醒，生成仍可继续。

缺少单价或用量、失败及中断的请求可能显示“待核对”，不计入已知费用合计，不能视为免费。实际余额和结算金额以供应商账单为准。点击明细“查看”可见供应商请求编号和当时单价；后续修改单价不会重算旧记录。

从新版首次启用开始记账，不补造以前的 Token 或费用。账本保存在当前工作区 SQLite，重启后保留，不保存密钥、提示词或语音正文。项目迁移包不包含工作区预算与账单，导入不会重复扣记费用。Mac App、浏览器本机版和不同电脑目前各自记账；需要留档时导出 CSV。跨机器共享余额与在线支付尚未实现，托管账号仍沿用原有图片额度。

### 更新 Git 下载的版本

先等待生成结束或点击“停止”，再在运行 `npm start` 的终端按 Ctrl+C。然后在项目目录逐行执行：

```sh
git pull --ff-only

```

最后刷新浏览器。如果 Git 提示本地修改或分支冲突，先保留现有文件并联系维护者处理，不要强制重置。后台启动入口发现旧发布仍在运行时会提示先停止旧服务，不会自动中断生成任务。

### 停止 Mac 后台启动的服务

如果通过“启动 AutoPPT.command”启动，关闭浏览器或终端都不会停止服务。可以在任务结束后重启电脑，再更新代码；也可以在终端先执行：

```sh
lsof -nP -iTCP:4317 -sTCP:LISTEN
```

记下输出中的 PID，在“活动监视器”找到同一个 PID，查看该进程的“打开的文件和端口”。确认其中包含当前 AutoPPT 文件夹后，只退出这个进程；如果无法确认，先联系维护者。不要批量结束所有 Node 进程。使用自定义端口时，请把命令中的 4317 换成实际端口。

### 备份与换电脑

迁移单个项目时，在交付中心点击“导出项目源文件 → 下载项目迁移包”，下载 `.autoppt.zip`。另一台电脑安装新版 AutoPPT 后，在项目首页点击“导入项目包”，选择这个文件。每次导入创建新项目，刷新列表并进入该项目的概览，不覆盖已有内容。PPTX、Markdown 和 HTML 是放映或交付文件；项目源文件才用于恢复编辑，不能相互替代。

迁移包包含保存的草稿、讲稿、图片与历史、内容附件、项目使用的风格与版本、动画图层和字体、已生成语音、声音标识、口播编辑文本及演绎编排方案。模型密钥与日志不导出，生成任务不自动恢复；继续生成时需在新电脑配置模型，复刻声音需使用有权限的 MiniMax 账号。已完成的图片与音频不需要重新生成。

项目包中的不透明图片使用高质量 JPG，透明素材保留 PNG；为保留动态图层坐标和附件细节，迁移素材保持实际尺寸。历史页面、素材与口播的对应关系一并更新，声音文件不重新压缩。本机原图不改写；如果需要无损归档原始图片，应另行保留本机工作区。重复导出已符合规则的 JPG 不会反复压缩。

先等项目任务结束再导出，并确认草稿已保存。最多 500 页、960 MB 素材、32 MB 记录，单个素材最多 64 MB，导入 ZIP 最多 1 GB。包损坏、素材缺失或版本不支持时会提示，失败不会覆盖已有项目。本机隔离工作区往返迁移已验证，其他电脑及 Windows/Linux 尚未实测。

项目数据位于代码目录中的隐藏文件夹 `.local`：

- `autoppt.sqlite`：项目、风格、原文、页面方案、历史、任务及动态演示图层和导入字体。
- `assets/`：参考图、内容附件、生成图片及动态演示背景和分离图层。
- `settings.json`：内容与图片模型连接配置及密钥。
- `speech-settings.json`：语音服务配置与密钥；`speech-audio/`：已生成的口播音频，语音演示和音色标识保存在 `autoppt.sqlite`。
- `server.log`：后台启动方式的日志；前台方式直接在终端显示日志。

**先停止服务，再复制整个 `.local` 文件夹作为备份。** Mac 的 Finder 可按 `Command+Shift+.` 显示隐藏文件。备份包含业务内容和密钥，应保存在可信位置。

换电脑或使用新版 ZIP 时，先保留旧目录，在新目录完成安装和构建；新目录尚未启动、也没有个人数据时，再把旧 `.local` 整体复制过去并启动。如果目标目录已有项目，请先分别备份并联系维护者，不要直接覆盖。

## 6 常见问题

### 找不到 node 或出现 node sqlite 错误

安装或升级到 Node.js 24 LTS，再重新打开终端。检查 `node -v`，确认当前终端确实使用新版本。单独出现 SQLite 的 ExperimentalWarning 不等于启动失败，以程序启动地址和页面是否正常为准。

### 找不到 package json 或 dist

确认终端位于含有 `package.json` 的项目目录。依次运行 `npm ci`、`npm run build`，构建成功后再 `npm start`。不要通过双击 `dist/index.html` 打开程序。

### 安装依赖失败

先检查网络和 npm 下载源是否可用，并保留完整错误信息。新系统需要重新运行 `npm ci`，不要复用另一台电脑的依赖目录。遇到 Sharp 等原生模块安装失败时，检查 Node 版本及安装包是否符合电脑芯片架构。

本版已将 PPTX 依赖链中的 `image-size` 固定到 2.0.4，修复旧版本的解析告警，相关导出测试通过。本次 `npm audit` 未报告漏洞；这不是长期安全保证。以后出现新的依赖提示时请交给维护者处理，不要直接执行 `npm audit fix --force` 更换导出依赖版本。

### 页面打不开或提示端口被占用

先查看终端是否仍在运行，并确认地址为 `http://127.0.0.1:4317`。只有本机能访问，不能把这个地址发给其他电脑直接使用。检查是否已有 AutoPPT 或其他程序占用端口；不要重复启动多份服务来尝试解决。

确需更换端口时，先停止旧服务。在同一个终端执行下面对应命令，然后打开 `http://127.0.0.1:4318`：

Mac：`PORT=4318 npm start`

Windows 命令提示符：

```bat
set PORT=4318
npm start
```

### 模型连接或出图失败

401/403 查密钥与权限，404 查模型与接口，429 查额度或限流。修复后继续，无需删除数据目录。

本机内容和图片请求遇到明确拥堵、503 无可用通道或限流拒绝，自动等待约 5、15、30 秒再试；TLS 握手中断仅内容请求重试，等待 2、5、10 秒。最多重试 3 次，可停止；遵守 Retry-After，超过 10 分钟则稍后继续。需修正配置或结果不明（普通 5xx、超时、中断、已有结果/用量）时不盲目重发。各次用量分别记录，未知费用不记零。

内容分析每批最多 8 页，校验通过即保存。失败或重启后点“继续未完成任务”，复用原稿未变且版本有效的分析；旧版未保存的结果无法补回。分析进度不等于出图进度。


## 7 邀请制线上使用

邀请制网页版的内容与图片模型由后台主服务加载，管理员账号不会自动改用 Mac App 或本机 `.local` 的连接配置。若账号状态显示模型已配置，但提交讲稿提示未就绪，应先排查主服务与工作进程是否运行不同版本；只构建前端或刷新网页不会更新正在运行的主服务。新版会把缺失或无效的内部就绪状态明确提示为“网页后台版本尚未同步”。维护时先确认无正在进行的任务、备份数据，再保留原有环境变量、密钥文件和数据目录，正常停止并重新启动主服务；无需重新填写或删除模型 Key。

网页版默认提供四款精品风格：克制儿童摄影杂志风、先锋酸性色彩编辑风、日系现代建筑提案风、当代 Neo-Swiss。风格库默认打开“精品风格”；自己创建或导入的风格在“我的风格”。其他旧内置风格暂不提供给新项目选择，已有项目仍可继续沿用原风格，不改写提示词、图片或历史。Mac App 的原风格保留。

如果管理员给你的是正式网站地址和邀请码，无需进行前面的本机安装，也无需填写模型 Key。打开网站先查看产品介绍，点击“邀请注册”，填写邀请码、账号、至少 6 位的密码并确认；可以使用纯数字，最长 128 个字符。管理员发来的注册链接会自动填入邀请码。邀请码有效期 7 天且只能使用一次；已注册后直接用账号密码登录。修改密码、管理员重置密码与初始管理员密码使用相同要求，已有账号密码不变。

新邀请码为 6 位数字，开头的 0 也需要填写；旧的长邀请码在原有效期内仍可粘贴使用。管理员在“网站管理”点击“创建 6 位邀请码”，复制数字或邀请链接交给同事。每个 IP 每 15 分钟最多尝试注册 5 次，全站每小时最多 30 次；提示操作频繁时请稍后重试。注册后可在“用户与额度”给对应账号增加图片张数。

每个人有独立的演讲项目、风格版本、附件与图片，默认风格已经内置。从讲稿开始，先看一页效果，满意后再制作其余页面。内容保存在服务器的个人工作区，不能把它与本机 `.local` 当作同一份数据。

首页点击“用我的讲稿开始”，在同一页粘贴讲稿、选择精品风格，再点“生成第一张画面”。不用先建空项目；演讲名称自动填写，可展开修改。没有讲稿可“用示例体验”，示例文字可直接替换。输入中显示“暂存于此浏览器”，点击“只保存讲稿”才保存到服务器且不调用模型；退出账号会清理浏览器临时缓存。

生成时先完整保存并拆分讲稿，只制作第一页，成功使用 1 张图片额度。结果会放大展示；点“画面文字少一点”“重点更突出”或“换一种构图”可预填要求，确认后才重新生成，旧版本保留，讲稿与风格原文不改。满意后点“生成其余页面”，核对张数与额度后继续，已有试做图保留。刷新和重复提交不会自动重复创建演讲或调用模型。

项目导航依次为“概览 → 画面与讲稿 → 放映与配音 → 下载与导出”，“概览”汇总项目进度。重新打开演讲仍直接进入“画面与讲稿”；首页卡片显示可继续的实际状态。全部完成后可直接下载 PPT 或放映；需要声音时再进入“放映与配音”。“下载与导出”集中其他交付方式。继续添加讲稿时仍可选择直接制作整段。

长项目可在“画面与讲稿”搜索标题、讲稿、上屏文字或原页码；搜索作用于当前范围，可切换“全部页面”。每组显示 24 页，跨组选择保留，提示“另有 N 页已选”。分组和搜索不改变项目内容，“下载与导出”仍导出完整项目。

继续制作或补齐缺图时，确认窗口会检查可用额度。额度只够一部分时，可以选择“先生成前 N 页”，其余未生成页保留，补充后再继续。零额度时仍可保存草稿、编辑、查看和导出。打开窗口和提交前都会刷新额度；其他任务可能继续占用，最终以服务器实际预留为准。

网页版支持图片演讲制作、普通放映和 MiniMax 语音合成。在项目“放映与配音”展开“AI 口播与配音（可选）”，选择“AI 口播”，声音、语速和当前页正文集中显示；上方常驻操作栏集中显示试播进度、停止与失败续做。声音生成好后，原按钮变为“播放试播”，点击即可开始；整场完成后同处显示“播放整场”，不必滚动找结果。播放器固定显示音频和翻页操作，正文按需展开；暂停、继续和重播不再合成。缺画面或正文的页会提前提示，历史录音默认收起。“更多选项”可调整表达、试播长度、沿用已有口播，也可手动保存本场选择。小屏幕优先显示口播表单，再查看画面预览。语音记录可播放，整场完成后可导出含口播的离线静态 HTML；原逐字稿、图片和旧音频保留。“开始演练”仍可直接使用。语音 Key 与默认声音由管理员部署配置，本场选项在“放映与配音”保存。自动情感编排已开放；数字人、声音复刻和动态演示制作暂不开放。语音不扣图片张数，但使用管理员 MiniMax 预算，并受每日字符及请求上限限制；播放、保存正文和缓存复用不重新合成。详见[网页版语音演练](网页版语音演练.md)。

本机已有项目不会自动上传或删除。需要迁移时，在 App 导出 `.autoppt.zip` 项目源文件，再从网页项目首页导入，每次创建独立副本。包内已有口播与动态素材会保留并随源文件再次导出；完整数字人视频和配置暂不包含在项目迁移包中。

## 分层演讲试用：改字与出场动效

新构建的本机工作台在「制作台」提供 **编辑文字与动效**。没有可编辑版本时，选择“底图 + 可编辑文字（试用）”，先确认制作页范围，再启动生成；它会调用内容和图片服务并产生费用。分层结果单独保存，不替换原项目的整页图片或文字。已安装的旧 App 不会自动出现这个入口；托管账号版尚未开放。

1. 选择页面，再点击预览中的文字或右侧“图层”。修改正文、字体、字号、字重、颜色或字距。文字超出框时先调整内容或版式，再保存；程序不会偷偷缩小字。
2. 在“播放方式”选择自然出场、逐步讲述或整页静态。“位置与出场顺序”可调整文字框及语义步骤。
3. 点击“保存并标记已校对”，再播放本页或全部。需要改字时，在独立播放器点击“暂停改字”，回到编辑器保存后，播放器更新当前页并保持讲述步骤。自行点击继续播放。
4. 已保存修改可用“撤销上次保存”恢复，最多保留 20 次。改字、保存、撤销和播放不调用模型。改上屏文字不会自动改逐字稿或重新合成口播，音画内容需自行核对。
5. 下载 HTML 可离线播放动效。下载可编辑 PPTX 会导出当前已保存文字并嵌入完整字体，需先由维护者配置字体包；暂不包含原生 PPTX 动画和口播音频。外部字体导入仍用于旧图片识别流程，分层 PPTX 目前只支持内置黑体与宋体的指定字重。

2026-10-20 起，分层页直接点画面文字输入，不再通过侧边文本框填写。选中文字后，拖动移动手柄调整位置，拖动右下角手柄调整范围（不会缩小字号）；手柄也支持方向键和 Shift+方向键。用“撤销一步”恢复最近一次文字或位置修改；“撤销修改”放弃本页全部未保存修改。中文输入过程中保留光标，粘贴只接收纯文字，超出文本范围时先调整再保存。

右侧切换“页面动效”，选择叙事镜头、金句聚焦、章节开场、阅读节奏、两侧对话或层层推进，点击画面上方“试播动效”立即查看。试播播放整页；正式播放仍按“自然出场 / 逐步讲述 / 整页静态”执行。选“原有编排”继续使用逐层效果、时长和延迟。动效不改变最终排版，系统减少动态效果时改为短淡入。六种编排来自原先 24 种表达方式的部分图文用法，完整图表、证据摘取等尚未接入，见[范围与操作](分层演讲-画布编辑与动效编排.md)。

本次用五种已有风格样例在新工作区验证，原项目未修改；新图片生成流程只完成模拟接口测试，尚未验证真实生成的五种风格质量。新 PPTX 已核对 5 页、21 个可编辑文本框及完整字体结构，原生 PowerPoint、Windows、WPS 等打开效果仍待验收。完整说明见[分层演讲制作与编辑试用](分层演讲-制作与编辑试用.md)。

## 首次生成直接可编辑（2026-10-20）

更新后的本机工作台第一次完成时就显示底图与独立正文。内部先按原风格完成整页设计，再按原图识别文字、局部去字并校准文字位置，不另做一套简化版式。进度会显示「按原风格生成完整画面」「按原画面识别文字位置与字形」「局部去除正文，保留原图与装饰」「画面已生成，整理可选校对建议」。

照片、插画、装饰和艺术字继续留在底图中；完整原图也保存下来，可在编辑器勾选「原图对照」。底图和文字可用就交付；局部补丁、残字或校对服务异常仅显示“已生成 · 待校对”，展开“可优化项”查看，不影响编辑和播放。旧版被画面检查拦住的已存底图会直接恢复。需要继续优化时可点“局部优化底图”，仅修复原图去字区域，文字、动效和原图不变，旧底图留在历史版本；修复失败仍保留可用画面。文字识别、检查与局部修复可能额外产生费用；继续时沿用已经保存的原画面。特殊字形和复杂背景无法保证完全自动还原，生成后请看一遍原图对照。

在制作台点击「编辑文字与动效」，默认打开「当前 PPT」。直接点画面里的字修改，或切换「页面动效」调整；保存后回到制作台、进入演练、导出都会使用这份结果。已完成的页面可以先编辑；未完成页返回制作台继续原任务。文字修改不改口播稿，历史版本可恢复。

普通 PPTX 和 ZIP 交付包会保留新页面的文本框，并使用维护者配置的完整字体包；没有字体包会提示配置，HTML 仍可导出。PPTX 暂不包含网页动效。历史整图页、旧分层试用记录不会自动迁移或覆盖。已有页只有在你主动选择重新设计时，才生成新的分层版本；旧版本仍可找回。托管版及未更新的 Mac App 维持原行为。

修正验证：同一张门店原图拆出 9 个正文层，保留门店、人物、小狗与荧光色块，文字修复遮罩外像素差异为 0。另在隔离工作区测试真实新页生成。具体测试范围和限制见[原画面保留与正文分层](原画面保留与正文分层.md)，本轮没有批量转换已有项目，也没有重做五风格和跨电脑 PowerPoint 验收。

2026-10-20 续接验证：两页分别恢复 5 / 8 个可编辑正文层，真实浏览器改字、保存、重开、撤销与试播通过。已有原图、旧底图和讲稿保留；测试改字已撤回。大标题不再用极端负字距强行压缩，内置字形在原区域自然排布。质量意见保留在“可优化项”，不再导致整页失败。PPTX 导出实际含 13 个文本框和 2 个完整字体部件，尚未新增跨电脑 PowerPoint/WPS 验收。
