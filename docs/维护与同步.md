# 维护与同步

## 日常执行

每次完成独立功能后，维护者按 `AGENTS.md` 自动更新相关说明、验证、提交并推送。代码改动至少执行相关检查；跨流程改动执行 `npm run check`，涉及交互时补充浏览器验证。文档更新检查命令、下载入口和 Word 排版。

风格修订按[风格开放性与成图自检](风格自检规范.md)检查共同特征与创作变量，用冻结文案的多类样本，从排版、留白、视觉层次、色彩搭配和原创性逐页及跨页复核。保留失败样本和未验证范围，不用单张成功图代替整套验收。此流程由维护者执行，不是日常出图中的自动审查功能。

Codex 的本聊天另有每小时检查一次的自动任务，用于补推送已完成的提交、核对说明是否遗漏，并验证下载入口。没有变化时保持安静；发现同步结果或需要处理的失败时反馈。它依赖配置所在的 Codex 主机可运行并联网，不是 GitHub 托管的定时任务。

定期检查只处理完成状态与归属明确的工作，遇到其他任务正在编辑的文件时保留现场。不要把“测试通过”单独当作“所有工作已经完成”的证据。代码发布不会自动重启用户的本地服务；运行中的图片生成继续执行。

## 更新使用说明

内容来源为 `docs/同事安装与使用说明.md`，Word 输出为 `docs/AutoPPT-安装与使用说明.docx`。维护脚本仅用于生成文档，不参与应用安装和启动，普通用户无需安装 Python。

Codex 中使用 workspace dependencies 返回的 Python 与 `python-docx`。其他维护环境需要 Python 3 与 `python-docx==1.2.0`。在项目根目录执行以下命令；脚本通过自身位置定位仓库，也支持从其他目录用完整路径调用：

```sh
python3 scripts/build-guide.py
python3 scripts/build-guide.py --check
```

`--check` 在内存中重新生成并比较 DOCX 的内部内容，不改写文件；两版不一致时以非零状态退出。生成时如果内容相同，也不会重写 Word 文件，避免仅因 ZIP 时间戳改变而产生无意义提交。

脚本支持当前说明使用的标题、普通段落、列表、代码块、三列表格、加粗、行内代码和网页链接。复杂 Markdown 需要先扩展脚本；不要在未验证输出的情况下加入新格式。

Word 更新后，使用 documents 技能提供的 `render_docx.py` 渲染并检查每一页，重点检查中文字体、命令换行、表格和分页。确认内容一致、排版正常后，将 Markdown、Word 及相关代码放在同一次提交中。

## 发布检查

1. 确认当前分支、远端状态、变更归属以及相关验证结果。
2. 按明确文件路径暂存，检查差异，创建提交并推送到目标分支。
3. 用远端查询确认提交已到达 GitHub；不能仅凭本地提交成功就报告发布完成。
4. 从仓库首页检查在线说明和下载入口。Word 下载的文件应与仓库中的文件一致。

GitHub 仓库：[vactioncn/AUTOPPT](https://github.com/vactioncn/AUTOPPT)。自动任务可以在 Codex 中调整或停用，具体授权和数据保护边界以仓库 `AGENTS.md` 为准。

## 维护产品介绍页

`site/intro/content.mjs` 是功能说明与快速指南的共同内容源；`index.template.html`、`intro.css`、`intro.js` 管理静态页面和交互。功能变化时核对内容源，运行 `npm run build` 自动生成 `dist/intro/index.html` 与 `guide.md`，不提交 `dist/` 构建结果。

UI 变化时先构建，再运行 `npm run intro:screenshots`。脚本只使用临时数据库、演示文字和已内置封面，自动采集真实界面，不调用模型、不读取 `.local/`，结束后删除演示数据库。提交 `public/intro/screenshots/` 中的截图和清单，再重新构建。浏览器默认使用 macOS 的 Google Chrome；其他环境设置 `CHROMIUM_EXECUTABLE`。

验证执行 `npm run check`，再执行 `INTRO_BROWSER_TEST=1 node --test tests/intro.test.mjs`；浏览器检查桌面与手机布局、功能按顺序连续展开、图片放大、指南下载和链接。测试使用独立静态服务器，不操作用户项目。

若手动部署 `dist/` 中的介绍页，保持 `intro/`、`style-covers/` 和 `favicon.svg` 的相对目录结构，将网站入口指向 `intro/`。下方 OSS 专用脚本则会独立构建、调整资源路径，让介绍页直接成为指定子目录的首页。公网介绍页不提供项目制作或保存能力，用户仍需安装本机程序并连接模型。页面未连接统计服务、外部字体或模型 API。

## 发布介绍页到 OSS

项目级技能位于 `.agents/skills/oss-web-deploy/`，由技术部原始静态站点技能适配而来。原版会同步整个当前目录并删除远端多余文件，不适用于包含私人数据与服务端的 AutoPPT；应使用本项目版本。

### 本机配置

使用阿里云官方 [ossutil 安装说明](https://www.alibabacloud.com/help/zh/oss/developer-reference/ossutil-overview/)。本次在 macOS ARM64 安装并验证了 `ossutil 2.4.0`，二进制位于 `~/.local/bin/ossutil`，安装包通过官方 SHA256 校验。其他机器需按其系统安装；无需为运行 AutoPPT 安装这个工具，只有发布维护者需要。

发布脚本优先使用 `~/.local/bin/ossutil`，否则从 PATH 查找；可用 `OSSUTIL_BIN` 指定其他路径。授权优先使用仓库外的 `~/.config/oss-web-deploy/ossutilconfig`，否则使用已有 `~/.ossutilconfig`；可用 `OSSUTIL_CONFIG_FILE` 指定其他文件。不要覆盖其他项目已在使用的配置。

首次配置专用授权文件时，确保目录与文件只允许本人访问，再用 `ossutil config --config-file` 交互填写技术部提供的信息：region 为 `cn-hangzhou`，endpoint 为 `https://oss-cn-hangzhou.aliyuncs.com`。AccessKey ID 与 Secret 从技术部取得，不写入命令参数、源码、聊天输出或文档；本次长期授权无需 STS Token。Mac 或 Linux 示例：

```sh
umask 077
mkdir -p ~/.config/oss-web-deploy
~/.local/bin/ossutil config --config-file ~/.config/oss-web-deploy/ossutilconfig
chmod 600 ~/.config/oss-web-deploy/ossutilconfig
```

本机授权配置及原始含密钥的资料不提交 Git。Windows 的配置路径需通过 `OSSUTIL_CONFIG_FILE` 明确指定；Windows 和 Linux 发布尚未实机验证。

### 发布与验证

先明确一个由 1–63 位小写字母、数字、短横线或下划线组成的目录名，首位必须是字母或数字；不能使用桶根目录、多级路径或网址。`autoppt` 是示例，`skill-web` 是同事测试目录，不是默认值。先查看目标已有内容，确认没有其他站点，再执行：

```sh
npm run deploy:intro -- autoppt --dry-run
npm run deploy:intro -- autoppt
```

`scripts/deploy-intro.mjs` 通过 `AUTOPPT_INTRO_OUTPUT_DIR` 将介绍页生成到全新临时目录，只复制页面实际引用的截图、内置封面和图标；同时修正资源与安装入口，使 `https://show.turing.art/<目录>/` 可直接访问。当前共 14 个文件，不包含源码、`.local/`、`.env`、依赖、模型密钥或生成素材。无需运行 `npm run build`，不改变正在使用的 `dist/`，不重启服务或调用模型。

预演使用 `ossutil sync --dry-run`，只显示计划；正式命令使用 `ossutil sync` 更新同名文件，不使用 `--delete`，不删除远端多余内容。上传统一设置 `Cache-Control: no-cache`。上传后通过 HTTPS 检查目录首页、每个资源的状态与 SHA256 内容，以及 HTML 响应类型；CDN 缓存或域名配置异常会使验证失败，此时应报告“已上传，公网验证未通过”，不能声称部署成功，也不要删除远端目录。临时文件在命令结束后清理。

相关验证为 `INTRO_BROWSER_TEST=1 node --test tests/deploy-intro.test.mjs`，覆盖发布范围、资源相对路径、非法目录、预演、失败退出、临时文件清理、公网内容核对及电脑和手机布局。Mac ARM64 上已验证本机授权、云端读取与真实预演；这不代表已经执行正式公网发布。
