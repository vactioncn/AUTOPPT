V1 证明了分步播放和模板切换可行，但视觉完成度未获用户认可。V2 保留原内容与 25 步，重新设计九页构图，重点补齐主视觉、图文比例、图形细节与步骤之间的连续变化。

- Neo-Swiss 使用大字号、黑白反差、局部黄绿重点和满高摄影；建筑提案使用轻字重、细线、横向或纵向影像视窗及更疏朗的空间比例。封面、假设场景和收束页有各自的构图规则。
- 关系图逐层建立连接；流程线随步骤向前推进；四个经营维度与章节目录聚焦当前项。动效服务于讲述顺序，遵循系统的减少动态效果设置。
- 本机示例增加一张 AI 概念影棚图，并在画面与看图弹窗标注「AI 视觉示意 · 非真实门店」。它用于视觉表达，不是原稿事实或真实门店照片。
- 「开始演讲」收起上方工具栏，底部导航在悬停或键盘聚焦时出现；Esc 退出。点击图片可放大查看，手机逐项播放会滚动到当前重点。

本机 V1 保留原路径，V2 在其 `v2/` 子目录；构建脚本不会批量覆盖已有产物。新模板仍需适配字号、构图、媒体处理、图形和动效，并逐页检查；当前没有实现任意模板提示词直接生成同等质量的网页成片。

## 使用

页面顶部选择模板；下一步先推进当前页，全部完成后再换页。支持左右方向键、PageUp/PageDown、Home/End、B 黑屏、F 切换演讲模式及 Esc 返回。目录可以跳转，讲稿弹窗打开时不会误推进底下的页面。刷新恢复模板与讲述位置。

大屏使用 1920×1080 设计画布等比适配。小于 760px 的演讲区域切换为可纵向阅读的版式，控制条保持可用；「手机预览」可在电脑窗口查看这种重排。全屏依赖浏览器支持与用户手势，不影响普通窗口播放。

V2 本机九页产物约 1.64 MB；公开两页无图示例约 1.29 MB。文字、脚本、样式、图片、字体及字体许可均内嵌于单个 HTML，播放时无外部字体、图片、模型请求。本次未制作音频、视频或原生可编辑 PPTX。

## 复现与代码边界

在仓库根目录生成公开的两页示例：

```sh
node scripts/build-web-deck-demo.mjs site/web-deck-lab/example.storyboard.json .local/web-deck-example/index.html
python3 -m http.server 8766 --bind 127.0.0.1 --directory .local/web-deck-example
```

然后打开 `http://127.0.0.1:8766/`。端口占用时换一个端口，不停止其他服务。

- `storyboard.json` 管理内容、来源页码、表达类型和讲述步骤，不包含模板视觉。
- `site/web-deck-lab/model.mjs` 校验来源及结构，建立可反向移动的步骤表。
- `site/web-deck-lab/design.mjs` 渲染九种内容构图与可选图片；文本经过转义。
- `site/web-deck-lab/deck.js` 统一管理播放状态、导航、图片查看、演讲模式和讲稿。
- `site/web-deck-lab/deck.css` 保存两套模板的适配规则与窄屏重排，不改写文案和步骤。
- `scripts/build-web-deck-demo.mjs` 将分镜和资源打包为一个 HTML。它是确定性渲染器，不是自动理解文档的模型接口。

可选图片由分镜显式指定，路径相对于分镜文件所在目录。只接收该目录内的 PNG、JPEG、WebP，每张不超过 10 MB；绝对路径、越界路径和指向外部的符号链接会被拒绝。构建后图片变成内嵌数据，保留说明与替代文本：

```json
{
  "assets": {
    "studio": {
      "file": "media/studio.jpg",
      "alt": "概念影棚",
      "caption": "AI 视觉示意 · 非真实门店"
    }
  }
}
```

需要主视觉的封面、情境或收束页设置 `"hero": "studio"`。不提供图片仍可生成。

后续接入正式模式还需实现：上传文档提取、依据语义选择表现方式、从用户模板生成可检验的视觉规则、真实媒体能力与失败恢复。不得把本次手工分镜的成功当作任意文档自动生成质量已经验证。
