# 风格开放性与成图自检

本规范用于审查和修订一个已有风格，避免每发现一种重复画面就追加一条禁令。审查对象包括风格原文、实际出图请求和生成结果。它是维护流程，实际成图的五维审查并非自动功能。当前风格可单独开启“按内容构思”：在冻结文案后比较表达方向并做构思自检，最终方案公开展示并加入完整出图提示词。风格原文仍完整传递，内容提炼与风格分离。

## 优先核对用户原始提示词

用户已经验证有效的原始提示词是修改基准。先找回原文、核对实际请求是否逐字传递，再定位具体冲突。只有确认存在限制且用户要求放开时，才做可追踪的局部删除；不能借自检把原文重写为新的审美体系，也不能为解决重复而自动开启额外构思模型。默认直接出图；原文允许纯排版不等于必须减少图像。

2026-10-01 开放性自检中曾把减少重复与语义风险优先于画面表现力，F/G 轮的“定稿”结论已被用户否定，不能作为批准的视觉基准。A、B、C 轮包含可保留的设计品质，不能以整轮有缺陷为由整体舍弃。

## 先区分共同特征与创作变量

共同特征说明作品为什么属于同一套视觉语言，例如字体气质、色彩关系、编辑秩序、强调方式和材质表现。它们应允许不同程度的使用，不要求每一页同时出现全部元素。

创作变量包括主体、表现媒介、构图、视角、图文比例、标题位置、疏密与明暗。逐条检查规则是否把某张参考图的坐标或题材误写为共同特征。也要检查反向固化：不能因为某种结构曾重复，就永久禁止它，或要求全部页面改为另一种结构。

语义忠实以上屏文案的原意与表达程度为准。辅助联想或解释可以少量、轻微、中性地丰富页面，但不能有指向性或引导性，不能让观众读出原文没有表达的意思、判断、倾向或结论。图像与图形关系同样适用；来源摘录与创作联想不混为事实。没有具体物体的抽象内容仍可以有图形，不应一概退回纯文字。

## 用同一套内容做成组对照

选取章节、开放提问、故事、数据、概念关系和真实内容附件等不同样本，优先使用实际工作中的材料。一个故事页或一张漂亮封面不能代表整套风格通过。

先独立提炼、复核并冻结上屏文案与语义辅助，再对比风格版本。保留原稿、旧规则、旧图片、实际请求与返回规格。样本中不填写为弥补风格缺陷而特制的单页反馈，不把旧图作为隐藏参考，也不挑选成功图片而隐去同轮失败样本。

每轮既检查单页，也把所有样本放在一起比较。识别重复时同时看骨架与视觉主题；颜色不同、左右镜像、物件替换不一定构成新的设计。反过来，同类内容合理共享结构也不应为了追求差异而强行修改。

需要针对成图做页级精修时，另记一轮并公开具体反馈，保留没有额外反馈的原样本。精修图可以作为交付结果，但不能用它证明默认流程已自动解决该问题；把可通用的检查经验纳入构思自检后，仍需在后续成图中验证执行情况。

## 五个审查维度

| 维度 | 检查成图中的证据 | 明显需要修订的情况 |
| --- | --- | --- |
| 排版 | 阅读路径、中文断行、对齐关系、图文与内容结构的对应 | 信息顺序混乱，重要条件断开，长期套用一侧文字一侧配景 |
| 留白 | 空白如何分组与聚焦，疏密节奏，主体是否有足够阅读尺度 | 为留白缩小重要材料，为填空添加无意义元素，局部拥挤或重心失衡 |
| 视觉层次 | 第一阅读点、支撑内容可读性、装饰与主体的权重 | 所有文字同样醒目，大字吞掉信息空间，小字无法承担必要解释 |
| 色彩搭配 | 明暗对比、强调色分工、材料原色与整页的关系 | 每页同样涂亮一整行，焦点竞争，对比不足，调色破坏材料含义 |
| 原创性 | 表达是否贴合本页，媒介与主体关系是否有实质变化 | 不同主题反复出现同一场景，只有换色换字，隐喻擅自增加语义 |

文字与材料忠实是另行检查的必要条件，不能被五维平均分抵消。检查错字、漏字、数值、单位、标签、疑问以及额外口号；对附件核对主体与关键细节。没有用真实图表测试过，就不能把照片融合成功视为图表保真已通过。模型绘制的数据图即使数值正确，也应检查长度、面积与比例；准确数字对照和精确统计图是不同的验收事项。

## 迭代与停止依据

将每个问题记录为“图片区域、可见现象、影响、可能关联的规则”。先修订造成多页问题的共同规则，删除冲突和重复要求，避免无限追加针对具体物件的禁令。改动应留在所审查风格内；其他风格不继承它的审美要求。

使用五维审查形成下一版，再用冻结的同一组内容复测。检查改善是否带来新的退化，例如消除了重复场景，却把所有内容变成同一种大字页。模型审稿可作为辅助，最终必须直接看图确认；模型高分、接口成功和自动测试通过都不是视觉验收的替代。

停止的依据是本轮代表性样本中没有未处理的明显缺陷、共同风格成立且内容之间有合理差异，而不是宣称设计已经没有任何提升空间。可继续改进的偏好与未验证范围需明确记录。若某项仍有明显问题，就保留未通过状态，不用总体“效果不错”掩盖它。

完成后保存审查结论、全量样本与规则差异，并核对所选风格外的数据未变。只有最终选定的规则写回正式风格；历史图片保留，重新生成才使用新规则。

## 当开放规则仍未改善成图

先确认实际请求确实采用候选规则，再比较只改规则与明确单页构思的对照。如果通用原则反复落回同一结构，不再无限增加例外；可为当前风格开启按内容构思，让内容模型把原则落实成可执行的画面。该机制不提供固定版式名单，不改写内容或风格，附近页面只提供构图描述而非新的语义依据。它能减少设计意图重复，但没有自动看图验证模型是否执行，不能代替成图审查。开启后对照 GPT 应复制完整提示词，不能将“有额外构图方案”的结果冒充只用风格与文案得到的结果。
