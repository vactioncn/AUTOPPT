────────────────
一、最重要的视觉原则
────────────────

核心原则：

【信息负责讲清楚，参数化景观负责制造感受。】

页面不能因为追求视觉效果，
让发光线条、波浪或山体抢走真正的信息。

每页生成前，
必须先判断：

这一页最重要的意思是什么？

它是：

强观点
趋势
变化
增长
过程
路径
系统关系
数据
挑战
转折
能力
章节
未来愿景
还是案例？

然后再决定：

是否需要使用“参数化数据景观”。

不是每一页都必须出现波浪。

如果内容适合纯文字，
可以只有黑底、白字和极少量线条。

如果内容适合数据，
让数据成为主角。

如果内容适合关系，
使用极简关系图。

如果内容适合情绪或战略表达，
再让数据景观成为重要视觉主角。

【视觉必须服从内容。】

────────────────
二、核心视觉资产：参数化数据地形
────────────────

本风格最重要的识别元素是：

由成百上千条极细线条形成的：

流体
波浪
山脉
地形
能量场
数据流
拓扑曲面
连续曲线
参数化曲面

这些线条应该具有：

连续性
方向感
纵深
层次
节奏
流动性

视觉上介于：

真实山脉
+
数字地形
+
流体模拟
+
数学曲面

之间。

不要画成普通折线图。

不要画成随机波纹。

它应该像：

“数据正在形成一片地形。”

或者：

“信息正在空间中流动。”

────────────────
三、线条语言
────────────────

参数化线条必须：

非常细
数量多
连续
精确
有透视
有层次

线条不能：

粗糙
杂乱
过粗
像霓虹灯管
像电线
像蜘蛛网

主要线条可以使用：

青蓝
冰蓝
深蓝
少量白色

局部高能区域可以出现：

橙色
火焰橙
暖红
琥珀色

形成：

冷色主体
+
暖色峰值

的关系。

暖色不能平均分布。

应该集中在：

峰顶
转折
关键节点
能量集中区域
视觉焦点

形成明确重点。

────────────────
四、颜色系统
────────────────

整个页面以：

纯黑
近黑
石墨黑
深蓝黑

为主要背景。

黑色必须占据绝大部分面积。

核心颜色系统：

黑
+
深蓝
+
青蓝
+
冰蓝
+
少量橙红

整体色彩比例建议：

70%–85% 黑色或深色

10%–20% 蓝青色

5%以内暖橙色

暖色是一种稀缺资源。

不要让整个页面同时蓝、紫、红、橙、绿全部出现。

不要彩虹渐变。

不要糖果色。

────────────────
五、蓝橙关系
────────────────

本风格一个非常重要的气质来源是：

【冷蓝 × 暖橙】

蓝色代表：

数据
理性
稳定
技术
结构
冷静

橙色代表：

能量
突破
异常
峰值
机会
变化

因此橙色应只出现在：

关键峰值
重要节点
视觉高点
变化点

不要把橙色当普通装饰色使用。

这种色彩关系应该让观众自然感觉到：

“这里发生了变化。”

但不要变成复杂 3D 建模展示。

我们要的是：

【二维演示页面中的三维空间感。】

────────────────
七、构图逻辑
────────────────

不要默认所有参数化地形都放在页面底部。

根据内容可以采用：

从远方进入

也允许：

完全没有参数化图形。

页面之间必须有明显变化。

不要整套 PPT 全部变成：

黑底
+
底下一条蓝橙波浪
+
中间一句白字。

这是最容易出现的模板化问题。

────────────────
十三、数据可视化
────────────────

数据图表应保持极简。

推荐：

主要使用：

例如：

关键年份 → 橙色

关键峰值 → 橙红

不要使用多色分类图。

────────────────
十四、参数化图形与数据结合
────────────────

如果内容存在真实数据，
可以让数据与参数化景观发生关系。

例如：

峰值对应曲面最高点

阶段变化对应不同山脊

增长曲线沿着数据地形上升

多个业务指标形成不同波峰

信息流形成连续曲面

但必须强调：

真实数据的准确性优先。

不能为了视觉效果扭曲数据。

如果只是视觉隐喻，
不要伪装成真实统计图。

────────────────

────────────────

摄影师工作场景
+
数字地形

但照片必须有明确内容作用。

不要普通图库感。

────────────────
十八、页面类型
────────────────

封面页：

可以使用一幅巨大参数化数据景观。

标题悬浮在黑色空间中。

文字极少。

形成强烈第一印象。

章节页：

一个章节编号
+
一句标题
+
一条横贯页面的流动曲线

保持极简。

观点页：

一句强判断
+
大片黑色留白
+
少量数据线

数据页：

真实图表成为主角。

参数化景观退到背景。

案例页：

照片或业务内容成为主角。

参数化线条只作为辅助。

流程页：

一条连续流线
+
关键节点

但不要画成复杂系统图。

────────────────
十九、黑色留白
────────────────

黑色不是“需要填满的背景”。

黑色本身就是留白。

允许：

半个页面什么都没有。

甚至允许：

80% 是纯黑。

只有：

一句白字
+
一条蓝色曲线。

这种极度克制，
反而能制造力量。

不要因为背景黑，
就认为必须加入大量发光元素。

────────────────
二十、页面节奏
────────────────

整套 PPT 应有明显的视觉节奏。

例如：

强视觉页
→
极简文字页
→
数据页
→
照片页
→
参数化大景观
→
黑底留白页

不要连续十页都是炫酷波浪。

参数化视觉是一种：

【关键视觉资源】

不是每页默认背景。

越克制，
关键页面越有冲击力。

────────────────
二十三、生成前内部判断
────────────────

生成每一页前，请先在内部完成以下判断：

1. 这一页真正的核心信息是什么？

2. 参数化数据景观是否真的有帮助？

3. 如果删除波浪，这页还能成立吗？

4. 主视觉应该是：
文字、数据、关系、照片还是景观？

5. 这一页需要冷蓝还是需要暖橙？

6. 暖橙是否只出现在真正重要的位置？

7. 页面是不是已经有太多发光元素？

8. 是否连续多页都出现相同的波浪结构？

9. 页面是在帮助观众理解，
还是单纯追求“炫酷科技感”？

如果偏向后者，
立即减少至少 30% 的视觉元素。

────────────────
二十四、最终效果标准
────────────────

最终作品应该像：

一个顶级生成式视觉工作室，
与一家国际科技公司的品牌设计团队共同完成的旗舰演示。

它应该：

第一眼：

深邃、强烈、未来。

第二眼：

信息极其清楚。

第三眼：

可以看到大量精密的线条、空间和信息设计细节。

它不是赛博朋克。

不是科技 UI。

不是普通蓝色企业 PPT。

而是一套：

【以黑色空间为画布，以数据地形为视觉语言，以信息秩序为骨架的高端未来演示系统。】

统一的是：

黑色基底
冷蓝线性地形
局部橙色峰值
参数化曲面
巨大与微小的尺度反差
高对比白色字体
空间纵深
克制的信息设计
高级数字艺术气质

而不是固定的“波浪模板”。

请基于当前实际内容，
自由决定每页最合理的构图。

不要复制参考图中的具体页面。

只继承这套视觉系统背后的设计 DNA。
