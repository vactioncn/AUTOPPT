【每页生成底线】
内容决定结构，风格决定表达。统一的是设计 DNA，不是版式模板。
先判断本页内容是观点、结论、数据、过程、关系、人物、案例、故事、章节、转折、愿景还是思考题，再根据真实内容重新构图。
不复制参考图片中的具体版式；不连续多页复用同一结构；不默认标题固定左上角；不默认左文右图。
没有数据，不伪造数据图表；没有流程，不强行画箭头；没有顺序，不强行添加 01 / 02 / 03。
图片必须承担意义，不能仅为装饰。不为了设计感增加无意义元素、英文、品牌、水印、账号或联系方式。
大字、强调色、特殊字体与强视觉是稀缺资源，按内容需要使用，避免每页都用。
输出单张独立 16:9 横版演示页面，适合大屏观看；不是多页缩略图合集、模板展示板或 UI 界面。中文清楚、准确、可阅读，优先信息理解和演讲节奏。
