# 动态 HTML 演示

## 范围与数据边界

此功能将项目内已有成图另存为可离线播放的 HTML：清理后的背景、真实 HTML 文字、透明或矩形的图像图层。转换不调用旧页面设计流程，不改变 `project` 记录、原图片、备注、历史或 PPTX 导出。独立 `motion` 记录保存原项目版本、来源页 ID、图像与备注快照、识别结果、逐页状态及校准版本；素材使用新的 UUID 文件名。按项目原页序接受 1–500 页，未成图页不静默跳过。

## 转换流程

1. 冻结页面快照。旧网页场景先转为一张独立图片，不修改原场景。
2. 使用现有内容模型做视觉识别，输出像素坐标、逐行文字、字体类别、字重、颜色、讲述步骤及可动元素。严格验证边界、数量和样式，文字保持普通文本，不允许模型提供可执行 HTML/CSS/JS。
3. 文字按字形与抗锯齿像素建立清理区域；简单背景按邻近背景的色彩与变化补齐，保护高亮色块。复杂背景及元素移除使用图片编辑与 mask，仅采纳清理区域内的结果。清理区域外始终使用原图像素。
4. 视觉元素从原图裁出，支持轮廓透明裁切、边缘连通的纯色去底和完整矩形照片。与文字或已选对象重叠的候选留作背景，不冒充可独立运动的元素。
5. 每页完成即持久化，错误属于该页，其余页继续。重试复用识别检查点并跳过成品；中断不自动重放模型请求。每个工作区只执行一项动态转换，不占用旧任务表。桌面退出、换模型、项目删除及线上空闲回收识别新任务。

## 字体与播放

文字是 HTML 元素，具有独立字号、字重、颜色、字距、坐标、行距和内容。固定原始像素画布等比缩放，按所用字形加载内嵌的 Noto Sans SC / Noto Serif SC 字体子集。拟合开启时通过浏览器字形度量匹配识别的墨迹框；手动字号模式按 CSS 字号显示。自定义 WOFF2（最多 8 MB）随演示内嵌，需使用者拥有授权。图片不能证明字体身份，定制字形不承诺逐像素一致。

播放与下载共用纯浏览器播放器，无 CDN、运行时依赖或网络请求。默认不导出备注，不额外内嵌原图；校对预览才含原图对照。字体许可证随 HTML 保留。支持逐步讲述、整页顺序出现、双向翻页、重播、全屏、总览、自动播放、触摸滑动与减少动态效果。离开标签页暂停自动播放。编辑器预览也不调用模型，保存使用版本校验防止覆盖其他窗口的更改。

[Fontsource 字体与分段加载说明](https://fontsource.org/docs/getting-started/install)；[图片编辑与 mask 接口说明](https://developers.openai.com/api/docs/guides/image-generation)。当前模型适配沿用项目已配置的兼容接口，供应商仍需支持实际图片编辑参数。

## 检查与限制

执行 `npm run check`；浏览器专项检查为 `MOTION_BROWSER_TEST=1 node --test tests/motion.test.mjs`，默认使用 macOS 的 Chrome，其他路径通过 `CHROMIUM_EXECUTABLE` 指定。测试使用临时 SQLite、模拟模型和测试图片，覆盖原数据不变、原页序、非法布局拒绝、导出转义、未授权素材替换拒绝、背景保护、透明抠图、失败重试、取消与重启恢复、离线字体、翻页、步骤、响应式画布和保存。预览不依赖正式用户服务。

2026-10-05 的真实样张为“超级品控”标题页、“每天照片太多”内容页及“除了看单张质量，还看整组”内容页，源图片复制到隔离目录；使用配置好的视觉与图片模型，保留中英文文字，标题高亮与照片阵列参与检查；第三页的九张雪山照片按轮廓分离并分步入场，重叠的反射与阴影保留在背景。测试中发现并修复了矩形清理误删高亮底色、画布缩放偏移两个问题。真实字体和背景修复仍需人眼对照，校对提示不会宣称已自动通过视觉验收。

尚未验证 Windows/Linux 实机、所有供应商、超大项目的内存与导出体积、所有字体与复杂照片背景。长项目内嵌图像会形成较大 HTML，建议先抽选代表页检查。手动移动文字不会重做背景，复杂纹理的修复可能留痕或保留照片底座/阴影；不提供自动重新设计、外部 PPTX 导入或可编辑 PPTX。默认成图与 PPT 导出继续使用原有实现。
