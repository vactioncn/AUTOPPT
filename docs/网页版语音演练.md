# 网页版 MiniMax 语音演练

2026-10-11：根据新增需求，邀请制网页版恢复语音合成。原第一版把语音与数字人一起关闭；本次单独开放普通口播，数字人、声音复刻、AI 演绎编排和动态制作仍不开放。App、模型配置与本机项目保持独立。

## 使用流程

1. 在已有画面的项目进入“演练中心”，选择“AI 口播”。
2. 选择本场声音、表达和语速，检查每页口播正文。正文修改只保存口播版本，原逐字稿不变。“保存本场选择”保存声音及本场选项，不修改后台连接。
3. 点击“先试当前页”，默认试开头最多 100 字，也可试完整一页。确认范围后开始生成，进度与失败原因显示在记录中；生成完成后点击播放。
4. 满意后“生成整场”，也可展开整场范围选择部分页面。已匹配的完整片段复用，短片段与完整正文不一致时单独生成。失败可继续未完成部分；刷新或重启不会自动发起收费调用。
5. 通过“已有版本与高级调整 → 已有口播 / 播放与导出”打开口播播放器；播放完成自动翻页。整场口播可导出含音频的离线静态 HTML。交付导出也可选择“静态 HTML · 可含口播”。浏览器拦截声音时，点击一次播放。

也可选择“自己讲”并打开“普通放映”，不会触发语音合成。服务未连接时明确提示联系管理员，已经生成的音频仍可播放。

## 管理员接入

图片/文本 Key 不替代 MiniMax Key。管理员提供原生接口地址、speech 系列模型、MiniMax Key；已有自定义音色需属于同一个 MiniMax 账号。供应商计费与音色权限以实际账号为准。

在 `deploy/secrets/speech_key` 写入 Key，沿用其他 secret 的权限规则：目录仅维护者可访问，文件允许容器 UID 1000 只读。勿提交 Git。`deploy/.env` 可配置：

```dotenv
AUTOPPT_SPEECH_BASE_URL=https://api.minimax.cn/v1
AUTOPPT_SPEECH_MODEL=speech-2.8-hd
AUTOPPT_SPEECH_VOICE_ID=当前MiniMax账号的已有音色编号
AUTOPPT_SPEECH_VOICE_NAME=默认演讲声音
AUTOPPT_DAILY_SPEECH_CHARS=500000
AUTOPPT_USER_DAILY_SPEECH_CHARS=50000
```

声音编号留空使用播报男声；填写自定义编号后，该声音作为该站点管理员提供的默认声音，受邀用户可选择。只有获得使用授权的声音应配置为站点默认。个人项目包带来的声音编号仍需当前服务账号有权限。

正常等待任务结束，备份持久卷，再配置、构建与启动：

```sh
export AUTOPPT_BUILD_GIT_SHA=$(git rev-parse HEAD)
docker compose --env-file deploy/.env -f deploy/compose.yaml -f deploy/compose.speech.yaml config --quiet
docker compose --env-file deploy/.env -f deploy/compose.yaml -f deploy/compose.speech.yaml up -d --build
```

后续更新继续加载两个文件。原 `compose.yaml` 仍可单独使用，不要求新 secret 文件；此时不会开放新语音合成。

直接启动时支持 `AUTOPPT_SPEECH_API_KEY_FILE`，或仅测试使用 `AUTOPPT_SPEECH_API_KEY`。Key 只由登录网关持有；每人工作进程使用内部令牌，不收到供应商 Key，网页只读取连接状态、模型和声音列表。工作区内旧的语音设置文件不能覆盖服务器配置，普通用户不能修改服务连接。

## 费用与数据

语音不扣图片张数；使用管理员 MiniMax 预算。全站统一调度语音请求，受模型并发/每日请求数及每日字符上限约束。字符上限按发送文字统计，缓存和播放不消耗，已发出失败和重试请求仍累计。字符上限不是供应商费用账单，当前“账号与额度”里的逐笔账本仍为图片记录。

音频保存于持久卷每账号的 `users/<账号 ID>/speech-audio/`，正文、演练选择和口播版本保存在该账号数据库。音频、项目、导出都需登录并按账号隔离。语音素材纳入整个数据卷备份与项目包迁移。安装 App、连接本地网页版不会移动或删掉原本机配置。

## 验证范围

自动化使用模拟 MiniMax 返回的有效 MP3 验证个人音色参数、短试播到整场、缓存、重复提交恢复、失败提示、字符上限、图片余额不变、音频范围读取、账号隔离、离线 HTML 与重启后音频保留。网页交互使用隔离试验工作区，不调用收费供应商。正式部署仍需用实际账号先做短试听，确认音色权限、听感与供应商费用；数字人和长篇演讲效果不属于本次验收。
