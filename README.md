# AutoPPT

本机演讲图片工作台，提供免登录的 Mac App，模型由使用者自行配置。逐段追加逐字稿，按观点拆分，依据自己的风格规范设计并生成图片。支持导出整页图片加逐页讲稿备注的 PPTX。

## 下载与使用说明

- **[在线阅读安装与使用说明](https://github.com/vactioncn/AUTOPPT/blob/main/docs/同事安装与使用说明.md)**：查看安装、模型配置、首次测试和常见问题。
- **[下载最新完整代码 ZIP](https://github.com/vactioncn/AUTOPPT/archive/refs/heads/main.zip)**：解压后按说明安装运行。

## Mac App

Mac 用户可直接打开 `AutoPPT.app`，无需登录、部署服务器或另装 Node。首次进入“模型设置”配置自己的两套模型接口与 Key；生成费用由所选服务商收取，App 不设账号额度。

本机内容和图片请求遇到明确的服务拥堵、503 暂无可用通道或限流拒绝时，先按约 5、15、30 秒间隔最多自动重试 3 次；遵守更长的 Retry-After，超过 10 分钟则等待用户稍后继续。内容请求的明确上游 TLS 握手中断仍按 2、5、10 秒重试。后台显示恢复原因、等待时间和次数，恢复期间不标失败，停止任务会取消等待。密钥、余额、权限、参数错误，以及普通 5xx、超时、响应中断或已含结果/用量的返回不会盲目重发。每次实际调用分别记入用量，未知费用不按零处理。连接测试只验证接口可达，不保证上游生成稳定。

批量制作的内容关系分析每批最多 8 页，通过校验后立即保存；失败或重启后点击“继续未完成任务”，复用同一任务中原稿未变且分析版本有效的结果，只补分析缺失部分。旧版失败时尚未保存的分析无法补回；这是分析进度，不代表图片已经生成。

制作进度按本次实际需要制作的页面计数，另列已保存并跳过的页数。当前页标注原项目页码；已生成、失败与待处理分别显示。可恢复的临时故障先自动等待并重试，无需反复点击继续；恢复成功后正常制作，重试耗尽或需人工处理时才加入失败明细，其余页面继续。任务结束后点击继续仅补做未完成部分。“已处理”包括成功和失败，不代表全部成图。内容分析进度与图片数量分开显示。

开发者在 Mac 上运行 `npm ci`、`npx install-electron`，再执行 `npm run build:mac`。构建在全新临时目录完成，验证 App 与压缩包后只保留 `release/AutoPPT-mac-arm64.zip`（架构跟随构建电脑）；临时 App 自动清理，避免启动列表重复。`AUTOPPT_MAC_OUTPUT_DIR` 可指定 ZIP 输出目录，构建不修改已安装程序。解压后将 App 放到固定的 `/Applications/AutoPPT.app`；升级前等任务结束并退出旧版，备份数据，再替换同名程序。确认新版本可打开、项目完整后，将解压目录中多余的 App 移到废纸篓，勿用卸载工具清理关联数据。当前提供 Apple Silicon 内部构建；Intel Mac 尚未实机验证，Developer ID 签名与 Apple 公证尚未配置，其他电脑可能受到 macOS 安全检查限制。

App 的项目、风格与模型配置独立保存在 `~/Library/Application Support/AutoPPT/workspace/`，通过菜单“AutoPPT → 打开数据文件夹”查看。安装包不包含开发者的项目或 Key。关闭窗口会保留后台任务；通过菜单退出时，有任务会提醒。重开 App 会保留本机项目和草稿。

设置按“模型服务 / 语音与声音 / 实验室”分类，每次只显示一类。已配置的模型和 MiniMax 连接默认收起，展开“修改连接配置 / 修改 MiniMax 连接”后编辑并明确保存；语音栏先选择默认声音，需要时再展开录音采集。切换分类保留未保存输入，并停止离开面板时的录音和试听；不会自动保存、重置密钥或生成素材。链接可直接打开 `#settings/speech` 或 `#settings/labs`。新项目默认“自己讲”；已保存的数字人演练选择和旧项目数字人配置继续保留。数字人标为实验功能，不代表生成质量已验证。

Mac App 的“设置 → 实验室 → 数字人工作室”统一管理头像、风格、MiniMax 声音和文字试播。连接 HeyGen 和 MiniMax 后，添加或选择头像，保存 MiniMax 播音员或已采集的本人声音，输入 1–300 字点击“生成试播视频”。文字先由 MiniMax 使用所选声音合成音频，头像和音频再交给 HeyGen 同步嘴型，不使用 HeyGen 平台配音。可上传原始照片、职业照、卡通或古装头像，也可用支持 Images Edits 的图片服务生成风格变体，原头像保留。风格分类不会自动修改照片。Key 只保存在本机私有设置文件，不回显、不随项目导出；连接测试仅查询账号，真实试播按两项服务规则计费。浏览器预览与 App 使用独立工作区。

项目的“演练中心 → 实验室 · 数字人讲解”直接选择已保存的数字人，点击“生成本页讲解”或“生成整场讲解”，确认上传及费用后，自动用所选 MiniMax 声音合成逐页讲稿音频，再同步嘴型。不要求先到另一处制作 AI 口播，也不在项目里临时添加头像。“播放讲解”在项目画面上播放有声数字人视频，可连续播放、切换片段和倍速。显示位置、大小及“沿用已有 AI 口播”集中在折叠选项内；已有口播直接传原音频，不重新配音，保留原播放器。生成前保存任务编号，重试使用同一编号；已完成且素材相同的片段可跨试播与项目复用。音频在视频提交前保存，下载重试不会再次合成声音。下载失败或 App 重开后可继续查询原任务，未知提交超过安全重试时限会被拦截，停止只阻止后续提交。 HeyGen 明确报告 API 额度不足时，会显示钱包提示并保留已生成音频；这类已失败视频不能继续查询恢复，补充额度后需重新确认新任务。

头像、默认选择、项目配置、音频和数字人视频保存在本机素材、SQLite、`speech-audio/` 和 `presenter-video/`，不修改讲稿、页面、已有口播或图片历史。迁移包、PPTX 和离线 HTML 暂不包含数字人内容，请备份整个工作区。2026-10-09 使用本人照片及 MiniMax 复刻声音成功生成约 2.64 秒视频，已核对音色编号、原音频上传、HeyGen 未接收平台配音选项，以及视频音轨确实沿用 MiniMax 音频；查询、下载、音视频校验和本机保存通过。旧版 HeyGen 配音试播保留并标注来源。二进制下载类型与 AAC 编码起始延迟造成的误拒绝已修复。卡通、职业照、古装上传与界面流程已验证；各图片服务生成风格及不同风格数字人的真实效果未逐项付费验证，建议先做短试播。


Mac App 支持在稿件的页面图片、放大图片等位置右键选择“复制图片”，复制实际图片像素，可粘贴到微信、Word、Keynote 等支持图片粘贴的应用。Mac 原生剪贴板验证通过；其他系统未实机验证。

原浏览器版 `.local/` 工作区仍保留；App 不会自动导入、覆盖它，也不依赖 4317 或 4318 服务。需要沿用旧项目时仍可打开原浏览器版。可通过交付中心“导出项目源文件”与首页“导入项目包”在工作区之间迁移单个项目，导入时新建副本。

项目首页的删除入口收为卡片右上角的垃圾桶图标，鼠标移到卡片上或键盘聚焦时显示；触屏保持显示并扩大点击区域。点击后仍需确认，取消会保留项目。

风格库只管理可跨项目使用的视觉风格。详情默认显示已保存状态，提示词、分析记录、版本和动态页码说明收在“高级设置”；主题在新建项目时填写，行业、受众与场景在项目的“内容倾向与配色 → 保存设置”中保存。视觉调整草稿自动保存在本机，点击“重新提炼风格”成功后才应用到风格；没有参考图时不展示无法应用的调整表单。已有风格、项目与历史不会因升级被改写。

风格库中打开“试做一页”，桌面左侧查看成图、保存和试做记录，右侧按“试做内容 / 调整效果”切换操作，生成按钮保持可见。窄窗口先显示内容编辑，再查看预览。默认已填一段示例，“换一段示例”可选择通用表达、儿童摄影或运动与赛事，不需要已有演讲。内容倾向与配色、生成依据默认收起；切换操作保留草稿，试做讲稿、倾向与配色自动保存在本机草稿中，仅用于当前试做，不保存为正式风格。原始规则与版本在“试做内容 → 高级设置”中查看。每次生成一页，普通试做不再用作封面。展开“风格封面”后点击“生成统一封面”，固定使用“让想法被看见 / 把内容讲清楚，让表达有自己的风格。”两句文案，按已保存的风格直接生成一张图，成功后自动更新封面。文案不再提炼，不带入试做讲稿、反馈、临时配色或内容倾向；只更换预览，不修改提示词或出图参考。旧封面在成功替换前保留，生成失败或风格中途变化时不覆盖。

封面、试做和演讲页面统一要求横向 16:9。保存前按实际图片像素校验比例（容许 1% 的取整差异），服务返回竖图、方图或其他比例时明确显示返回尺寸并停止，不更新成品或封面，也不自动重试。不会拉伸、裁切或补边伪装成合格画幅；重试可能再次计费。历史异常图片保留，在试做预览中完整缩放并提示比例问题。

0.2.0 版新增 8 套已选定的风格及统一文案封面：先锋酸性色彩编辑风、新瑞士主义战略编辑风、高质感手账、暗黑参数化数据地形风、80 年代复古编辑风、日系现代建筑提案风、当代 Neo-Swiss、高端科技战略发布会风。连同原有 5 套，共 13 套内置风格；默认首选仍为“克制儿童摄影杂志风”。新增的 8 套均保留完整提示词与已生成封面，新安装无需重新提炼或生成这些封面。升级只补齐缺失记录，保留同 ID 风格的个人修改、删除状态与已有项目选择。封面仅用于展示，不作为生成参考；模型接口仍由使用者自行配置。

### 动态角标页码

图片生成时，系统只在风格原有的明确页码描述处填入整份演讲的当前页序，例如“微型页码”临时变成“微型页码（显示为 84）”。字体、位置、大小与装饰仍由原风格决定；保存的提示词、版本和封面不会被自动改写。也可在原有页码位置手动填写 `{{page_number}}`。单页试做和统一封面使用 `01`，演讲页面按真实页序使用 `01`、`02`、…、`100`，与本次制作的任务编号无关。

系统仅识别明确的“页码 / page number(s)”描述或上述占位符。没有明确位置、带否定要求或已经指定固定数值时，不猜测修改；章节、照片与流程编号不替换。风格详情会提示是否支持动态页码。当前内置的先锋酸性色彩编辑风、新瑞士主义战略编辑风、高质感手账、日系现代建筑提案风可自动识别；其他内置风格保持原文。

“实际发送的出图提示词”可核对编号。页码由图片模型画入，下载和导出不会另加数字；模型仍可能漏画或写错。插页、删页、拆分、合并或调整顺序不会自动重画旧图片，受影响页面需重新生成，重试时按请求发出前的最新顺序取号。页面详情会提示新旧页序不一致；本功能没有为既有图片识别或修复页码，也不自动增加付费调用。

## 演练中心从试播到整场

演练中心按“准备本场演讲 → 先试效果 → 生成整场”组织。先选择“自己讲 / AI 口播”和“原画面 / 动态演示”；需要数字人时，按需展开“实验室 · 数字人讲解”，在同一处选择本场声音、表达、语速、头像、布局与页面范围，编辑当前页口播正文。布局预览不调用模型；口播正文单独保存，原逐字稿、图片和旧生成版本保留。

一次准备的服务连接、密钥、声音采集、默认声音放在全局设置；头像与数字人声音在实验室管理，风格在风格库管理；本场只保存素材编号与演讲选择。缺少声音或头像时，点击“管理声音 / 服务”或“管理 / 创建头像”，打开独立设置窗口，完成后直接返回原项目。改变全局默认声音不会替换已有项目保存的声音。数字人按本场所选 MiniMax 声音生成音频，再把同一音频交给 HeyGen 同步嘴型；也可沿用本项目已有完整口播，不重新配音。

“先试当前页”支持开头最多 100 字或完整一页，确认范围和费用后才开始。短片段明确标记，不当作完整页结果；完整页试播与整场文字、声音、语速、情绪、头像一致时复用音频和嘴型视频。动态演示先转换当前页，整场只生成尚无匹配结果的页面。未填口播或缺少画面的页面会提示，用户可调整范围后生成。

生成期间显示声音、嘴型与动态页进度，可先听完成的声音或看完成的页面；关闭窗口后任务和结果仍保留。整场完整音频另存为口播版本，可在高级播放器与交付中继续使用。HeyGen 明确失败时不再显示“继续查询或下载”，已生成的 MiniMax 音频保留；处理失败原因后，重新确认生成可复用音频。尚在处理或下载失败的提交继续使用原任务，避免重复提交。继续未生成的声音或失败的动态页需再次确认费用。

“已有版本与高级调整”保留原口播播放器、AI 演绎、数字人历史和动态图层校准。密钥已保存仅代表完成配置，不代表服务可用或额度充足。自动化测试使用模拟服务验证数据保留、个人声音、完整页复用、短片段范围和失败保护；真实 App 的验收进度与服务限制见[本次发布验证记录](docs/演练中心发布验证-2026-10-10.md)。

## Mac App 的演播与帮助

演播台分为“放映、1 · 口播文本、2 · 演讲表达、3 · 声音制作”。识别、保存文本或修改声音设置只改变制作草稿，已有口播仍可播放；生成新版本时旧版保留，新版完成后主动选择“使用新口播版本”。画面下方“播放倍速”支持 0.75×–2×，播放中即时调整、换页保持，不调用语音服务；生成语速仅影响新音频。

“采集演讲者声音”移入“设置 → 语音与声音”，Mac 可用 ⌘, 打开设置。侧栏“产品介绍”展示风格、演讲、口播、动态演示、交付迁移；“使用帮助”独立提供可搜索的常见问题、新手引导和版本工作区排查，Mac 帮助菜单也能进入。

概览的“核对 N 页画面”表示画面生成后讲稿有变化，并非必须重做。逐页查看原因和前后原稿，选择查看并修改画面、确认保留或稍后处理。确认保留会关闭该页提醒，不改图、不删讲稿；以后再次改稿会重新提醒。

## PPT 放映与情感口播

打开项目，在演练中心点击“普通放映”。可直接放映已有 PPT 页面，支持全屏、前后翻页和查看逐页讲稿；配置语音后，可使用四个默认中文声音（播报男声、新闻女声、电台男主播、温柔学姐）或自己的复刻声音，按检查后的口播文本自动讲述，音频结束后才翻页。整体与逐页可分别选择随文表达、平稳、热情、低沉或惊喜情绪，并调节语速。先试听本页开头，再生成整场口播。试听按钮旁会显示生成进度、成功或失败原因，生成后自动尝试播放；若自动播放受限，可直接播放已生成试听，暂停、重播及读取重试不会重新合成。

在“1 · 口播文本”检查正文并点击“保存并继续”，到“2 · 演讲表达”选择“AI 编排整场演讲”，内容分析模型会先通读全文统一规划，再将连续多页分批处理，结合前后文和原稿提示，给原句安排情绪、停顿、语速和重点表达。可选自然、沉稳或生动风格，逐页检查并下载演绎稿，点击“使用方案 · 选择声音”进入“3 · 声音制作”试听、生成；也可“跳过 AI 编排 · 使用普通口播”，不额外调用内容分析模型。正文不会被模型改写；重点句整体稍慢、音量略增强。适度笑声、轻叹等辅助声音仅 Speech 2.8 支持，每页最多一次；咳嗽、清嗓仅采用原稿明确提示。编排和合成分别使用内容分析与语音服务额度，正文修改后需重新编排或切回普通口播；已有音频保持可播。编排随项目迁移，静态/动态 HTML 保留片段间停顿。新增演绎流程已通过模拟接口、浏览器交互和真实模型短稿联调：121 字正文生成 5 段音频，包含轻笑、停顿与重点句表达。真实感染力及长篇连贯性仍需用户试听验收。

批量编排按句数、正文长度和连续页数自动分组，每批最多 64 句、8000 正文字符、12 页，尽量保持单页完整，超长页再拆分。全场规划超过单次阅读范围时分段通读后汇总，不截掉正文。界面显示全文规划阶段、当前批次及覆盖页码、已保存页数；成功后可展开“全场表达思路”。批次结果通过整批编号及逐页校验后才保存，跨页不会串句。该流程已通过模拟服务与浏览器验证，尚未用真实模型验收长篇速度和听感。

表达编排会在每次模型结果通过检查后保存进度，包括长页面中已经编排的句子。遇到明确拥堵、暂无通道或限流时有限重试；最终失败、手动停止或重开 App 后，点击“继续编排 · 从中断处继续”，只请求剩余内容，已保存句子不会重新编排，已完成的全文规划也会复用；旧版逐页断点可继续使用，先补充全文规划再批量处理剩余句子。界面显示已完成页数和已保存句数。续编要求整场口播正文、原稿提示、标题、页序、表达设置、内容分析模型及接口一致；发生变化时需从头编排。“从头重新编排”会替换未完成进度并重新请求整场，已有完整方案和音频保留。重开 App 不自动发起付费请求；旧版失败时未保存的结果无法补回，迁移后的项目需重新编排。

在“设置 → 语音与声音 · MiniMax”配置独立的语音 API Key；默认使用 MiniMax 原生接口 `https://api.minimax.cn/v1` 和 `speech-2.8-hd`，可修改地址及模型。语音不是 OpenAI 图片/文本兼容协议，不复用已有密钥。试听、生成、复刻由所选语音服务计费，播放本机音频不再调用模型。录音或上传 10 秒至 5 分钟的 WAV / MP3 / M4A，确认本人或已授权后才上传并创建音色；供应商要求实名认证，7 天内未使用的复刻音色可能被清理，首次使用可能单独计费。

语音演示单独保存生成时的画面、完整讲稿、页序与情绪。实际口播文本由原稿派生，过滤主副标题、一级菜单、章节、图片标记、Markdown 排版符号和停顿、暂停、环顾四周等动作提示，可逐页修改并保存；原稿和 PPT 备注保留。无口播页停留 3 秒后翻页。旧音频需主动重新识别并生成新版本才能去除已读入的提示。“重新识别整场口播”会在按钮旁显示处理页数、过滤数量和更新结果；无变化也明确提示。识别与保存只处理文本、不计费，保存结果就近显示，更新声音仍需生成口播。长页按句段合成，音频逐段落盘；明确限流时等待后有限重试，其他失败停止后续请求，支持继续未完成部分。按服务账号、模型、文本、音色、语速和情绪复用音频，修改讲稿后只为变化部分重新请求。中断后不会自动恢复付费调用。音频在工作区 `speech-audio/`，语音配置与密钥在 `speech-settings.json`，音色标识、缓存和演示记录在 SQLite；原始采集录音不写入工作区。

MiniMax 错误码 `1002` 表示请求频率超限，`1008` 才是余额不足。新语音请求按同一服务密钥至少间隔 6.1 秒发送；遇到 `1002`、`2045` 或 HTTP `429` 限流拒绝，等待 60、120、180 秒后最多自动重试 3 次；明确的 HTTP 服务拥堵拒绝按约 5、15、30 秒重试，均遵守更长的 `Retry-After`（超过 10 分钟则停止）。整场任务显示恢复等待状态，可以停止，已完成片段不会重发。超时、网络错误、余额或权限错误，以及已含音频/用量的返回不自动重试；播放缓存音频不占生成请求频率。此控制只覆盖当前后台，同一 MiniMax 账号在其他程序中的请求仍共享服务方限额。

播放器持续显示已生成页数、总时长和本页时长。读取失败时可点击“重新读取音频”，仅重新加载已保存文件，不重新合成或计费。2026-10-07 修复默认 `.local` 目录中音频已生成却返回 404 的问题，并绕过更新期间缓存的读取错误；等待生成任务结束，重启更新后的后台并刷新页面，已有音频可直接播放，无需重新生成。

本功能播放本产品已有页面，不读取外部 PPTX；静态及动态 HTML 可内嵌已生成口播，PPTX 暂不包含音频。线上账号版暂未启用语音。2026-10-06 已用真实 MiniMax 服务生成四个默认音色及全部情绪选项的中文短样，并在 Chrome 中验证真实音频自动翻页、暂停和缓存复用；平稳讲述按官方 `calm` 参数发送。听感与长篇表现仍需人工试听，声音复刻相似度、Mac 麦克风系统授权和跨机器运行尚未验收。模拟接口另覆盖失败继续、停止、恢复、权限与声音创建。详见[语音演示说明](docs/语音演示.md)。

静态和动态 HTML 导出按页、按素材分块写入临时文件，完成校验后再下载，避免长篇演示触发 `Invalid string length`。离线文件内嵌高质量 JPG 和已有音频，播放时按需读取，不重新调用模型；下载完成、失败或中断后清理临时文件。2026-10-08 在同一份 133 页、759 段口播的项目上，HTML 从约 789 MB 降至 197 MB，macOS Chrome 离线首尾页画面与声音验证通过；文件仍需预留磁盘空间。

## 产品介绍页

在“使用帮助”展开“版本与工作区”，可查看前后端版本、12 位短 SHA（悬停可见完整提交）、构建时间、接口版本、运行形态、数据工作区和能力矩阵。浏览器本机版、Mac App 和 hosted 共用这个面板，默认不显示内部绝对目录。Mac App 数据与本机浏览器版分开保存；hosted 数据属于登录账号，由管理员管理。

未配置语音的本机版仍可标准放映，AI 口播生成会说明配置要求；hosted 当前未开放播放器与语音，模型设置由管理员管理。演练、交付和模型设置入口复用服务声明的禁用原因。四区导航与项目包导入导出入口保持原位。

接口版本不兼容（包括服务过旧而未返回版本信息），或生产环境前后端已知 SHA 不一致时，会暂停进入工作台并提供刷新及更新说明。刷新后仍异常时，等制作任务结束再更新 App，或请管理员完整部署同一发布的前后端。开发环境 SHA 差异只提示，`unknown` 表示无法核对提交，不当作冲突。

`npm run build` 生成根目录 `build-info.json`，Vite 将同一清单内嵌网页并输出 `dist/build-info.json`；生产后端只读取打包清单，运行时不读取 Git HEAD。发布目录须同时复制 `build-info.json`、`dist/`、`server/`、`shared/` 和运行依赖。`npm run build:mac` 自动生成 desktop 清单并核对 App 中的网页、清单和内置后端。Docker 使用同一机制，构建参数见[线上部署说明](docs/线上部署.md)。运行形态由实际启动入口声明，账号工作进程返回 `hosted`。

本机浏览器和 Mac 内置生产后端在启动时核对网页清单，并保留这一发布的完整网页资源快照。后台运行期间，即使再次构建覆盖 `dist/`，刷新、图片字体与延迟加载页面仍使用配套版本，不会混入新网页。新版需要等生成任务结束后重启后台才能启用；后台启动入口发现旧发布仍在运行时会明确提示，不会自动中断任务或假称已经更新。此保护不代替 hosted 的完整发布部署。

发布构建要求完整 40 位 SHA。Git 工作区会自动读取；源码 ZIP 或不含 `.git` 的构建目录必须先设置 `AUTOPPT_BUILD_GIT_SHA` 为该源码对应的完整提交，不能填写 `main`。可选 `AUTOPPT_BUILD_TIME`（ISO 时间）用于复现构建时间；开发时 `npm run dev` 可在无法取得提交时显示 `unknown`。发布应从干净提交构建。

## 制作流程

首次打开项目首页会显示工作区准备卡，可检查运行形态、模型与可用风格；模型未就绪时仍可先写草稿；hosted 按真实账户的模型服务状态判断，未就绪时联系管理员配置。新建只需主题和默认风格，点击“创建并写第一段”直接进入制作台；完整风格、受众与配色收在“个性化设置，可稍后修改”。空项目可使用可替换的示例文字，不调用模型。草稿自动保存，“已保存”不等于“已生成”。

邀请制网页版默认“先试一页”：完整保存并拆分这次稿件，只生成第一页画面（成功后使用 1 张图片额度）。查看试做页，满意后点击“生成其余页面”，只补做本段缺图页，已完成的试做图与版本保留。也可在提交前选择“制作全部页面”。试做和整场使用独立提交标识；刷新、重复点击及服务重启不会自动追加图片请求。Mac App 原有整段制作方式保持不变。

首次提交讲稿前会说明内容拆页、逐页出图与费用，取消保留草稿；勾选“以后直接生成”只作用于提交新讲稿，且仅在服务端接受生成后记住；草稿保存或请求失败不会启用。响应丢失时重试同一讲稿会复用提交标识，避免重复建批次。本机费用由配置的服务商收取，hosted 使用管理员提供的图片额度。页面详情首次显示逐字稿、上屏文案、重新设计三点概念，点击“知道了”或保存讲稿后不再显示；重新设计的费用提示保留在操作确认框。“使用帮助 → 重新查看新手引导”可以重看准备卡和页面提示。三个偏好独立保存在当前浏览器，按运行形态和实际登录账号隔离，不进入项目包；浏览器存储不可用时仅本次会话有效。空项目的演练与交付先引导返回制作台，交付中心折叠保留项目源文件备份。

项目通过“概览 → 制作台 → 演练中心 → 交付中心”组织同一份持续更新的母版，对应“写 → 做 → 练 → 交”。概览显示页数、画面与待办，并根据真实状态给出一个下一步动作；母版 revision 与口播、动态演示的来源版本分别展示，不代表已完成演练。手机制作台保留“补齐未生成页面”，重新设计、首部插页和撤销收入可点击或键盘展开的“更多操作”。已有讲稿时，制作台顶部显示“继续添加讲稿”入口，内容视图分为“页面 / 演说稿”，范围筛选分为“最近制作 / 全部页面 / 历史段落”。

“最近制作”显示当前制作及排队任务涉及的页面；没有进行中的制作任务时，显示最近一次制作的页面，完成后仍可查看。卡片使用整份演讲的实际页码，标签数字是页数，不是制作进度。历史讲稿可通过段落下拉框查看；没有制作记录时回退到最近添加的段落。

1. **风格库**：选择“手动填写”，输入名称和完整提示词即可保存，无需图片、不调用模型、原文不改写，保存后可直接试做并保留后续版本。也可上传少量参考图，或在「创建风格 → 从网址获取」粘贴公开作品页/图片链接，勾选 1–12 张参考图后提炼。提炼字体、色彩、线条、图形画法、信息层级和留白规则。图片只用于建库/明确重新提炼；图中的岛屿、台阶或具体位置作为观察记录，不是必须复用的模板。
2. **风格试做**：粘贴一段讲稿或从已有页选取。先提炼并独立复核上屏文案，再将文案与所选风格的原始提示词交给图片模型。风格提示词逐字保留，出图请求另附本页文字核对清单，强调不得把风格示例标题当作本页内容；这是生成约束，不保证模型每次正确遵循。统一直接出图，不再由内容模型额外制定构图方案。原参考图只用于建库或主动重新提炼，不传入出图。
3. **修改图片**：画面调整与上屏文字调整分别填写，点击“只调整这一页”。画面反馈不改写风格或文案；文案反馈会重新提炼并复核。需要修改风格时，在“试做内容 → 高级设置”中编辑原文，试做后点击“保存这版为正式风格”。所有试做保存历史，成品可直接保存高质量 JPG。
4. **我的演讲**：填写主题，点击“创建并写第一段”，使用默认风格开始，也可展开个性化设置更换风格、内容倾向和配色，再一段一段追加。提交时的原文完整保留；拆页前自动去掉 Markdown 标题，各页正文相加等于清理后的讲稿，完成后继续下一段。
5. **讲稿与重做**：每页逐字稿只保留要讲的正文，`#` 到 `######` 标题及下划线式标题整段移除；普通短句、加粗强调和正文段落保留。保存时执行同样清理。修改正文会标记画面待核对，可查看改动后重新设计或确认保留。按当前项目风格重新设计图片，旧结果保留。重做时可添加 1–4 张内容附件（PNG/JPG/WebP，每张最多 12 MB），用于把图表、产品截图等真实材料融入页面；可预览、移除。附件传入文案提炼、复核和图片生成，不作为风格参考。切换风格或规则后，续做不会复用不匹配方案。附件随成功版本保存；失败续做使用本次附件，恢复历史同时还原对应附件。
6. **合并/拆分**：手动拆分可对照原图插入分界，立即拆成两、三、五页，不等待模型设计方案。默认逐页后台出图，也可关闭后台生成、先改稿。合并相邻页仍先预览方案。支持撤销结构调整。
7. **报告**：在交付中心查看原文字数、页面数、页面备注字数与演说稿字数。统一忽略空白、按字符计数，另列去掉 Markdown 标题后的正文；逐字核对备注与正文并定位首处差异。演说稿由当前备注按页序组成，字数相同不等于独立验证。未拆页段落计入原文，未提交草稿单列；可下载文字报告。
8. **导出 PPT**：在交付中心完成导出检查后，点击“下载 ZIP 交付包”，下载带版本号的 ZIP，内含 16:9 的 `.pptx` 和独立逐字稿 `.md`。逐字稿按当前页序使用完整、最新保存的备注，包含插页与改稿，不使用上屏摘要；也可仅下载逐字稿，无需等待图片生成。全部页面按当前顺序各放一张完整图片，对应的最新已保存逐字稿写入备注。页面使用高质量 JPG，最长不超过 2560×1440 的边界，等比缩小、居中、不裁切、不放大；其他比例会留白。WebP 和历史网页场景也采用同一规则，透明图片保留 PNG。导出不调用模型。

新生成、风格试做和带附件重绘统一请求 2560 × 1440（16:9），质量为 high。已有图片不自动放大或重做；服务实际返回尺寸可能与请求不同，可在生成依据中核对。落盘采用 JPG 质量 92、4:4:4 色彩采样，等比限制在 2560×1440 内，较小图片不放大。此为兼顾屏幕演示与体积的有损压缩，并非无损保存。页面、试做、封面及单图下载采用相同规则；风格参考图沿用 1600×1600 上限，内容附件保留实际尺寸。透明素材、抠图和修复蒙版仍使用 PNG。已有本机原图及历史不批量改写，导出旧项目时现场转换；合适的现有 JPG 在重复导出、迁移时直接复用，避免反复压缩。

制作任务显示真实已等待时间与阶段；离开页面不会停止后台制作，重新打开可查看进度，不展示未经测量的剩余时间。明确失败可补做未完成页；结果不明的请求保留待核对标记，网页版联系管理员核对用量后再决定是否重新提交，继续前单独确认可能再次计费。

生成失败但仍有旧图时，导出检查列出失败页数量与页码，必须勾选确认使用现有画面后才能继续；失败且无图仍需先补齐。服务不支持 ZIP 交付包时，主按钮为“下载 PPTX”。标准放映不可用但已有画面时，演练中心显示禁用的“标准放映不可用”及服务原因；没有可演练画面时引导回制作台；空项目显示“先写讲稿 / 生成至少一页”。

### 静态 HTML 与离线口播

在交付中心点击“导出静态 HTML”，可直接导出已有画面，无需先转换动画。在口播播放器中也可直接“导出此版本 HTML · 含口播”，使用该口播保存时的画面。交付中心的动态 HTML 卡片与动态演示窗口底部均可选择“HTML 口播版本”和是否包含演讲备注；系统逐页检查画面和讲稿是否对应，拒绝把不一致的音频拼到当前画面。

带口播的 HTML 会尝试自动播放，按音频结束翻页，支持暂停、继续和跳页；无口播页停留 3 秒，末页停止。浏览器若拦截有声自动播放，点击一次“开始演讲”即可。每页的动态图层仍按预设动效播放，不做逐字时间对齐。文件不依赖本机地址或语音服务，播放不调用模型；未选择音频时仍支持定时翻页。自动播放限制参考 [MDN](https://developer.mozilla.org/en-US/docs/Web/Media/Guides/Autoplay)。

### 项目导出与导入

交付中心“导出项目源文件 → 下载项目迁移包”下载 `.autoppt.zip`，另一台电脑安装新版 AutoPPT 后，在首页选择“导入项目包”。包内包含已保存的草稿、原稿、页面和历史版本、内容附件、使用的风格及其版本、动态图层与字体、已生成口播、声音标识和口播编辑文本。导入重建编号与素材引用，每次创建独立项目，不覆盖现有项目，也不自动调用模型。已有图片和音频可直接使用；继续生成时，在新电脑配置模型密钥，复刻声音仍受原 MiniMax 账号权限约束。模型配置、密钥、运行日志和生成任务不打包。项目包把不透明图片转换为 JPG，并同步历史和快照引用；为保持动态图层坐标和附件细节，迁移素材沿用实际尺寸，透明素材保留 PNG，已有音频字节不变。本机原图仍保留，项目包不是原始图片的无损归档。

当前支持最多 500 页、960 MB 素材、32 MB 项目记录；单个素材最多 64 MB，导入 ZIP 最多 1 GB。缺失素材、校验不一致、未知包版本和非法路径会被拒绝。导出前需等待项目生成任务结束；未提交到后台的输入无法随包迁移。单机隔离工作区已验证往返导入、再次导出、音频及历史保留；Windows/Linux 和两台物理电脑间迁移尚未实测。

### 全部或选择几页重新设计

在制作台点击“重新设计”，选择“全部页面重新设计”或“选择几页重新设计”。全部始终指整个项目，不受当前段落筛选影响；选页模式可直接勾选缩略图、全选空闲页或清空。页面卡片的多选框常驻显示，勾选后也可点击底栏“重新设计所选 N 页”。窗口显示本次页码、数量和当前风格，点击“开始重新设计 N 页”才调用模型并产生费用。正在制作的页不能重复提交，可只选择其他空闲页。沿用已保存的讲稿、附件、风格与配色，成功后保留旧版本；失败保留旧图。此操作重做 PPT 图片。

### 动态 HTML 演示

标准放映从演练中心的“普通放映”进入；新的口播与数字人流程在演练中心统一准备、试播和生成整场，旧播放器保留在“已有版本与高级调整”。动态 HTML 下载集中在交付中心，支持选择已有版本，并显示未完成、来源版本不同和页面范围差异。项目源文件用于备份和在 AutoPPT 中继续编辑，PPTX、Markdown 与 HTML 用于放映或交付；导入仅在项目首页提供。Mac、本机与托管版保持四区导航一致，不可用能力显示服务限制（托管版当前未开放演讲播放器与语音功能）。

在演练中心选择“动态演示”，先试当前一页，再生成整个项目或直接勾选的页面；已有动态版本和图层校准在“已有版本与高级调整”中打开。它从已保存图片中识别文字、位置、字号、字重和颜色，分离可识别的照片、插图和图形，独立保存为背景与 HTML 图层。原图、逐字稿、历史版本和原有 PPT 导出流程保持不变。当前一次可选择 1–500 页，所选页面必须已有成图。

转换后逐页对照原图，点击文字校准内容、字体、边界、字号、颜色及出场步骤。默认按原图字形边界拟合；手动改字号会关闭拟合。可导入有嵌入授权的 WOFF2 原稿字体，最多 8 MB。字体来自图片估计，生成图的特殊字形、手写字、复杂遮挡和背景纹理不能保证完全还原，需先校对再用于正式演讲。可明确分离的图形单独运动，复杂交叠元素留在背景。

播放器支持方向键、空格、Page Up/Down、触控滑动、全屏、总览、整页动效、逐步讲述及 5/10/20/30 秒自动播放；遵循系统减少动态效果设置。下载的单个 HTML 内嵌图片、所用字体和选择的口播音频，可断网播放；默认不含讲稿，可主动勾选包含备注。预览与导出采用同一播放器，源图片不随普通导出额外打包。

每页调用一次内容分析模型；不能局部补齐的背景会额外调用一次图片编辑，需服务支持带图片与 mask 的 Images Edits。费用由当前服务提供方收取；邀请制网页版第一版暂不开放动态演示制作。已完成页面和分析结果逐页保存，失败可单页重试；停止和服务重启都不会自动重新发出收费请求，继续时跳过已完成页。已发送请求即使停止也可能计费。模型设置更换、项目删除及桌面退出保护会识别进行中的转换，线上工作区也不会把转换误判为空闲。

校准、播放、预览和下载不调用模型。每份演示保留转换时的项目快照，后续改稿或换图需新建转换。动态演示记录、字体与任务状态保存在 SQLite，分离素材保存在 `assets/`，随原数据目录一起备份。此功能不是从外部 `.pptx` 反向导入，也不改变 PPTX 的整页图片导出形式。

2026-10-05 已使用隔离数据完成模拟接口、浏览器与三张真实生成页面的转换检查；真实样张覆盖标题高亮、重叠照片阵列及九张独立照片的分层动效。Windows/Linux、超大项目的资源峰值、其他供应商的图片编辑兼容性及所有字体的还原质量尚未实机验证。详细设计与验证边界见 [动态 HTML 演示](docs/动态HTML演示.md)。

### 内容倾向与独立配色

新建项目、工作台的“内容倾向与配色”和风格试做使用同一组简洁设置。**不改就用默认**：内容倾向留空，配色选“默认 · 沿用风格”，不追加语境或替换原配色。打开设置后不编辑再保存，也不会改写已有选项。

内容倾向直接写一句受众或场景即可，例如“面向儿童摄影影楼老板”；不需要开启开关或先生成说明。需要细化时，可在“展开说明（可选）”手填或点击“AI 完善说明”。生成说明以用户提供的“受众与行业语境”范本为参考，依次展开受众视角、具体候选场景、抽象概念的转译、应避免的偏离、使用边界及最终目标；场景与措辞按行业或活动重新选择，不只替换名称。修改简述后清除旧的展开说明，以新描述为准；未改动的旧说明保留。语境只帮助理解与视觉转译，不增加原文没有的事实、定义、判断或倾向，也不强行加入行业符号。

配色直接点击基础色板，或选“自定义”调整背景、文字、强调色三个颜色。无需先提取配色、起名字或填写说明。只有主动选择新配色时，出图模型才判断原风格的配色：有明确配色则替换，没有则采用所选方案；其他设计语言保留。选回默认即可取消替换。切换风格保留已选独立配色。自定义的详细说明仍可按需编辑，原有配色记录未编辑时保持原样。

简述填写、色板选择和自定义颜色均不调用模型；只有主动点击“AI 完善说明”会调用内容分析模型。保存设置不自动重做旧图。文稿、附件未变且已有有效复核文案时，重新设计复用该文案；生成式出图仍可能改变构图，实际成图需检查。附件承载事实的颜色编码、图例、品牌或产品本色要求保留。设置随试做、方案与图片历史保存，不改共享风格或其他项目；对照时复制完整出图提示词。

### 删除项目与风格

“我的演讲”的项目卡片、风格库的风格卡片右上角均有“删除”，点击后确认；风格详情也保留删除入口。项目正在制作时不能删除，需完成或停止后再操作；风格正在提炼或试做时同样禁止删除。

删除项目会从列表移除，并停止对该项目的编辑、生成和导出访问，不影响其他项目或共享风格。删除风格会从风格库移除，已有页面、讲稿及历史保留，使用它的项目需另选风格继续制作。为保留历史及共享素材，删除不清理本机图片文件，不能用于释放磁盘空间；目前不提供界面恢复入口。

### 从参考图创作新风格

风格详情固定标题和底部操作区，保存规则、试做及用于新项目的入口保持可见。桌面左侧浏览参考图和可选视觉调整，右侧显示保存状态；完整提示词与分析记录放在“高级设置”内。窄窗口改为单列内容滚动。参考图完整显示，单张参考图可点击查看大图。调整草稿自动保存在本机，点击“重新提炼风格”成功后才应用；高级提示词手动编辑期间需先保存或取消，再试做或新建项目。

“风格库 → 创建风格 → 上传图片 / 从网址获取”提供视觉风格提示词生成器。可上传或追加 1–12 张参考图，支持多页缩略图展示；风格名称可留空自动命名，可选填写希望强化或避免的视觉方向。使用场景、行业、受众与主题在项目中填写。点击“分析视觉风格”后，先从十二个视觉维度观察各图，分开内容、版式、视觉语言与设计逻辑，再判断同一系统、不同页面类型、多种风格、离群图或证据不足。混合风格在“分析记录”中独立显示“风格 A”“风格 B”等结果，不强行平均；离群图明确标注并排除于主体提示词。

提炼时每节只保留一份章节标题；程序清除模型在章节开头重复的同名标题和编号，保留正文，不自动改写手动保存的规则或旧版本。

每组结果包含中英文风格名、定义与边界、5–10 条视觉 DNA、19 个章节的完整提示词、3–5 句锁定语句及多页模板化风险。四级规则明确“必须保持、可以变化、偶尔使用、必须禁止”。锁定语句、四级规则和共同设计底线直接合并进保存的出图提示词；可以一键复制，预览其他组不更换当前规则，点击“采用这组风格”才保存新版本。试做、封面和正式页面使用当前保存的完整规则，不额外带原参考图。右侧默认显示已保存状态；在“高级设置”中查看当前保存的完整原文，“复制完整提示词”和手动编辑都使用这份原文。分析判断、视觉 DNA、锁定语句和风险提醒收进“分析记录”，与当前规则分开；其中“复制这组分析提示词”只复制分析候选，不自动采用。手动调整或恢复版本后仍默认展示当前原文，不让旧分析结果代替它。动态页码说明在“高级设置”中查看。

每次分析调用一次支持图片理解的内容模型，再为每组调用一次内容模型写完整提示词（单组共两次），由所配置服务商计费；不自动调用图片模型。全部组校验通过才保存，任一组失败或任务取消保留原规则。原图只在观察阶段发送，写作只接收当前组的观察；源文案、水印、品牌及缩略图展示外框按模板要求忽略。单张拼图内部若有不同系统，只能提炼可识别主体并说明局限，需拆成独立图片才能分组。主模板保存在 `server/prompts/style_prompt_generator.md`，结构约定与观察模板也集中在该目录，便于维护。模拟模型、接口和浏览器流程已验证；真实模型的分组准确率、分析深度及新风格成图品质尚未实测，需用实际参考图试做核对。现有风格不会随升级自动重写。

### 提示词版本

在“风格库 → 查看风格 → 高级设置”进入“历史版本”，或在试做区的“试做内容 → 高级设置”中展开“提示词版本”，可查看保存时间、来源、提示词原文，并与当前版比较差异。手动保存、重新提炼、试做转正式都会在提示词变化时留存版本；内容相同不重复记录。旧版构思方式仍可作为历史记录查看。

点击“恢复此版本”会保存为一个新版本，恢复前的内容仍可找回。恢复提示词及原有历史元数据，不改变参考图、已生成图片或项目；旧版构思方式不再生效，下次主动制作时使用。未保存的编辑先保存或取消；其他窗口已更新时会阻止覆盖并保留当前输入。版本与业务数据一起存于本机数据库，备份时一并保留。旧提炼/转正式记录可查看，过去未留存的手动修改无法补回。

### 风格切换与细节修改

程序默认风格为“克制儿童摄影杂志风”，新建演讲自动选中，也可改选；从风格详情新建项目时沿用明确选择。完整提示词原文保存在 `server/styles/restrained-childhood-editorial.txt`，采用黑白基底、荧光强调、杂志编辑语言和儿童摄影行业语境，默认直接出图。风格库、新建项目和无成图的项目封面使用随程序发布的专属封面；封面仅用于展示，不加入参考图、不传给图片模型，也不固定以后页面的构图。升级复用已保存的同 ID 风格，不覆盖其提示词、版本、删除状态或已有项目选择；新安装自动补齐内置记录。旧的“克制极简风格”仍可选择，原提示词保留。默认项不可用时回退到其他可用风格。

默认字体、配色、材质、线条、装饰和留白要求来自各自保存的风格规范；选择独立配色时，仅颜色要求由该方案覆盖；通用生成规则不预设极简、荧光配色或精细线条。已有风格规范和完成的图片保持原样。新主题建议建立独立风格，提炼后先试做一页，再用于演讲。

逐页修改后可提交后台任务，再编辑其他页，最多同时执行 4 项，超出自动排队。手动拆分立即保存新页，每张新图独立排队；制作只锁定对应页。合并方案只锁定来源页，追加讲稿只锁定未完成页，同一项目的追加段落按顺序制作。其他空闲页可改稿、重绘、拆分，也可提交下一段。正在制作的本页可先写草稿，完成后再提交；离开时提示未提交内容。已有拆分或合并方案在来源页空闲时即可确认，其他页任务不影响。确认时显示提交状态，失败提示仅属于本次窗口，重新打开会清除旧提示。切换风格和 PPT 导出仍需项目空闲，单独下载已保存逐字稿无需等待出图。旧图保留，失败可重试；实际提速取决于服务商额度。弹窗外部点击或拖动不会关闭弹窗；请用关闭、取消按钮或 Esc 键。

切换风格或手动修改提示词后，重新设计会原文使用新提示词。讲稿、内容附件未变且已有当前版本的文案复核记录时，复用同一份上屏文案，不重新拆稿或改写文字。需要改文案时填写“上屏文字调整”；画面调整仅用于本页，不写回风格库。仅切换选择不会自动重做已完成页面，需选页重新设计。生成式图片不保证逐像素保留原构图，效果仍需检查样张。

内容附件参与整页构图：先判断用途、保留内容与阅读尺度，再组织图文，不默认贴缩略图、套卡片或固定放在一侧。照片可裁切无关外围、在不改变事实时衔接背景；图表和界面截图通过周围排版融合，保留数据、标签、控件及必要上下文，避免扭曲、遮挡和缩得过小。这些要求只在有附件时追加，不指定其他风格的材质或场景；实际融合与细节保真仍需检查成图。

在交付中心点击“导出演说稿（Markdown）”，可以单独导出全部页面的最新完整正文，每页用 Markdown 二级标题标明页码。

在页面卡片或演说稿的页间点击“插入”，填写这一页的完整讲稿，选择“插入并生成”或“仅插入，稍后生成”。新页固定为一页，沿用项目当前风格、内容倾向和配色，后续页码顺延；也支持在第一页前、末尾插入。后台任务不锁住邻页，失败后页面与讲稿保留，可继续修改或重试；同一次请求重复提交不会重复插页。

未完成的页面或未拆分的段落会阻止导出，窗口显示具体缺页，先补齐再下载；正在生成时需等待或停止。改稿后尚未重做图片时，下载按钮会明确提示使用当前图片与最新备注。未提交生成的输入草稿和未确认的合并/拆分方案不纳入导出。

旧图片、网页页面及其历史继续保存和展示；显式重做才生成新图片。风格删除保留历史。原有 PPTX 只含完整图片和逐页备注，不拆为可编辑元素；新的“动态 HTML”入口另存网页图层与动效。

## 风格与出图

### 上屏文案与密度

流程为“完整逐字稿 → 按讲述逻辑拆页 → 每页提炼上屏文案 → 独立文案复核 → 原始风格提示词与文案组合出图”。段落是拆页依据，不机械地一段一页；已有手动分界仍由用户决定。风格不参与拆页和文案提炼。

内容关系与上屏文案的原稿引用校验允许空行、换行、中文间距和成对的 Markdown 加粗、斜体差异，不改写原稿或引用记录。英文单词、数字之间有意义的分隔仍保留；实质文字、数字、标点、否定或条件变化，以及跨过正文拼接引用，仍不通过。此规则用于判断引用是否来自本页，不代替模型对完整语义的复核；已选主张的必保条件继续独立检查。

上屏文案只保留核心表达及必要支撑，开场、重复解释、口语衔接和展开优先留给口播，不逐句缩写整段稿件。关键条件、数值、单位、范围和疑问语气需要保留，逐字稿与 PPT 备注保持完整。内容部分另含“可选语义辅助资料”和“辅助表达边界”：只摘取本页原稿或内容附件明确提供的短定义、关系，独立复核后可用于少量小字，不能升级成主标题或新结论。以提炼后的上屏文案为主，保持原意和表达程度。可为丰富页面增加少量、轻微、中性的辅助联想或解释，不能增加指向性或引导性，不能让观众读出原文没有表达的意思、判断、倾向或结论，也不能补造事实；文字、图像和图形关系都遵守这一边界。风格中的示例文案不作为本页事实来源。生成后仍需核对小字和图形是否越界。

页面的“上屏文案与风格”中可查看画面文字、“文字取舍与密度”、本次风格提示词原文和实际发送的出图提示词。风格试做的“查看上屏文案与生成依据”提供相同记录。字数按非空白 Unicode 字符统计，包含标点及保留的 Markdown 标记；附件内部文字不计入统计，但文案模型会看到附件并判断阅读负担。

校验针对已选上屏主张的必要条件，允许“五个/5个”等明确等值的整数数量写法，不自动换算单位或改写范围。完整移至口播的非核心支撑主张可释放其对应保护，仍在表达的主张不能只删限定词。来源引用错误与实际遗漏分别报告；可修正的来源或必保信息错误每页最多自动修正一次，字面匹配仍失败时，自动恢复对应的有据原句并重新校验，无需再点重试，也不增加模型请求。来源、原意或其他校验仍不通过时，显示阶段、待核对文字、来源引用与候选文案并停止出图。失败提示随原有任务或页面错误保存，不保存模型的全部原始响应。语义判断仍依赖模型复核，不能保证所有同义表达都自动通过。

发送给图片模型的内容部分保留各组“核心表达、支撑信息、限定或出处、标签”角色，角色说明本身不上屏，字号、位置和构图仍由风格与内容决定。旧成品不自动重做；下次主动重新设计或续做时更新内容格式，复用有效的已确认文案。此传递修复不等于成图层次已经通过视觉验收。

风格试做在成图下方展开“查看上屏文案与生成依据”，可查看“本次提炼的上屏内容”，复制上屏文案、本次风格提示词、“内容部分（含辅助信息）”或完整出图提示词。分开对照时请复制风格和完整内容部分，单独两句主文案不含语义辅助依据；已有 ChatGPT 对话也可能带入不同上下文。展开“辅助信息与语义边界”可查看实际内容。复制取自当前选中的试做记录，不混入后来修改但尚未生成的讲稿或风格；输入改变时会提示。查看和复制不调用模型。旧记录未保存的内容不会补造；浏览器不允许复制时提供文字全选后手动复制。

语义辅助摘录与原稿、附件共同绑定，复核时允许移除；程序校验原稿摘录的逐字来源、附件归属与重复，限制为 0–6 条、每条最多 160 个非空白字符，防止整稿混入辅助内容。附件内文字的准确性由模型复核，程序没有独立 OCR 校验。摘录不是必上屏文字，不计入主文案字数，但模型复核须考虑其阅读负担。逐字来源存在不等于含义必然正确，语义相关性仍依赖模型复核和成图检查。

`server/screen-copy.mjs` 按观点提问、关系对照、数据论证、内容附件设置初始提醒值（总字数分别为 50/90/120/50，文字组数为 3/7/8/4）。这些值不是硬上限或理想字数，不截断原文；超出时须说明保留的必要性。复核是模型判断，不测量成图文字面积或精确阅读时间。

复核未通过时停止出图并保留旧图片，可按提示修改文案或手动拆页，不会自动增加页数。新文案需要提炼和复核两次内容请求；讲稿、附件未变且未填写文案调整要求时，换风格或重新构图复用已复核文案。改稿、增删附件、填写文案调整要求或遇到旧版本文案记录时重新提炼。图片失败后的原任务重试复用已保存请求依据。

已取消“按内容构思”开关与额外构图模型调用。风格试做、单页重新设计和整场制作统一按已保存的风格原文与已复核文案直接出图；旧配置即使开启也不再生效，重试不会追加旧构图要求。已有成图、提示词版本及实际生成指令保留，旧构图说明标为历史记录；升级不会自动重做图片。

### 风格提示词与生成

`server/models.mjs` 独立组织内容分析与文案提炼，不调用风格编译器。默认直接发送风格原文、上屏文案和简短的中性补充边界；没有辅助摘录时省略空资料区，不追加特定案例或标签白名单。旧方案下次主动生成或失败重试时更新出图边界，仍复用有效的已确认文案，旧成品与历史保留。不再调用单页构图模型。旧 `compositionMode` 仅作兼容元数据，不影响出图；旧构图缓存下次主动生成或重试时重新组织为直接出图方案，复用有效的已复核文案。`server/direct-image.mjs` 在普通出图中发送“风格 `rules` 原文 + 空行 + 内容部分”，内容部分由 `server/image-content.mjs` 组织主文案、可选来源摘录和语义边界，与复制的内容部分一致。语义约束不指定配色、明暗或构图，不改写风格。有内容附件、用户填写的画面反馈、内容倾向或独立配色时，追加各自标注的要求。受众语境可进入内容理解，但配色不进入文案提炼；项目与试做的 `designOptions` 独立保存并参与方案缓存匹配。尺寸、质量、背景通过图片接口参数发送；实际请求末尾独立标注横向 16:9 成品画幅，不改写保存的风格原文。不会混入旧参考观察、其他风格、预选版式或默认的极简、细线、荧光配色。

参考图在建库或用户主动“重新提炼风格”时生成设计语言。用户直接编辑并保存后，自动生成和试做均保留该原文。试做不再自动“调整规范并再试”；旧客户端的 refine 请求也只调整本页。历史观察和旧风格缓存继续保留，但不参与新出图。

文案按原稿与内容附件绑定，和风格指纹分开校验。`server/jobs.mjs` 保留拆分、合并、队列、失败续做与版本历史；旧方案在用户重新生成时升级，已完成图片不会因升级自动替换。图片服务来源、请求模型、实际提示词和规格保存在 `plan.imageRequest`；`plan.imageResponse` 记录实际图片尺寸，以及服务声明的模型、尺寸、质量和改写提示词（若返回）。展开“实际发送的出图提示词”可对照请求与返回，不含密钥。模型名称只是请求值；第三方服务未返回模型标识时，不能据此确认其后端与 ChatGPT 相同。代码发布不会自动激活已运行进程中的新代码；本地服务需在任务空闲时重新启动。真实图片质量仍由所配置的模型决定。

## 网址导入

先获取图片预览，选图后才创建风格并进入原有提炼任务；建议选择 3–5 张同一风格、不同构图的作品。已保存的风格保留来源链接。普通网页识别正文图片与常见懒加载地址，站酷优先识别作品图库，不读取头像、评论和相关推荐；不递归爬取整个站点。本次最多读取 36 张候选图片，预览保留 30 分钟，未提交的预览不进入正式风格库。小于 480 × 240、重复或无法读取的图片会略过。

站酷页面需要 JavaScript 时使用本机 Google Chrome 的独立临时会话；不会读取个人浏览器账号，也不会自动完成验证码。需要登录、滑动验证或不公开的图片会明确提示失败，可以改用公开图片链接或本地上传。2026-09-30 实测用户提供的站酷作品页触发滑动验证，未验证整页自动导入成功；该页公开展示的图片直链已实际完成获取、预览和选择。不能将这两项结果混同。

如果前端已更新但旧服务仍有生成任务，网址入口保持禁用，待更新本地服务后启用，避免打断正在生成的页面。

## 模型接入

在“模型与服务”分别配置内容理解与图片生成。内容服务需支持 Chat Completions、JSON 和视觉输入；视觉用于风格建库及理解用户在重做时提供的内容附件。无附件时图片服务使用 Images Generations；带附件时需兼容 Images Edits 的 `image[]` 多图输入。不支持时明确报错并保留上一版与附件，不会悄悄忽略材料继续出图。模型名称以实际服务为准。

Key 仅保存在服务端 `.local/settings.json`（0600），不回传浏览器。支持 `OPENAI_API_KEY` / `OPENAI_BASE_URL`。测试连接只验证接口与模型列表，不代表实际出图成功。

## 用量与账单

Mac App 和本机浏览器侧栏新增“用量与账单”：今天、本月、全部时间的 AI 用量与预估费用，按项目和调用类型汇总，查看逐笔明细及导出 CSV。内容分析、风格分析与试做、页面图片、动态页面识别/修复、演绎编排、口播试听与合成、声音复刻均在实际请求时记录；失败、重试分别留痕。播放已有音频和本地操作不调用模型，相同语音缓存复用显示零费用。

先在“模型单价”填写供应商人民币单价，再正常制作。文本按输入/输出 Token 计价，缓存输入包含在输入中，不重复计算；图片可按张或统一 Token 单价估算，尺寸和质量分别配置；语音优先使用供应商返回的计费字符，没有时标为字符估算；复刻按成功次数估算。每次请求保存当时的单价，之后改价不重算历史。复杂多模态、阶梯价格、折扣及汇率不自动处理，填写平均价时只是预算估算，结算以供应商账单为准。

“补充预算”只为本机账本增加记账额度，不发起支付、不充值供应商。可切换 ¥1 = 1,000 积分显示；积分不是 Token。预算不足 20% 或用完时在账单页提醒，默认不阻止任务。缺失单价或用量、结果不明的请求显示待核对，未计入合计；失败不能自动等同免费，余额也不是供应商真实余额。

从新版首次启用开始记录，旧项目的历史费用不伪造补记。记录和预算保存在当前工作区的 SQLite，不保存 API Key、提示词或音频正文；项目迁移包不含整个工作区账本，以免导入后重复记账。不同 Mac/本机浏览器工作区目前分别记账，可导出 CSV 留档；跨机器共享账户与支付未实现。托管版继续使用原有图片额度规则，本次不改变托管账号扣费。

隔离模拟服务及 Chrome 验证覆盖单价快照、缓存输入、语音字符、复刻、失败中断、并发项目归属、重复预算、防跨站写入，以及界面配置、筛选、详情和 CSV 下载；验收不调用收费模型。

## 数据与恢复

已有项目会在服务启动时清理逐字稿中的 Markdown 标题，保留画面与页序，不触发生成。清理前的项目记录保存在 SQLite `manuscriptBackup`，受影响页面的原稿也留在版本历史；提交批次原文、草稿与旧版本内容保持原样。恢复版本时仍以正文用于口播。导出的 PPT 备注和演说稿与页面正文一致。

- `.local/autoppt.sqlite`：项目、原文、方案、风格、试做、历史和任务。
- `.local/assets/`：原始参考、内容附件及生成图片。
- `.local/server.log`：后台日志。

中断时已完成图片保留，重启可继续；失败重做不丢弃上一版结果。备份请复制整个 `.local/`（服务停止后），或通过 SQLite 备份 API 创建数据库快照。
