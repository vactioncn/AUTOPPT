# 数字人工作室

Mode: Operate. Existing-world extension, following DESIGN.md; no new brand direction or comp round.

THESIS: Prepare an avatar once, test it with text, then use it directly in any project.
OWN-WORLD: AutoPPT quiet personal speech studio. Warm canvas, white paper, terracotta actions, olive navigation; incumbent typography and controls.
STORY: Connect HeyGen and the configured MiniMax speech service → save avatar/style/MiniMax voice from the shared AI-narration voice list → preview short text with MiniMax audio → send that audio and portrait to HeyGen for mouth synchronization → select that saved avatar in a project → generate and play notes. Existing AI narration remains an optional advanced source whose original audio is sent directly, preserving its voice.
FIRST VIEWPORT: Saved avatar list and identity readiness name the MiniMax voice; an already configured avatar leads immediately to text preview. Incomplete avatars show editing fields. Project generation controls stay visible without an upload flow or narration prerequisite. Selecting existing audio changes the main description to retaining the original narration voice; missing selection shows “待选择口播”.
FORM: The library lives under Settings → Labs, marked as experimental, beside the workbench on desktop and stacked on narrow screens. Saved identity is collapsible, preview and results are explicit. Upload and style variants are managed in this laboratory resource surface. Rehearsal exposes the digital actor through an optional laboratory disclosure; new projects default to self, and saved project actors remain intact.

Voice-source contract: MiniMax voices include collected personal voices and announcers and come from the same configuration as AI narration. A portrait does not identify a voice. Text generation uses the saved MiniMax selection and never substitutes HeyGen platform dubbing. Existing narration sends the original audio without resynthesis. Records label MiniMax, original narration and preserved legacy HeyGen dubbing separately; recovery reuses saved audio.

Truth constraints: Connection test is read-only. Video and generated style images require explicit cost/upload confirmation. The MiniMax text path explains both speech and video service usage; the original-audio path explains upload and mouth synchronization with the original voice. Uploaded styles are categories, not automatic transformations. Preserve original avatars, project notes, images, narration, history and browser drafts. Use durable generation IDs and safe reuse. Current implementation is local App only; exports do not yet bundle avatars/videos. Earlier Chinese 2.36-second video verification is retained as history. On 2026-10-09, a 2.64-second video using the saved personal MiniMax voice was verified, with the video audio matching its MiniMax source (correlation 0.999983). This is a short source-retention check, not a claim that all styles or long-form mouth synchronization were paid-model tested.
