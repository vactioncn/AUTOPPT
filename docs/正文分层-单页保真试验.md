# 正文分层：从单页到五种风格的保真试验

2026-10-19 的目标是验证：保留图片生成页的构图和艺术表现，把主要表达文字变成可修改对象。当前成果为独立试验，不改变正式制作、导出流程或现有项目。

## 样例和产物

第一阶段使用《朝花夕拾》第 4 页“先讲故事”的原始 1672 × 941 图片。保留书法标题、页眉、书籍文字、水墨插画和装饰，将三行主要正文按黑色与红色拆成四个文字层。随后加入官网四个已有风格的实际页面，验证细字、粗体大字、彩色强调和照片背景等不同情况；这些是各自内容不同的页面，不是同一文案换色。

| 风格 | 页面主要内容 | 独立文字层 |
| --- | --- | --- |
| 水墨书卷 | 先讲故事 | 4 |
| 日系建筑 | 留白不是空着。 | 3 |
| 儿童摄影杂志 | 孩子第一次说“我自己来” | 4 |
| 当代 NEO | 一个清楚的观点，胜过一页堆满的信息。 | 5 |
| 先锋紫绿 | 好想法，不该安静地消失。 | 5 |

- 试验页：`.local/experiments/editable-text-20261019/output/index.html`。
- 分层 PPTX：同目录 `editable-text-five-styles.pptx`（网页下载别名 `editable-text.pptx`），五页各一张底图，合计 21 个原生文本框。最初单页版本保留为 `single-v1.html` 和 `single-v1.pptx`。
- 源图、生成的去字图、位置数据、提示词和验证证据保存在本地试验目录，不随代码提交。

网页支持原图、分层效果、只看底图、拖动对照；可在画面或表单中改字。切换风格保留各页修改，恢复原文只影响当前页。保存的独立 HTML 包含五个样例的修改、图片和字体，离线重开后仍可编辑、再次保存。下载的 PPTX 是已校准的原文版本，不同步之后在网页里的修改。文本超过原定宽度时给出提示，不自动缩字或重新排版。

## 本次做法

1. 只读复制选中的原图，不接入项目存储和任务服务。
2. 人工测量四段正文的墨迹边界、颜色、字重与位置，原正文逐字保留。
3. 使用 imagegen 去除三行正文，保留艺术字和装饰。合成时只从修复图取正文笔画附近的像素，其余像素继续使用原图。
4. 网页以嵌入的 Noto Serif SC Variable 还原原页宋体风格。按原文字边界校准一次，后续修改固定位置和比例。官网使用现代黑体的决定不受本页文学风格影响。
5. PPTX 使用 macOS 可用的 Songti SC 创建原生文本框，并单独对齐；网页和 PowerPoint 的字体及排版引擎不同，两份结果仍有细微字形差异。

四个新增样例采用同样的局部去字方法：从 `public/style-showcase/` 只读复制对应原图，以 imagegen 生成去字参考，再按文字遮罩合成。网页正文使用嵌入的 Noto Sans SC Variable，按各自原图的文字墨迹边界校准；保留手写 Idea、装饰英文及非主要表达文字。PPTX 使用 Noto Sans SC 与 Source Han Sans CN，并用实际渲染的墨迹边界单独校准字号和位置。源码不调用模型，模型生成和配置测量仍是本次人工试验步骤。

## 已验证与限制

原图 SHA-256 前后一致：`52394daebc476b85308f9c4059b9a999e3d87543d605e5f70d18a1c88112f074`。修复遮罩覆盖 62,087 像素（约 3.95%），遮罩之外 1,511,265 像素完全一致。这是背景像素保留证据，**不是“整页相似度 96.05%”或“文字完全一致”的评分**。

新增四页的源图哈希也前后一致，生成底图在各自修复遮罩之外的像素差异均为 0。遮罩占比分别约为日系建筑 6.44%、儿童摄影杂志 13.03%、当代 NEO 36.48%、先锋紫绿 15.15%；它们只表示局部替换范围，不表示视觉相似度。

真实 Chrome 验证覆盖全部五种风格、21 个文字层、表单和画面编辑、改字后变换参数不变、超长提示、各页修改保留、仅恢复当前页、原图/底图/拖动对照，以及保存全部样例后离线重开和再次保存。1500、820、390、320px 下所有风格无横向溢出，未出现页面脚本错误。相关正文编辑和局部去字测试 5 项通过。五页 PPTX 已检查原生文本框、原文、文件结构、画布尺寸与字体，并通过回读和逐页渲染；原生 PowerPoint 打开及跨电脑字体表现尚未验收。

本次为五页人工测量、人工校准的可行性样例，不证明任意图片可以自动无损拆层。图片模型生成的字形可能不是任何现成字体；底纹被文字遮挡的区域也需要推断恢复。因此不能承诺将历史纯图片页转换成百分之百一致的可编辑文字。

## 正式升级建议

新页面应在生成前确定同一份版式数据：正文内容、位置、宽高、断行、字体、字重、颜色、行距、字距，以及保留为艺术图像的文字。图片模型按这个布局生成插画、材质、装饰和艺术字，正文由确定的文字排版器绘制。预览、HTML 和 PPTX 共用这些坐标与文案，并做字体/溢出检查。

历史图片走“原图分析 → 局部去字 → 文字校准 → 原图对照”的独立转换流程。复杂遮挡、透视字、弧形字和纹理字允许继续保留为图像；转换质量不足时保留旧版并提示人工校准。

## 复现网页试验

在本地准备 `case.json`、原图和经过 imagegen 去字的参考图，随后执行：

```sh
node scripts/build-editable-text-lab.mjs /absolute/path/to/case.json
```

`case.json` 的 `original`、`generated`、`output` 相对它自身目录解析。`layers` 每项包含 `id`、`label`、`text`、`x/y/w/h`（原图墨迹边界）、`maxWidth`、`fontSize`、`fontWeight` 与 `color`；`font` 可用 `sans` 或 `serif`（省略时沿用最初的宋体样例）。每个样例可额外指定 `id`、`title`、`styleName`、`description` 和 `sample: {id, text}`。

多风格配置使用 `cases` 引用多个样例，路径相对汇总配置解析；`output` 指定共同输出目录，`activePageId` 指定初始页：

```json
{
  "output": "../output",
  "activePageId": "japanese",
  "cases": ["story/case.json", "japanese/case.json", "childhood/case.json", "neo/case.json", "avant/case.json"]
}
```

本次汇总配置为 `.local/experiments/editable-text-20261019/multi/cases.json`。构建输出含 HTML、各页背景图、`layers.json` 和字体许可；对应验证报告写在配置旁的 `verification.json`。网页构建器不生成 PPTX；本次 PPTX 通过独立的人工校准导出制作。示例配置、素材、提示词和浏览器/导出证据留在私有试验目录。构建器只读显式输入文件，不读取模型密钥、工作区数据库，不调用模型，不写入原项目。
