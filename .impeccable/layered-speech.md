# 分层演讲试用入口

Mode: Operate. Local extension of the incumbent warm, quiet speech workbench; no replacement visual world or approved external comp.

## User contract

The user approved implementing background + editable main text, simple presentation animation and editing while paused. Begin with the existing five-style test; preserve every existing project, asset and history. Artistic lettering can remain in the image. Reuse the brand and built-in typography.

## This milestone

- A visible “分层制作 · 试用” entry on the local production toolbar. New independent motion records snapshot manuscript/style/copy; original projects are not rewritten.
- Generation plans text and placement before drawing a text-free background and checking residual text. Original style rules guide free composition. No generic fixed-layout template.
- Main editor: click/select text, edit, choose built-in font, fixed size, weight, color, spacing. Playback presets: natural, semantic steps, whole/static. Geometry and effect sequence are disclosed. Overflow blocks saving layered text; never silently shrink or distort.
- Saving and undo do not call models. A managed player pauses and requests the current page in the editor; saving updates that player while retaining its step. Screen text never silently replaces manuscript or narration.
- HTML embeds assets and fonts. PPTX uses native editable text and full OFL font faces from a separately prepared font pack. PPTX animation is not implemented in this milestone. Hosted mode retains its existing capability boundary.
- Five supplied style fixtures are imported into a NEW isolated data directory. No generation calls or copied provider settings are used for the demo. The end-to-end generation stages are covered using mock models, not claimed as a new five-style live model run.

## Motion and canvas-editing follow-up

- Focal moment: authored page sequences drawn from the 24-expression reference. Story reveals context then detail; focus brings the key sentence into focus; comparison approaches from two sides; chapter expands a headline; progression rises in semantic steps; editorial settles into a reading rhythm. These are six compatible choreographies, not a claim that all 24 structural components exist.
- Continuity: finish in the exact saved geometry. Replaying, stepping backward, switching pages or editing cancels all transient transforms. Keep old custom effects by default; new presets are explicit choices.
- Feedback: click the actual text to type, select and paste plain text. Selection handles move and resize its box; the inspector changes typography. Keep the caret and IME composition in place, show overflow, save with revision checks, and provide local undo plus saved-version undo.
- Budget: no loops or dependencies. WAAPI transform/opacity, at most 3px bounded text blur and one subtle background settle. Stagger capped at 1.4s; reduced motion uses short fades. Full font coverage in the editing preview, no iframe reload on typing. Editing preview never mutates a project without Save.
- Verify on a fresh five-style workspace, preserving the prior 51921 demo and all existing data. Desktop/mobile captures and actual canvas editing, replay, save/undo checks are required.
