# 讲好 · 品牌规范

更新：2026-10-12。名称、定位和标语已经由灏哥确认；本轮将它们落实到官网。

## 品牌核心

**讲好**

**AI 演讲工作台**

**从一份讲稿，到一次从容的表达。**

讲好的核心感受是「从容」。它来自充分准备：想法整理清楚、画面呈现合适、讲稿完整保留、讲述节奏可以演练、成果能够带走。品牌用真实作品与明确的操作建立信任。

主要场景是工作汇报、主题演讲、产品介绍、培训分享与年终总结。家庭学习中的看图讲述、知识复述也可以沿用这一品牌，不另设教育专用名称。

## 品牌故事与介绍

一份讲稿里，已经有你的想法、经历和判断。讲好帮助你整理观点，找到合适的视觉表达，再把演练和交付一起准备好。观众看见重点，你的完整讲述始终保留。

短介绍：

> 讲好是 AI 演讲工作台，帮助你从一份讲稿出发，制作有风格的画面，准备讲述与演练，导出完整的演讲成果。

官网主标题使用已确认的标语。按钮使用「用邀请码开始」「继续我的演讲」「播放产品介绍」「下载这份 PPT」等明确动作。

## 标志

标志是一对朱红底上的浅色引言符号。引言代表讲述的起点；下沿向前的折角让它同时具有页面与表达的联想。图形可独立用于网页图标，和「讲好」字标组成官网识别。

- 独立标志：[mark.svg](../public/brand/mark.svg)。
- 横向组合参考：[wordmark.svg](../public/brand/wordmark.svg)。组合 SVG 的文字已转为轮廓，分享或导出时无需安装字体；官网与产品界面使用同一 SVG 标志加本地字体的真实文字。
- 字标、官网标题与官网正文统一使用 Noto Sans SC Variable（思源黑体同系），本地字体别名为 `Jianghao Sans`；英文和未覆盖的动态中文保留 DM Sans 与中文系统字体作为后备。字标约 700 字重，标题约 600，正文约 400。
- 标志四周至少留出标志宽度四分之一的空间。网页图标可按实际像素使用，不增加文字。
- 小尺寸仅使用独立标志；避免描边、拉伸、渐变、发光和叠加装饰。

## 视觉语言

整体像一个认真准备内容的精品出版工作室。大字承担主题，细线建立秩序，作品承担视觉证明。暖色保留亲近感，朱红集中标记行动和主标题的关键词。

| 用途             | 色值      |
| ---------------- | --------- |
| 暖纸色背景       | `#FAF7F0` |
| 浅色工作面       | `#FFFDF8` |
| 墨色文字         | `#292820` |
| 朱红标志与主行动 | `#A83D30` |
| 次要文字         | `#676258` |
| 分隔线           | `#DED8CC` |
| 阅读段落背景     | `#F0EBE1` |

经灏哥反馈和字体复核，品牌从宋体调整为清晰、稳健的现代黑体。官网主标题使用 Noto Sans SC 600 字重，桌面 36–58px、行高 1.36，手机 32–36px、行高 1.45；段落标题 28–42px、行高 1.4。字标桌面 32px、手机 28px，700 字重，字距 0.02em。官网正文 16px、行高 1.8；主标题说明 17px、行高 1.85；辅助说明 13px、行高 1.65。静态介绍页沿用同一字体与字标，居中主标题最大 64px。标题保持完整语义与自然换行，不依赖缩小文字适配窄屏。产品其他操作文字保留已有字号体系。

320px 复核发现的标题断行已修正：官网与静态介绍页在 360px 及以下使用 30px 主标题，并保持“从容的表达。”完整，不在短语内换行。390px 及以上保留原字号角色，产品工作台布局与控制尺寸不变。

真实页面保留原有风格与完整 16:9 画幅，周围的官网颜色不改写作品。首屏保留产品实际制作的视频，作品区展示四组十二张生成页面。页面按「写 → 做 → 练 → 交」连接内容准备、视觉制作、口播演练和成果交付。

主标题从墨色缓慢落到朱红；原录音案例随滚动滑入，也可点击展开，声音只在用户点击播放后开始。内容默认可见，遵守系统的减少动态效果设置。手机导航、焦点、按钮和作品阅读继续可用，图库不再显示“放大查看”提示。

## 用词与证明

表达简洁、具体、平等。先说明用户可以做什么，再提供实际作品和开始方式。优先使用「整理观点」「有风格的画面」「完整讲稿」「先试一页」「从容表达」。

不用「颠覆」「行业第一」「百分之百」「零成本」等未经证实的承诺。画面生成质量随内容、风格与模型变化；能力状态沿用真实实现。数字人仍在实验室阶段，网页版不展示为已开放。

PPTX 每页仍是完整图片加演讲者备注，文字与图形不能单独编辑。官网须在交付说明中保留这一事实。

## 更名边界

产品显示名、工作台页头、菜单与官网统一为「讲好」，使用同一 `public/brand/` 标志。旧名 AutoPPT 保留在迁移解释、技术路径、历史用户项目和已有导出文件中。公开六页产品演示 PPT、视频、备注与字幕同步为讲好；仅重录 3 段含旧名的口播，另 19 段保留原音频，不把局部更新描述为整场重新制作。

这次品牌更新不迁移数据，不更改以下技术标识：

- 仓库 `vactioncn/AUTOPPT` 与软件包 `autoppt`。
- 主程序 `/Applications/AutoPPT.app`。
- `~/Library/Application Support/AutoPPT/`、`.local/` 与 hosted 用户工作区。
- 环境变量、API、项目编号、`.autoppt.zip` 和已有导出文件。

当前没有公网官网地址，本机预览为 [讲好官网](http://127.0.0.1:51770/website)。本轮更新源码、公开演示与可独立发布的介绍页，未安装或替换 `/Applications/AutoPPT.app`；新源码需在新构建版本下一次启动后生效，正在运行的旧 App 不会自动更名。后续发布使用明确的域名或目录。

## 资产来源

官网四组作品继续沿用 `public/style-showcase/` 与 `public/showcase/` 的实际生成页面，保持原风格与画幅。产品演示公开文件为 `public/product-demo/jianghao-introduction.mp4` 与 `public/product-demo/讲好-产品介绍.pptx`；名称相关的三段配音更新，其余十九段保留，字幕与演示内容同步。
