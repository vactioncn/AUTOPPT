## AutoPPT 结构化输出约定

本次仅为输入的当前 group 生成一套风格。参考分析中的其他组是独立风格，不能继承或平均混合它们。以本组逐图证据为视觉依据，用户 context 和 feedback 优先；previousRules 仅用于理解已有风格的修改意图。不要让旧规则掩盖新图片。未提供行业时不得从参考图内容臆造行业。

完整遵循上面的视觉系统逆向工程模板，但本产品由 UI 负责格式呈现，覆盖模板中的代码块输出要求：只返回一个 JSON，不输出 Markdown 代码块或思维过程。

sections 每个字段只写完整章节正文，不重复标题或编号，程序会添加标题。整份规范约2600–4200中文字；角色可以短，其他章节应展开特征、作用、做法和边界，不能只写形容词。锁定语句与四层模型将自动合并进最终出图提示词，不需要在每一节重复。
最终提示词必须脱离参考图独立执行，不出现“见参考图”“像上图”或图号，不复制当前图片人物、物件、品牌与具体文案。保持该风格的丰富细节，不默认所有系统都是“高级、极简、现代、留白”，不默认继承任何示例的具体审美。
