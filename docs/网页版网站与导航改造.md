# 网页版网站与导航改造

日期：2026-10-11。范围是邀请制网页版；保留现有 App 与工作区，不开放数字人。

## 盘点与优先级

| 优先级 | 原问题 | 本次调整 |
| --- | --- | --- |
| P0 | 未登录访客先看到登录表单，不能了解产品 | 官网公开展示真实能力、风格示例、制作流程和功能边界 |
| P0 | 注册和登录靠表单切换，没有可分享入口 | 独立注册、登录地址，邀请码可通过注册链接预填 |
| P0 | 找回账号只能看到一句管理员提示 | 账号帮助解释邀请码问题与管理员重置步骤，支持部署方联系方式 |
| P1 | 左侧混合创作、介绍、帮助与重复账号设置 | 创作、最近项目、支持及账号分层；网站管理独立且仅管理员可见 |
| P1 | 窄屏图标缺乏说明，手机导航拥挤 | 平板保留名称提示和可访问名称；手机使用完整导航抽屉 |
| P1 | 查看介绍与返回时容易丢失工作位置 | 官网与工作区分离，当前会话保持工作区挂载，返回保留页面和草稿 |
| P1 | 网站缺少公开说明与基本元数据 | 提供帮助、使用与数据说明，配置域名元数据、robots 与 sitemap |
| P2 | 官网首屏随整个创作程序加载 | 工作区延迟加载，访客先加载官网与账号页面 |

## 使用路径

访客：官网 → 邀请注册 → 创建账号 → 我的项目 → 新建演讲 → 先试一页 → 满意后生成剩余页 → 打磨与导出。

已有用户：登录 → 项目；直接打开项目链接时登录后返回目标页面。官网、数据与使用说明可随时查看；工作区当前会话保留。账号底部集中显示可用与预留额度，点击查看记录或修改密码。

管理员：网站管理 → 创建一次性邀请码 → 复制邀请码或注册链接 → 分配额度、管理用户与核对异常。服务端权限继续隔离管理员和普通用户。模型 Key 只通过部署配置提供。

## 验证与边界

通过隔离环境验证网站直达、注册登录与角色隔离，使用模拟模型验证原有生成流程；不调用用户收费模型。官网示例来自公开内置封面和既有演示截图。前端交互验证与最终本地升级结果见交付记录；公网 DNS、TLS、正式服务器承载、邮件和支付未在本次部署。

不自动同步 App 的项目，不改已有正式风格及生成策略。服务器目录、图片与账本保留，升级前核对空闲状态并备份，安装包只包含源码和部署文档。
