## 这次验证了什么

以现有「当代 Neo-Swiss」为主模板，增加「日系现代建筑提案风」对照。两者分别依据 `server/styles/neo-swiss.txt` 和 `server/styles/japanese-architecture.txt` 人工适配。切换模板保留页面、步骤、文案与来源，改变字体层级、字重、信息组大小、留白、强调形式、关系图线条及动画速度。

这证明了表达结构可以和模板视觉分开。当前只完成两款模板及九种页面实现；没有实现任意提示词自动转成网页样式，也没有完成全部 24 类表现方式。

本机试稿取自《儿童分会演讲（正式版 1.0）》2026-10-03 的 v1051 导出，第 18–29 页，围绕经营方式与两道思考题，提炼成 **9 页、25 步**。该导出是明确选定的试作来源，不代表已核对为最新稿件。每页的「讲稿与来源」保留对应原稿和页码，2030 年与 200 万明确作为头脑实验的假设条件。

原稿、分镜、生成 HTML 与截图保存在本机 `.local/research/web-deck-style-test-2026-10-17/`，不进入 Git。可复用代码、通用示例和文档进入仓库。

## 使用

页面顶部选择模板；下一步先推进当前页，全部完成后再换页。支持左右方向键、PageUp/PageDown、Home/End、B 黑屏及 Esc 返回。目录可以跳转，讲稿弹窗打开时不会误推进底下的页面。刷新恢复模板与讲述位置。

大屏使用 1920×1080 设计画布等比适配。小于 680px 的演讲区域切换为可纵向阅读的版式，控制条保持可用；「手机预览」可在电脑窗口查看这种重排。全屏依赖浏览器支持与用户手势，不影响普通窗口播放。

产物为约 1.3 MB 的单个 HTML，文字、脚本、样式、字体及字体许可都内嵌；运行时无外部字体、图片、模型请求。本次未制作音频、视频或原生可编辑 PPTX。

## 复现与代码边界

在仓库根目录生成公开的两页示例：

```sh
node scripts/build-web-deck-demo.mjs site/web-deck-lab/example.storyboard.json .local/web-deck-example/index.html
python3 -m http.server 8766 --bind 127.0.0.1 --directory .local/web-deck-example
```

然后打开 `http://127.0.0.1:8766/`。端口占用时换一个端口，不停止其他服务。

- `storyboard.json` 管理内容、来源页码、表达类型和讲述步骤，不包含模板视觉。
- `site/web-deck-lab/model.mjs` 校验来源及结构，建立可反向移动的步骤表。
- `site/web-deck-lab/deck.js` 渲染九种页面，统一管理播放状态、导航和讲稿；文本经过转义。
- `site/web-deck-lab/deck.css` 保存两套模板的适配规则与窄屏重排，不改写文案和步骤。
- `scripts/build-web-deck-demo.mjs` 将分镜和资源打包为一个 HTML。它是确定性渲染器，不是自动理解文档的模型接口。

后续接入正式模式还需实现：上传文档提取、依据语义选择表现方式、从用户模板生成可检验的视觉规则、真实媒体能力与失败恢复。不得把本次手工分镜的成功当作任意文档自动生成质量已经验证。

- 3 项针对性测试通过：跨页正反向步骤、缺来源/不支持类型/不匹配步骤拒绝、单文件打包及脚本注入边界。

- 检查了模板切换、目录跳页、跨页反向推进、讲稿弹窗导航隔离、黑屏返回、带模板与步骤的刷新恢复。截图复核修正了一处目录标题断行，并提高建筑提案风非当前条目的对比度。
- 原始导出 SHA-256 与取材前一致。页面不读取或写入项目数据库、模型配置和历史，不调用付费模型。
- 当前证据来自本机内置浏览器。尚未在实体手机、Windows 投影设备、Safari、实际翻页笔及断网 `file://` 环境验收；未发布公网。
