# 制作与演练流程

2026-10-20。此次调整把可编辑 PPT 的制作与演练接成一条主线。

## 使用方式

1. 在制作台点击“编辑文字与动效”。直接点页面上的文字修改，在“页面动效”选择编排、播放方式并试播。
2. 保存后关闭编辑器，仍停留在制作台。进入演练中心，点击“开始演练”，自己现场讲，按自己的节奏翻页。
3. 演练时点击“返回制作台调整”继续编辑；“结束演练”或 Esc 返回演练中心。不会自动开启麦克风或录制声音。
4. 需要 AI 代讲时，展开“AI 口播与配音（可选）”，再准备口播稿、声音、试播和整场生成。画面文字、讲稿与口播稿分别保存。

## 当前版本如何选择

演练读取制作台保存的可编辑 PPT。编辑器中选中的版本按项目保存在本浏览器；未选择时使用最近建立、已经完整完成的版本。必须同时满足来源项目版本一致、全部页面完成、页数和页序一致。保存和撤销后重新读取记录，播放不再另行生成动效。

可编辑版本未完成或与项目不一致时，演练页明确说明使用项目现有画面，并可返回制作台核对。记录读取失败时禁用主播放按钮，用户可明确选择“先放映项目画面”，不会把读取失败当成没有可编辑版本。只有图片的老项目继续直接放映图片。

原“原画面 / 动态演示”选择只留在可选配音区的“旧版画面兼容设置”；原图片提取记录可从“已有版本与高级调整 → 查看旧版提取记录”进入。这些兼容流程仍保留原来的范围、费用确认与历史记录。

## 范围与验证

- 本次调整入口、版本选择与播放链路，不改变底层项目、图片历史、模型配置或已安装 Mac App。
- 主要文字可编辑、六种动效编排仍沿用上一阶段实现。网页 / HTML 支持这些动效，PPTX 保留可编辑文本与内嵌字体；尚无 PPTX 原生动画。
- 默认整图生成尚未全量改成底图加文字；新可编辑版本仍通过“编辑文字与动效”明确创建，实际生成会调用模型。旧图片页不会自动转换。
- 在新隔离工作区复用五种风格样例，实际验证画布改字、换动效、保存后演练、方向键翻页、返回制作台及撤销。测试修改已撤销，原工作区保留。
- 15 项相关自动测试通过，包含版本选择对旧版本、部分完成、页序改变和指定版本的保护，以及口播复用、停止、正文保留回归。TypeScript 与 Vite 构建通过。
- 本次没有调用真实语音或图片服务，也不扩展上一阶段的 PowerPoint、跨系统字体和出图质量验收结论。
