# 分层演讲：画布编辑与动效编排

2026-10-20。本机源码工作台的独立试用升级；不迁移旧项目，不覆盖整页图片、讲稿、已有口播或已安装 App。演示使用新工作区里的五种既有风格、21 个文字层，没有调用模型重画。此前的测试工作区也保留。

## 在画面上编辑

1. 在制作台打开“编辑文字与动效”，选择已完成页面。
2. 直接点画面中的主要文字输入、换行或粘贴。粘贴只接收纯文字。艺术字仍属于底图，不能选中编辑。
3. 选中后上方手柄移动文字，右下角手柄调整文本范围。手柄支持方向键移动 1 个画布单位，Shift 加速至 10；画布按比例缩放时仍以原始坐标保存。移动不改变字号，调整范围不缩小或拉伸字形。
4. 在“文字排版”中调整字体、字号、字重、颜色和字距。超出范围会提示并阻止保存。
5. “撤销一步”恢复最近一次文字、排版或位置修改。画面内也处理 ⌘Z / Ctrl+Z，Shift+⌘Z / Ctrl+Shift+Z 重做；“撤销修改”放弃本页未保存修改。“保存修改”写入独立演示，可撤销上次保存，最多保留 20 次。

输入时只同步文字数据，不重建正在输入的节点或重新加载 iframe。预览内嵌完整可用字体范围，中文组合输入期间不接受外部画布重绘。保存检查版本，遇到其他窗口更新会拒绝覆盖。更改画面不会重写讲稿或重录口播。

## 六种页面编排

“页面动效”选择编排后，点击画面上方“试播动效”。未保存也能试播；结束或停止后回到可编辑原位。正式 HTML 播放应用已保存的编排，PPTX 继续导出最终排版的可编辑文本框，暂不包含原生动画。

| 编排 | 表现 | 参考表达方式 |
| --- | --- | --- |
| 叙事镜头 | 底图轻微落定，文字按语义组跟进 | M06 图文叙事、M07 主视觉 |
| 金句聚焦 | 重点大字由虚到实，解释稍后出现 | M03 金句、M04 数字页中的文字层 |
| 章节开场 | 大标题舒展落位，辅助文字跟进 | M01 封面、M02 章节 |
| 阅读节奏 | 文字轻移、同组错峰，保持阅读顺序 | M06 图文、M09 并列观点 |
| 两侧对话 | 根据图层实际左右位置相向进入 | M14 对照、M15 比较页的文字层 |
| 层层推进 | 依据现有讲述步骤递进出现 | M05 公式解释、M09 观点、M13 层级 |

这六项只编排现有独立图层；不会自动把普通文字变成关系图、卡片或矩阵。“原有编排”保留旧演示逐层设定的效果、时长和延迟。新分层生成的布局计划可以根据内容选择六种编排之一，用户仍可更换；历史记录没有该字段时继续使用原有编排。

自然出场按语义组自动播放；逐步讲述由演讲者点击揭示，返回上一组不遗留变换；整页静态关闭出场动画。编排结束落在原始位置，不逐字切割中文，不改写数值。错峰总延迟上限 1.4 秒；减少动态效果模式使用 120ms 淡入，不做空间移动、模糊或镜头缩放。无持续循环，新播放会取消旧动画。

## 复现与验收

已有上一阶段素材时，新建试验目录：

```sh
node scripts/seed-layered-workflow-demo.mjs /absolute/editable-text-experiment /absolute/new-demo-data --authored-motion
AUTOPPT_DATA_DIR=/absolute/new-demo-data PORT=51922 npm run dev
```

目标必须不存在；脚本只导入指定五风格素材，不复制业务项目和模型配置。默认配对为水墨叙事、日系阅读、儿童聚焦、NEO 章节、先锋对话；第六种层层推进可随时选择试播。

自动测试覆盖六种编排的最终位置、时长上限、减少动态效果、比较方向、步骤计时，以及 API 保存、无效编排拒绝、撤销、旧项目保护与 HTML 导出。浏览器检查了五风格文本、原位替换与继续输入、换行溢出拦截、方向键移动与调整范围、保存与撤销、一步撤销、动效试播及 1280×720 / 390×844 布局。

真实指针已在同一编辑引擎的独立画布验证贴顶移动、贴底调整范围与 ⌘Z 撤销，边缘手柄保持可见。嵌入 iframe 的跨框指针自动化仍受坐标校验限制；工作台内已验证方向键移动/调整范围、保存与撤销。真实中文输入法候选窗、多设备帧率和系统减少动态效果开关尚未实机验收。代码包含对应处理，但不以自动测试代替这些实机结果。PPTX 原生软件打开与跨平台边界沿用[制作与编辑试用说明](分层演讲-制作与编辑试用.md)，本轮没有重新完成原生 PowerPoint 验收。
